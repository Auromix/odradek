# Odradek

**探索主动注意力、探照灯与灯瓣呼吸感的开源七轴桌面机械臂。**

[English](README.md) · [设计简报](docs/design-brief.md) · [方案比较](docs/concept-comparison.md) · [行为草案](docs/behavior-spec.md) · [路线图](docs/roadmap.md)

Odradek 是 Auromix 的独立项目，灵感来自《死亡搁浅》中的肩载探测器。首版面向桌面／固定底座的实际操作任务，期望通过关注朝向、定向照明、末端灯片的张合和光强变化，形成有主动注意力的机械形象。

**当前处于工业设计概念阶段。** 已收录 AI 辅助概念图、设计说明、生成提示词和后续路线图。尚未提供制造 CAD、经过验证的七轴机构、固件、感知跟踪系统或测试样机。负载、臂展、成本及性能指标待定义。

## 形态发散

![六组轮廓发散](docs/concepts/00-form-exploration.png)

从六个轮廓／光学头变体收敛为三个候选。七轴指机械臂本体，夹爪和灯瓣的额外驱动单列；透视草图不能证明轴系成立，具体拓扑将在 CAD 布局阶段复核。

## 三组候选

| 方案 | 灯片和光学头 | 与操作工具的关系 | 首要验证问题 |
| --- | --- | --- | --- |
| **A / FIELD 精密探索工具** | 四片较宽灯瓣，围绕相机与探照灯 | 观察头与夹爪暂按可换工具探索 | 换装接口、头部质量与灯瓣展开范围 |
| **B / FRAME 折叠骨架** | 三条腕背狭长灯片，光学头位于夹爪上方 | 探索照明、观察与抓取共存 | 手指净空、视场、灯瓣／工件干涉 |
| **C / SHELL 紧凑仪器** | 四片短灯瓣，收拢为侧向护罩，光学孔口仍外露 | 独立工具接口，空间关系待深化 | 收拢方式、光热与维护路径 |

## 主动注意力与呼吸表达

![注意力与灯瓣动作研究](docs/concepts/04-attention-study.png)

动作页暂用 A 方案研究表达语言，不代表已经选定最终外形。探照灯负责定向观察和任务照明，漫射灯瓣负责状态表达；慢张合与亮度变化共同产生呼吸感。机械臂朝向、任务照明和灯瓣表情分别控制，在任务状态下协调。图中追随目标的意图尚未实现为自动感知能力。
