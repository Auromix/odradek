# Odradek

**探索发光夹爪、圆形 LED 状态显示与主动注意力的开源七轴桌面机械臂。**

[English](README.md) · [设计简报](docs/design-brief.md) · [方案比较](docs/concept-comparison.md) · [行为草案](docs/behavior-spec.md) · [路线图](docs/roadmap.md)

Odradek 是 Auromix 的独立项目，灵感来自《死亡搁浅》中的肩载探测器。首版面向桌面／固定底座的实际操作任务，期望通过关注朝向、定向照明、末端灯片的张合和光强变化，形成有主动注意力的机械形象。

**当前处于工业设计概念阶段。** 已收录 AI 辅助概念图、设计说明、生成提示词和后续路线图。尚未提供制造 CAD、经过验证的七轴机构、固件、感知跟踪系统或测试样机。负载、臂展、成本及性能指标待定义。

## R1：灯片就是夹爪手指

根据新增要求，末端发光片同时承担抓取。每指探索承力骨架、内侧可换软垫和外侧／侧缘发光窗；中央圆盘暂用 **LED 点阵显示 + 外圈分区任务白光**，具体构型尚未选定。

![D2／D3／D4 发光夹爪比较](docs/concepts/05-petal-gripper-options.png)

| 候选 | 探索重点 | 主要取舍 |
| --- | --- | --- |
| D2 两指 | 对向夹取、较少手指 | 展开环绕感较弱 |
| D3 三指 | 围抱、接触分布 | 不规则工件与桌面接近待验证 |
| D4 四指 | 两组对向，保留四片展开剪影 | 指间干涉、接触均衡与走线更复杂 |

**D4 是建议优先深化的方向，尚未定案。**

![D4 整臂、抓持和圆盘显示研究](docs/concepts/06-petal-gripper-study.png)

图中给出待机、关注、进度、完成、等待五种显示示例。机械呼吸仅在空手且任务允许时进行；抓取、保持与释放不为表情改变夹持，灯光呼吸也须服从照明与成像。工件可以遮挡圆盘，不得为露出显示而松爪。显示与照明由不同光学区域承担；点阵全白不视为已经具备探照能力。

这些图用于评审功能与外观的关系，夹持力、运动学、光学与散热仍待 CAD 和样机验证。七轴指本体，统一核算末端驱动，不预设另有独立灯瓣机构。

## R0 历史：三组候选

| 方案 | 灯片和光学头 | 与操作工具的关系 | 首要验证问题 |
| --- | --- | --- | --- |
| **A / FIELD 精密探索工具** | 四片较宽灯瓣，围绕相机与探照灯 | 观察头与夹爪暂按可换工具探索 | 换装接口、头部质量与灯瓣展开范围 |
| **B / FRAME 折叠骨架** | 三条腕背狭长灯片，光学头位于夹爪上方 | 探索照明、观察与抓取共存 | 手指净空、视场、灯瓣／工件干涉 |
| **C / SHELL 紧凑仪器** | 四片短灯瓣，收拢为侧向护罩，光学孔口仍外露 | 独立工具接口，空间关系待深化 | 收拢方式、光热与维护路径 |

## R0 历史：主动注意力与呼吸表达

![注意力与灯瓣动作研究](docs/concepts/04-attention-study.png)

这张 R0 动作页曾以 A 方案研究表达语言，不代表已选定最终外形或满足 R1 抓取要求。探照灯负责定向观察和任务照明，漫射灯瓣负责状态表达；慢张合与亮度变化共同产生呼吸感。机械臂朝向、任务照明和灯瓣表情分别控制，在任务状态下协调。图中追随目标的意图尚未实现为自动感知能力。
