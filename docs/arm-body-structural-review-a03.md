# A03 构型的结构可实现性复核

日期：2026-09-30。回应“这样做关节，结构设计上能够满足吗？”；只复核本体，未修改底座、末端机构或查看器几何。

## 判定

**七轴拓扑及 J5 俯仰 → J6 横摆 → J7 整头 roll 有可实现的机械布置路径；当前 viewer 的实体画法不能直接制造。** 已发现 J5 完整圆环与 J7 壳体重叠，不应继续把它们当作成立的装配。140°腕部折回、全部滑条角域、纤细外形和2 kg净工件承载尚未共同得到验证。

用户已经确认的是 J2 竖直向上为零、低位 Z 字回折和 J7 直接 roll。J5/J6 的新顺序、60 mm肘部错层和精确角域仍是提案。零位改变仅改变角度表示，不会自动增加机械行程。

## 已发现的确定性干涉

本次直接检查 A03 查看器源代码中的几何，不依赖画面是否看得出穿插：

- J5 圆环主半径50 mm、管半径6 mm，位于其局部 XZ 平面。
- J7 简化壳体半径32 mm、长度40 mm，中心在 J6 输出的局部 X 轴上，距腕心65 mm。
- 在 J5 坐标系选点 `p=(55,0,0) mm`。它距 J5 圆环中心线5 mm，小于管半径6 mm，因此在圆环内部。
- 当 J6 为默认的−30°时，J7 轴方向为 `u=(cos(-30°),sin(-30°),0)`。该点相对圆柱中心的轴向坐标 `p·u−65 = −17.3686 mm`，径向距为27.5 mm；分别在半长20 mm和半径32 mm内。因此同一点也在 J7 壳体内部。
- J6=0°时，该点轴向−10 mm、径向0 mm，同样在两个实体内；+30°也不能消除此重叠。上游刚体旋转和 J7 自身绕圆柱轴旋转不改变此结论。

这是局部相交的反例，足以否定当前圆环/圆柱装配，但不是整臂的完整碰撞扫描。头部下相机与前臂在大俯仰折回时还存在独立的避让问题；默认侧头30°不能当成已通过的解决方案。

## 各部位的结构路径

| 部位 | 可继续的设计方向 | 还需要落实 |
|---|---|---|
| J2 肩部 | 横向俯仰关节；竖直上臂作为零位；按载荷设计输出支承 | 肩壳、上臂根部、线束及底座附近的真实摆动范围；静态保持和运动扭矩 |
| J3 上臂 roll | 沿连杆轴线布置驱动和中空通道 | 两端轴承/连接、装配路径和转动线束余量 |
| J4 肘部 | 错层叉架让上臂与前臂能够回折 | 60 mm不是冻结尺寸；需同时核对外壳、轴承、螺钉和线束，不只核对两根杆 |
| J5 腕部俯仰 | 有开口的双侧叉架、两侧耳轴；优先把驱动放在前臂末端附近 | 开口与桥接位置、真实驱动包络；驱动侧定位与对侧支承的配合避免过约束；是否保留140°回折 |
| J6 腕部横摆 | 随 J5 转动的紧凑正交载架或转台，承接 J7 | 与 J5 叉架、J7、前臂及头部的组合角域；允许必要的轴心偏置 |
| J7 整头 roll | 中空轴向旋转总成，后接可拆头部法兰 | 同时核对输出轴承的弯矩/径向力和驱动转矩；线束扭转限制，暂不假定无限旋转 |

上述为结构建议，并未新增用户确认。共点轴线不要求电机实体重叠，但也不要求为了数学共点而牺牲装配和内部走线。允许小偏置通常增加布置自由度，是否影响目标工作空间要用修改后的同一套模型比较，不能提前宣称无影响。

外观方向建议为细长主连杆配局部加宽的肩、肘、腕关节，外壳以折线和圆润边缘与头部协调。不要通过把承载关节缩成没有驱动的薄环来获得纤细比例。此处不冻结任何关节外径。

## 驱动与载荷为什么必须一起检查

可采购的中空减速器和承载输出轴承提供了实现基础。例如 Harmonic Drive 的 SHD-2SH 集成中空输入和交叉滚子输出轴承，但它仍是减速器总成；不能等同于包含电机、反馈、制动、驱动电子和散热结构的完整关节。无框电机本身也不是带轴、壳体和支承的执行模组。[SHD-2SH 官方资料](https://www.harmonicdrive.net/products/gear-units/simplicity-gear-units/shd-2sh)、[Kollmorgen 无框电机说明](https://www.kollmorgen.com/en-us/products/motors/technologies-explained/what-is-a-frameless-motor)。

仅作数量级计算：设头部质量1.5 kg、其质心距 J5 轴110 mm；2 kg工件质心距 J5 轴200 mm。在两者均水平前伸、J6=0°的情形下，头部与工件对 J5 的重力矩为：

`τ = 9.81 × (1.5 × 0.110 + 2.0 × 0.200) = 5.54265 N·m`。

1.5 kg是研究假设，不是已确认的头部质量；110/200 mm在这里是假定质心偏置，不是由外形中心或 TCP 自动得到的实测值。此数值不包含 J6/J7、叉架、线束的重力，也不包含加速度、摩擦和任务外力，不能据此选一台“5.5 N·m电机”就认定满足要求。仅2 kg工件在肩部水平前伸700 mm时已有13.734 N·m，肩部还须另计头部及本体自重。

对 J7，轴向 roll 的电机转矩不等于输出端承受的倾覆弯矩；对 J6，其轴线会随上游转动，不能因参考姿态叫“横摆”就认为始终不承受重力矩。减速器额定值、允许倾覆力矩、整关节连续转矩与封闭外壳散热需分别核对。

## 内走线与最小下一步

双 GMSL/GMSL2、EtherCAT 与电源仍按内部布置。J5/J6需要分段弯曲空间，J7需要有限扭转余量、应力释放与拆装路径；三根互相垂直的中空轴不等于一条已经贯通的通道。半径、循环寿命和连接器包络需由具体线缆及接头确定。

下一步只做 **J5–J7腕部的粗实体装配**：加入实际尺寸的驱动占位、输出支承、叉架、法兰及线束包络，保留同一个头部和前臂作为边界。先比较Z字待机、抬起互动及两者过渡，回答“140°能否做到、腕宽需要多少、要偏置多少”。通过后再回算有效臂展与肩肘负担；这一步不替代强度、刚度、热、疲劳或实物验证。
