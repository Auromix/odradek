# Odradek 注意力、抓取与显示行为｜R2 草案

本体 7 自由度决定操作姿态，末端四指各 1 自由度。J7 沿末端正面法线带动四指、圆形 LED 屏和双鱼眼一起 roll；机械表达服从当前任务与抓取约束。

## 状态与转移

| 状态 | 候选行为 | 转移依据 |
| --- | --- | --- |
| **Rest 休息** | 空手保持安静姿态；任务允许时缓慢小幅张合，四片柔和发光 | 收到有效任务或可靠目标后进入 Notice |
| **Notice 注意** | 本体朝向目标，空手四指独立舒展；小幅 roll 与屏幕方向标记共同表达关注 | 目标与任务条件满足后进入 Inspect |
| **Inspect 观察** | 双鱼眼按所需视角观察，四片提供稳定任务照明；确定抓取姿态和开口 | 观察、定位及抓取条件满足后进入 Grasp |
| **Grasp 抓取** | 四指按接触计划闭合；停止机械呼吸，不叠加表情性 roll | 夹持条件确认后进入 Hold；失败时按任务处理 |
| **Hold 保持** | 保持夹持约束；本体与 J7 只执行任务所需运动 | 放置条件满足后进入 Release |
| **Release 释放** | 按放置计划张开，表达请求不改变释放过程 | 确认释放、手指无约束后进入 Rest 或下一任务 |
| **Park 收纳保护** | 空手四片完全闭合；允许遮挡屏幕和双相机，不继续宣称视觉观察 | 新任务到来后，先沿验证路径展开，再恢复所需观察 |

接触、夹持确认、目标有效性和故障处理仍需在控制设计中确定。全闭路径与姿态需由同一套机构实现，不能从静帧推定可达。

## 动作、照明与显示的分工

四个独立开合坐标控制四指。分节指片若采用固定连杆耦合，各节按同一坐标联动，不额外提供独立指节、侧摆或扭转。外形为左右各一组近邻双瓣、左右镜像且上下不同；同组不强制同步，可只舒展一指表达方向。

机械呼吸仅在空手且任务允许时进行。抓取、保持、释放阶段不为表达改变夹持，也不为显示可见而松爪或移动工件。表情性 roll 同样只在任务允许时使用，不能与任务要求的姿态相冲突。

**四片承担照明，中央圆形 LED 屏承担显示。** 屏幕可用圆周像素画出灯环感，没有独立实体灯环或中央任务探照灯。夹指内侧软垫承担接触，发光窗拟在外侧／侧面；抓取姿态下的照明方向和遮挡需要样件验证。亮度呼吸可以与机械张合分开控制，但须服从任务照度与成像需要。

## 中央显示的候选语义

| 图案 | 表达内容 | 使用边界 |
| --- | --- | --- |
| 关注点／方向标记 | 当前任务关注方向 | 不以动画暗示视觉锁定已经完成 |
| 圆周进度弧 | 有可测依据的任务进度 | 无进度依据时显示等待，不制造百分比 |
| 完成图形 | 当前任务已满足完成条件 | 不以动画结束代替操作完成 |
| 等待图形 | 等待指令、条件或人工处理 | 与运行和故障可辨识 |
| 故障图形 | 已知异常或暂停原因 | 显示不替代实际停止、保持等控制 |

上述图案均在同一圆屏内绘制。空手全闭或抓取物体时可以不可见，不把无遮挡显示作为动作成立的前提。

## 旋转与视觉边界

双鱼眼在末端局部坐标中位于 12 点／6 点方向，随整头旋转。屏幕内容和相机图像的旋转补偿可作为软件候选，不增加物理稳定云台。J7 本轮仅示意有限角度 roll；具体限位与线束路径尚待设计。

若采用感知驱动，目标须有有效性依据；目标丢失或相机受遮挡时，不继续表现为可靠跟踪。持物时仍保留夹持约束。
