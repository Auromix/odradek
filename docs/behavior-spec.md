# Odradek 注意力、抓取与灯光行为｜R1 草案

状态：候选设计，待原型验证；不是已实现能力。灯片即抓取手指，机械表达必须服从当前抓取约束。

## 状态与转移

| 状态 | 候选行为 | 转移依据 |
| --- | --- | --- |
| **Rest 休息** | 空手时保持安静姿态；任务允许才做缓慢小幅张合和柔和灯光呼吸 | 收到有效任务或可靠目标后进入 Notice |
| **Notice 注意** | 本体朝向目标，空手手指适度舒展；中央图案表达关注方向 | 目标与任务条件满足后进入 Inspect；失效则停止推进 |
| **Inspect 观察** | 按观察需要调整姿态，使用稳定任务照明；确定抓取姿态与开口 | 观察、定位及抓取条件满足后进入 Grasp |
| **Grasp 抓取** | 手指按抓取计划闭合；接触和夹持控制优先，停用机械呼吸 | 接触与夹持条件经确认后进入 Hold；失败时按任务处理 |
| **Hold 保持** | 保持抓取约束；注意力和表情请求不得改变夹持或松爪 | 仅在任务允许且放置条件满足后进入 Release |
| **Release 释放** | 按放置／释放计划张开，表达请求不改变释放过程 | 确认已释放且手指无约束后进入 Rest 或下一任务 |
| **Park 停放** | 空手时沿经验证的路径收拢；仍持物时不得直接套用空手停放动作 | 收拢状态和路径均需运动包络验证 |

以上转移条件表达控制需求。接触检测、力反馈、目标有效性及故障处理的具体实现尚未定义。

## 抓取、照明与表达的协调

本体七轴决定观察与操作姿态，末端驱动决定手指开合。由于灯片同时承担抓取，机械表达与夹持共用同一组物理约束，不预设另有一套灯瓣机构。**机械呼吸仅限空手且无接触约束的时段；抓取、保持和释放阶段不为表情改变夹持。**

发光窗位于手指外侧或侧面，内侧可换软垫用于接触。灯光呼吸可以独立于机械张合，但亮度变化须服从任务照度、成像与人员观察需求，必要时暂停。不能以呼吸灯效代替稳定任务照明。

中央圆形 LED 在 R1 图示中暂分为中心点阵和外圈分区任务白光，分别定义光学、散热与控制；这是一种构型候选。任务白光提供照明，点阵表达状态，不预设两者能在所有工况同时达到所需效果。具体显示分辨率、亮度和照射方向待验证。

## 中央显示的候选语义

| 图案 | 表达内容 | 使用边界 |
| --- | --- | --- |
| 方向标记 | 当前任务的关注方向 | 来自有效任务状态，不暗示已完成视觉锁定 |
| 进度 | 有可测依据的任务阶段或完成比例 | 无进度依据时使用等待图案，不制造虚假百分比 |
| 完成 | 当前任务已满足完成条件 | 不以动画播放结束代替实际操作完成 |
| 等待 | 等待指令、条件或人工处理 | 与运行、故障有可辨识差异 |
| 故障 | 已知异常或暂停原因 | 显示不替代停止、保持等控制行为 |

工件可能遮挡圆盘，这可以作为抓取中的正常状态接受。**不得为了展示图案而松爪、改变接触或移动工件。** 后续可研究侧向提示或上位机反馈，但不把无遮挡显示作为抓取成立的前提。

若采用感知驱动，目标须有有效性与置信依据；目标丢失时停止继续追随，按当前任务约束等待或恢复，持物时仍须保留抓取约束。默认不持续扫描人脸；关注对象来自任务或用户明确选择。表达须随真实状态变化，不用预演灯效冒充识别、锁定或任务成功。
