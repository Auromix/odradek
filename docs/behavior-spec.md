# Odradek 注意力、抓取与显示行为｜R3 草案

本体 7 自由度决定姿态，末端四指各 1 自由度。J7 沿末端正面法线带动四指、圆形 LED 屏和双鱼眼一起 roll；机械表达服从当前任务和抓取约束。

## 状态与转移

| 状态 | 候选行为 | 转移依据 |
| --- | --- | --- |
| **Rest 休息** | 空手保持安静姿态；允许时在已验证范围内小幅张合、柔和发光 | 收到有效任务或可靠目标后进入 Notice |
| **Notice 注意** | 朝向目标，四指独立舒展；任务允许时用小幅 roll 和屏幕标记表达关注 | 目标与任务条件满足后进入 Inspect |
| **Inspect 观察** | 按实际可用视野观察，四片提供稳定照明；确定抓取姿态和接近开口 | 观察、定位与抓取条件满足后进入 Grasp |
| **Grasp 抓取** | 按接触计划闭合，停止机械呼吸及表情性 roll；不继续硬推至空手收拢限位 | 接触和夹持条件确认后进入 Hold；失败时按任务处理 |
| **Hold 保持** | 保持夹持约束，本体与 J7 只执行任务所需运动 | 放置条件满足后进入 Release |
| **Release 释放** | 按放置计划张开，不以表达改变释放过程 | 确认已释放、手指无约束后进入 Rest 或下一任务 |
| **Park 收拢** | 空手沿验证路径达到各指收拢限位，保留结构间隙 | 新任务到来后，先到达所需观察／操作开口，再继续任务 |

空手全闭不意味着密封或光学件必然被遮住。Park 中可否观察、可否显示，由实际遮挡决定，不能从“闭合”这个状态名推断。各状态的接触、夹持确认及故障处理尚需控制设计。

## 机构约束与接触

选定外形是上两片大、下两片小、左右镜像；每指仍独立。当前优先研究完整刚性灯板、不同限位和前后错层。额外连杆只能确定性联动，不增加独立自由度；动作时序不能修复最终姿态的实体交叉。

空手闭合检验每片与其他指片、掌体及光学件的间隙；持物闭合另检验接触位置、法向、摩擦和力路径。向前包合时灯面转向物体，候选接触结构采用同侧凸起软垫／承力边框及凹入灯窗。定角指尖垫或掌部止靠面仍待验证，不能让物体被推向屏幕或镜头承力。

机械呼吸和表情性 roll 仅在空手且任务允许时进行。抓取、保持、释放不为表达改变夹持，不为露屏松爪或移动工件。抓持成功目前没有验证依据，界面不能以合拢动画替代真实确认。

## 照明与显示

四片承担照明，中央圆形 LED 屏承担显示；圆周像素可画灯环，没有独立实体灯环。夹指姿态改变时，照射方向、反射和遮挡随之变化，光强呼吸须服从任务照度与成像。

| 图案 | 表达内容 | 使用边界 |
| --- | --- | --- |
| 关注点／方向标记 | 当前任务关注方向 | 不暗示视觉锁定已经完成 |
| 圆周进度弧 | 有可测依据的任务进度 | 无进度依据时显示等待 |
| 完成图形 | 当前任务已满足完成条件 | 不以动画结束代替操作完成 |
| 等待图形 | 等待指令、条件或人工处理 | 与运行、故障可辨识 |
| 故障图形 | 已知异常或暂停原因 | 显示不替代实际停止、保持等控制 |

这些图案均在同一圆屏内绘制；显示被指片或工件遮挡时，不能以改变夹持来恢复可见。

## 相机外倾与旋转

双鱼眼位于局部 12 点／6 点方向，分别向上／下外倾并保持左右对称。外倾角 α 尚未选定；增加外倾会减少近场重叠，需要按目标距离、视场和抓取遮挡验证。双相机不自动代表已实现双目深度或全程无遮挡感知。

相机随整头 roll 旋转，局部上／下不等于世界坐标上／下。图像和屏幕方向补偿可作为软件候选，不额外增加稳定云台。J7 仅示意有限角度转动。

目标丢失、镜头被遮挡或观察条件不足时，不继续表现为可靠跟踪；持物时仍保留夹持约束。R3 的计算与边界见[收拢研究](r3-closure-study.md)和[数字几何图](concepts/11-r3-geometry-check.png)。R2 的紧凑保护茧只是历史画面，不是已验证的 Park 姿态。
