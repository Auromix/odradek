# Odradek 昵称候选

状态：创意候选，未选定。项目与仓库仍为 **Odradek / Auromix/odradek**。

| 候选 | 建议中文读法 | 命名意图与性格 |
| --- | --- | --- |
| **Odi** | **欧迪，o-di** | 从 Odradek 简化而来，亲切、机灵；最能延续项目身份，优先推荐 |
| **Lumo** | **露莫，lu-mo** | 由 luminous 的声音联想到光，偏柔和、明亮与呼吸感 |
| Noto | 诺托，no-to | 创作时由 notice 联想到“注意到你”，偏专注的观察者 |
| Piko | 皮可，pi-ko | 短促轻快，适合动作敏捷、会探头的机器 |
| Tavi | 塔维，ta-vi | 友好、好奇的造词式昵称，适合探索伙伴 |
| Filo | 菲洛，fi-lo | 轻盈、精细的造词式昵称，与细长灯指呼应 |

这些解释是本轮设计赋义和发音联想，不是严格词源。候选未做名称占用或商标可用性判断。

若希望与原作名字保持联系，选 Odi；若希望它独立形成灯光伙伴的性格，选 Lumo。昵称选择不改变当前 7＋4 DOF 与四瓣模块方向。
