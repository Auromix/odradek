# 机械臂本体：独立讨论入口

日期：2026-09-30。用户将工作分开：原讨论分支继续底座，本讨论分支负责机械臂本体。继续按部分确认，不一次展开完整选型、建模和制造图。

本页是范围与已确认输入记录，不是新的轴系或硬件定案。历史工程资料仅作参考，其质量、几何和硬件不自动成为新本体设计。

## 本分支范围

- 七轴本体的整体轮廓、典型姿态、轴系位置、主连杆与腕部比例。
- 随后逐项确认关节包络、驱动、结构截面、外壳、维护与内部线束。
- J1 执行总成与所需安装包络归入本体研究；固定承载件、桌夹、底座装饰壳和后部接口布局由底座分支收敛。两者之间通过安装基准、载荷和空间要求协调。
- 末端以可拆模块及其接口需求参与本体设计，本轮不重做四瓣机构或相机选型。外置盒硬件不在本轮选择。

## 继承的确认输入

| 项目 | 已有要求 |
|---|---|
| 定位与外观 | 桌面机械宠物；细长、灵动、科幻机甲风格，与四瓣末端协调；拆下末端后本体仍有完整外观 |
| 本体自由度 | 7 个主动轴，独立于末端开合机构 |
| J7 | 沿末端正面法线带动整头旋转；连续转动能力和角域尚未确认 |
| 尺度 | 肩关节至任务 TCP 约 700 mm；需计入可拆末端长度，不能同时把肩至法兰设为 700 mm |
| 载荷 | 2 kg 净工件，另计真实末端模块质量、质心和惯量 |
| 控制与走线 | EtherCAT 执行链、双 GMSL/GMSL2 相机通路及电源内走线；外置控制与传感器处理 |
| 末端接口 | J7 后可拆；品牌、具体法兰和连接器尚未冻结 |

既有图稿见[本体与末端视觉方向](r5-modular-design.md)。整头不超过 1.5 kg 只是历史工程争取目标，不是已确认或已实现的输入。图稿的关节外形也不证明实际轴系已成立。

## 与相邻模块交换的最少信息

| 相邻模块 | 需要对齐的信息 |
|---|---|
| 底座 | 固定安装基准、J1 轴位置与总成包络、安装连接、质量和重心、底座所受六维载荷、线束入口及维护空间 |
| 可拆末端 | 工具坐标系与 TCP 偏置、法兰连接、包络、质量/质心/惯量、接口载荷、电源与通信、拆装空间 |

这些接口目前是协调清单，尚无可用于制造的冻结数值。底座分支的形状、桌夹范围与开孔不由本页重新决定。

## 当前只确认一个问题

待机和观察时，本体更偏向哪种整体轮廓？

- **舒展、前倾的 S 形轮廓**：作为推荐的待选方向，突出探身观察的机械宠物感。
- **肩、肘、腕分节明显的折线轮廓**：突出机械手臂感。

两种方向都保留七轴；这是典型姿态与视觉取向比较，不预设肩三轴、肘一轴、腕三轴的具体轴线布置，不宣称任一方案已满足关节范围、无碰撞、负载或线束要求。等待用户选择后，再比较轴系和轮廓怎样协同。
