# 机械臂本体：独立讨论入口

日期：2026-09-30。用户将工作分开：原讨论分支继续底座，本讨论分支负责机械臂本体。继续按部分确认，不一次展开完整选型、建模和制造图。

本页记录范围、确认输入、姿态方向与当前讨论入口，不是新的轴系或硬件定案。历史工程资料仅作参考，其质量、几何和硬件不自动成为新本体设计。

## 本分支范围

- 七轴本体的整体轮廓、典型姿态、轴系位置、主连杆与腕部比例。
- 随后逐项确认关节包络、驱动、结构截面、外壳、维护与内部线束。
- J1 执行总成与所需安装包络归入本体研究；固定承载件、桌夹、底座装饰壳和后部接口布局由底座分支收敛。两者之间通过安装基准、载荷和空间要求协调。
- 末端以可拆模块及其接口需求参与本体设计，本轮不重做四瓣机构或相机选型。外置盒硬件不在本轮选择。

## 继承的确认输入

| 项目 | 已有要求 |
|---|---|
| 定位与外观 | 桌面机械宠物；细长、灵动、科幻机甲风格，与四瓣末端协调；拆下末端后本体仍有完整外观 |
| 本体自由度 | 7 个主动轴，独立于末端开合机构 |
| J7 | 沿末端正面法线带动整头旋转；连续转动能力和角域尚未确认 |
| J2 零位 | 上臂竖直向上为0°，向桌内俯下为正角；用户确认需要两侧摆动，实际机械角域待定 |
| 尺度 | 肩关节至任务 TCP 约 700 mm；需计入可拆末端长度，不能同时把肩至法兰设为 700 mm |
| 载荷 | 2 kg 净工件，另计真实末端模块质量、质心和惯量 |
| 关节技术偏好 | 准直驱＋转子/输出端双编码器；优先有具体型号开源采用证据，紧凑和性能优先 |
| 控制与走线 | 用户已接受各种关节通信协议，EtherCAT不再是选型前置要求；双GMSL/GMSL2相机通路及电源内走线，外置控制与传感器处理 |
| 末端接口 | J7 后可拆；品牌、具体法兰和连接器尚未冻结 |
| 关节预算 | 用户确认没有预算上限；优先比较体积、重量、低速控制、保持能力与开发可行性，不据此放大所有关节 |

既有图稿见[本体与末端视觉方向](r5-modular-design.md)。整头不超过 1.5 kg 只是历史工程争取目标，不是已确认或已实现的输入。图稿的关节外形也不证明实际轴系已成立。

## 已确认：低位收拢，互动时抬起

用户明确选择 **低位收拢，互动时抬起**。这替代之前未确认的常态轮廓比较；确认的是默认行为与姿态方向，不是某张完整新图或精确关节角度。

本轮将其转为以下设计意图。头部朝向、收拢路径和动作分配均是进一步提出的做法，尚未完成运动学或视场验证。

| 状态 | 本体姿态意图 | 头部与空间意图 |
|---|---|---|
| 低位待机 | 肩部降低、肘部回折，两段主连杆靠近但留真实间隙，整体降低并收回底座附近 | 头部仍朝桌内侧用户、可轻微仰起；屏幕与相机不被本体遮住；下灯瓣和腕部不触桌 |
| 抬起互动 | 肩肘展开并抬升，前臂适度前探，保留肘部弯曲；腕部做小幅转向/倾斜 | 头部明显高于待机位置，表现抬头关注；日常互动不默认全伸直或伸至最大臂展 |

同一本体只改变姿态，不通过缩短待机图的连杆或放大互动图制造差异。图中四瓣头保持同一展开状态，“低位收拢”指本体折叠，不附带确认灯瓣全闭。抬起高度、行程、速度和持续保持功耗本轮均未指定；低姿态不等于自动断电或已证明省电。

## 与底座并行推进的约束

本轮只读取原对话底座分支，不修改它的文件。读取到的 B03 记录为：保留桌后沿夹装、盒架向桌内收、允许夹体与走线所需的小后缝。由此提出本体布置目标：肩肘向桌面内侧回折，不依赖大幅越过桌后缘向墙侧活动；仍需与底座交换 J1 包络和完整运动扫掠空间，不能由静态图确认靠墙运行。

本对话继续使用 `design/arm-body` 独立工作树，只提交本体资料。用户已调整优先级：**先讨论机械臂构型、电机与关节选型，再推进外观细化**。

选型研究见 [A02 七轴构型与关节初筛](arm-body-architecture-a02.md)：并列比较中空 EtherCAT 一体化关节与定制关节。用户通过查看器反馈后，轴系探索更新到下方 A03；A02 腕部顺序不再作为最新提案。候选器件和质量假设均待确认，不沿用旧 RH 平台的几何、质量或逐轴能力结论。

A03阶段：用户确认竖直肩零位、低位Z字回折和J7直接roll；提案把J5改为外层俯仰、J6改为内层横摆，以同一套几何比较收拢、抬起与参考伸展。该版理想共点腕与60 mm肘错层已由下面A05的实尺寸包络方案替代；旧查看器保留在Git历史。

随后完成 [A03 结构可实现性复核](arm-body-structural-review-a03.md)：轴序具有机械实现路径，但当前J5整环与J7壳体有确定干涉。建议先用开口叉架、真实驱动/支承和线束包络重建腕部粗装配，再决定尺寸、偏置和有效角域；此建议尚未成为已确认结构，不据此宣称完成2 kg承载或制造验证。

最新选型见 [A04 准直驱、双编码器关节初筛](arm-body-actuators-a04.md)：用户明确QDD与双编码器、接受各种总线、优先开源社区采用证据。以达妙和RobStride低比行星关节为主要候选，按轴负载分级；A02的高比中空EtherCAT路线不再是本轮优先方案。具体型号、轴分配和采购版本仍待结构与载荷核对。

当前装配研究为 [A05 实尺寸关节装配与走线修订](arm-body-assembly-a05.md)及 [交互查看器](viewers/arm-body/README.md)。用户要求把候选关节装入模型并修正：本轮以RobStride分级组合建模，J5/J6轴心错开55 mm、采用开口载架，肘部侧向错层90 mm；低位略放松肘部回折以避让下相机。已把电机固定壳体、旋转输出与线束预留区分别建模，形成可重复检查和可编辑Blender包络。支承、完整线束、载荷及制造尺寸尚未冻结，不能据此直接加工或认定2 kg承载成立。
