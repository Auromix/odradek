# Odradek 决策记录

## 2026-09-27 / 项目意图与命名

已确认：开源七轴机械臂，设计与实用性并重；首版为桌面／固定底座，用于实际操作任务。项目采用游戏中装置的名称 **Odradek**，仓库为 `Auromix/odradek`。用户要求表现主动注意力、探照灯、张合呼吸与末端灯光片，并绘制候选概念图、创建 GitHub 仓库。

## 2026-09-27 / R0 光学灯瓣探索（历史）

首轮从骨架、护盖和停放剪影，发展为 A FIELD、B FRAME、C SHELL 三案；A 用于 04 行为分镜。A／C 探索观察头与夹爪换装，B 探索光学头、灯片和普通夹爪共存。当时未选定最终方案。

原图、提示词与审阅记录保留。三种本体形态、护盖层次与比例仍可迁移；上述工具关系已被 R1 的一体化要求取代，不再作为当前末端主方向。

## 2026-09-27 / R1 灯片兼作夹爪手指

用户新增要求：灯片也能作为夹爪使用，中央探照灯可探索圆形 LED，并能做特定显示。

本轮据此将发光片本身作为抓取手指，对比 D2 两指对夹、D3 三指包络、D4 四指两组对向。每指暂按承力骨架、内侧可换软垫、外侧或侧面发光窗共同设计。**建议优先深化 D4；这是工作建议，不是用户已选定的最终方案。**

R1 图示中央暂采用点阵显示与外圈分区任务白光，各自考虑光学、散热与控制。用户确认的是功能探索方向，具体构型、显示分辨率、光学布局与驱动未定型。关注方向、进度、完成、等待、故障是候选图案语义，不代表感知或控制已经实现。

机械呼吸仅限空手且任务允许时；抓取、保持和释放阶段不为表情改变夹持。灯光呼吸受任务与成像约束；工件遮挡圆盘可以接受，不得松爪露屏。本体七轴之外，统一核算末端所需驱动，不预设灯片和夹爪必有两套机构。

R1 交付：[机构候选图](concepts/05-petal-gripper-options.png)、[深化研究图](concepts/06-petal-gripper-study.png)及对应简报、行为与验证计划。图片仍为概念表达，不能证明夹持力路径、运动学或工程可制造性成立。
