## 2026-09-27 / 项目意图与命名

已确认的用户要求：

- 开源七轴机械臂，设计与实用性并重，放在 Auromix。
- 首版为桌面／固定底座，执行实际操作任务。
- 项目采用游戏中装置的名称 **Odradek**，仓库名 `odradek`。
- 明确表现主动注意力、探照灯、张合呼吸感、末端数片灯光面板。
- 本轮绘制若干候选概念图，随后创建对应 GitHub 仓库。

## 2026-09-27 / 从风格参考转向光学灯瓣设计

首轮调研主要关注骨架、护盖和停放剪影。用户随后明确要求末端发光片与张合呼吸，因此本轮把它们纳入核心功能意图，不再将它们仅作为装饰参考。

当前保留 A FIELD、B FRAME、C SHELL 三案；A 额外用于动作分镜，以便比较同一头部的状态。**没有选定最终方案。** A／C 探索工具模块化，B 探索光学头、灯片与夹爪同时安装。

本体目标七轴，夹爪与灯瓣驱动单独计数。3+1+3 空间组织、局部打印护盖、候选材料和灯光状态均属工作假设，等待任务输入与工程验证。
