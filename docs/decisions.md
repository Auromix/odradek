# Odradek 决策记录

## R5 / 最新确认：单中央驱动、发光面夹持、独立本体

用户明确四瓣不要求独立控制，可用一个电机与另外三瓣mimic随动；优先隐藏于中央后壳，避免周边电机突出。保留上大下小、左右镜像、宽肩折线及截短端部造型，不改成纯三角尖片。发光面本身是夹持面；空载全闭→全开→全闭≤1秒，接触后限力，持续占空尚未指定。2kg是净工件，另计末端；约700mm肩至TCP和GMSL/GMSL2均已确认。

本体与末端分开开发，统一风格和可拆接口；本体载荷仍需包含真实末端质量/质心/惯量。暂争取整头≤1.5kg只是工程权衡目标，未经用户指定也未实现。P16退出主末端路线，历史四驱数学/CAD保留。新增被动顺应不会自动成为独立主动轴，真实连杆关系不能任意用线性mimic代替。见[R5图稿与架构](r5-modular-design.md)。

## 2026-09-27 / 项目意图与命名

最初提出开源七轴机械臂，后按下述许可决策调整为非商业公开设计；设计与实用性并重；首版为桌面／固定底座，执行实际操作任务。项目采用游戏装置名 **Odradek**，仓库为 `Auromix/odradek`。主动注意力、张合呼吸与末端灯光是持续保留的表达目标，nickname 尚未选定。

用户选中 R2 展开正面图的上两片大、下两片小、左右镜像外形，要求认真检查空手完全闭合不干涉及持物有效闭合。双鱼眼在中央上下位置向外倾，保持左右对称；倾角尚未选定。

## R3 / 当前候选与定义

- 优先保留完整刚性灯板，研究上下不同闭合限位与真实前后错层。根部位置、连杆和限位尚未确定；不靠灯板变形、缩短或动作时序掩盖穿模。
- 空手全闭指达到机械收拢限位、保留真实间隙且不干涉，不意味着密封、四尖同点或必然遮挡屏幕／相机。可见性由几何决定。
- 持物闭合须另行检查接触法向、摩擦、受力及退让空间，不能把空手不碰撞当作有效抓取。
- 向前包合使原朝前灯面转向工件；接触候选改为同侧凸起可换软垫／承力边框、灯窗凹入，替代 R2 的相反两面假设。定角垫和独立承力止靠面仍是候选，屏幕和相机不承担接触载荷。
- 四指执行器与端侧控制仍拟置于可拆模块内，接口待定；J7 仍采用有限角度 roll 假设。
