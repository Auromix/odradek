# A09 离线查看器

`index.html`内嵌两种长度的原始CAD三角网格、底座背景和MIT three.js，可离线使用。默认短版抬起互动；拖动七轴滑条或选择预设、切换长短比例、隐藏护罩检查骨架，鼠标拖动旋转、滚轮或双指缩放。

查看器是设计讨论工具，无机器人控制接口。滑条不是合格工作空间：采样发现参考姿态其他轴不变时J2 −70°及J4 −155°干涉；任意拖动组合均未实时碰撞检查。3 kg是目标，热/轴承/紧固/线束未完成。
