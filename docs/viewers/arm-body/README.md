# A03 七轴构型交互查看器

本轮响应用户对 A02 viewer 的修正，再继续选型。它是构型讨论工具，不是已选外观图或制造 CAD；不修改并行工作的底座设计。A02 查看器保留在提交 `540f158` 的历史中。

## 已确认与当前提案

用户确认：**J2 上臂竖直向上为 0°**；向桌内俯下为正角，两侧可摆动。低位应为 Z 字回折；J7 保留沿头部法线直接 roll。

本轮提出、尚未冻结：**J5 外层俯仰、J6 内层横摆、J7 整头 roll**，取代 A02 的 J5 前臂 roll、J6 pitch、J7 roll。J5/J6 移至同一理想腕心，J7 轴线通过腕心。两道环表示理想转轴关系，不是已装配好的电机壳体或叉架。

理由是把 Z 字收拢所需的大幅俯仰放在第一层。局部腕角速度雅可比为 `Jω = [ey, Ry(q5)ez, Ry(q5)Rz(q6)ex]`，行列式为 `cos(q6)`：J5 折回140°本身不导致这一腕部姿态退化；J6 横摆接近±90°仍会退化。查看器在 J6 接近这个位置时显示提示。

旧 X–Y–X 腕在 J6=0/180°有腕部姿态退化，但**旧腕三条轴线的延长线本来就相交于 J6**，不能因关节原点相距150/65 mm，就认为它不是共点腕。整臂是否奇异仍需完整6×7雅可比，不能由三轴腕的行列式直接决定。

新轴序的好处针对当前 Z 折叠和关注动作成立，**尚未证明扩大或保留全部可用工作空间**。真实轴线偏置、驱动包络、灯瓣扫掠体、角域和线束都可能改变结果。J2 重标零位也不等于扩大实际机械活动范围。

## 操作

- 七个滑条控制 J1–J7；对应轴高亮并随上游关节运动。
- 拖动画面改变视角，滚轮/双指缩放；斜视、侧视、正视和适配按钮可调整观察。
- 可关闭“末端外形”单独观察本体；此时保留虚拟 TCP 标记。
- 预设姿态使用同一套几何，切换预设仅自动适配镜头，不改变连杆长度。
- 四瓣头保持展开；没有夹爪开合、接触或硬件控制。

## 几何假设

世界 Z 向上，+X 为桌内方向。局部轴序为 `Z,Y,X,Y,Y,Z,X`；先平移至父坐标系中的轴心，再施加旋转。J2 几何旋转为 `显示角度−90°`，其他轴显示角度直接用于局部旋转。

| 项目 | A03 假设 |
|---|---|
| J1 / J2 轴心高度 | 65 / 150 mm，没有同步降低肩高 |
| 肩→肘 | 260 mm，J3 位于肩后90 mm |
| 肘→腕 J5/J6 | 轴向240 mm，输出沿肘局部Y错层60 mm |
| J5/J6 | 理想相交轴，用不同半径的示意环，不把两台实体电机重叠 |
| 腕心→J7 | 65 mm，沿 J7 轴线 |
| J7→头中心→TCP | 45 mm＋90 mm，沿头法线 |
| 标称轴向尺寸和 | 260＋240＋65＋45＋90＝700 mm |

错层使参考伸展姿态的肩至 TCP 空间距离约为702.57 mm；700 mm不是严格的最大可达半径。60 mm错层用于探索折返间隙，不是制造尺寸。关节壳体均为简化体，不代表厂商完整 CAD。

滑条探索角域：J1 ±150°、J2 ±110°、J3 ±160°、J4 ±165°、J5 ±175°、J6 ±110°、J7 ±160°。这些不是批准的机械限位；viewer不阻止穿桌、自碰或超出实际线束角域。竖直零位是参考定义，不表示最佳工作姿态。

| 预设 | J1→J7，度 | 头中心 XYZ，mm | TCP XYZ，mm |
|---|---|---|---|
| Z 字收拢 | 0,100,0,−150,140,−30,0 | 167.5,5,259.1 | 245.4,−40,259.1 |
| 抬起互动 | 0,75,0,−65,65,0,0 | 399.1,60,482.1 | 486.0,60,505.4 |
| 参考伸展 | 0,90,0,0,0,0,0 | 610,60,150 | 700,60,150 |

低位肘轴约为 `(256.1,0,104.9)`、腕心约为 `(72.2,60,259.1)` mm。上臂向桌内伸出，前臂沿 X 回退约184 mm，头部再向桌内，形成 Z 字关系。默认略侧头30°，用于观察下相机与前臂的避让，并未宣称通过完整碰撞检查。

若低位保持 J6=0°，下方相机可能进入前臂空间。侧头、调整腕偏置或优化头部包络均需比较。允许 J7 roll 时，还必须检查灯瓣对桌面及本体的扫掠，不能仅凭正放头部的下瓣净空判定安全。

## 验证与交付

2026-09-30：独立矩阵/平面公式复算低位与互动姿态；浏览器核对滑条、轴线、坐标、整头roll、镜头拖动及深浅背景。A02七轴组合的独立FK校核保留在历史提交，不能替代A03复核。

A03 最终片段实测：低位 TCP `(245,−40,259)`、互动 `(486,60,505)` mm，与上表四舍五入一致；参考伸展后将J2置0，TCP为 `(0,60,850)` mm且上臂竖直。J7改45°保持轴线上的TCP不变；J6改90°出现腕部退化提示。关闭末端外形后仍可见本体、转轴和虚拟TCP；适配按钮可完整显示竖直伸展姿态。

`arm-body-viewer.html` 是对话交互视图的 HTML 片段，小于1 MB，使用宿主提供的主题和基础控件样式。three.js r160 已内嵌，模型不请求远程资源。原始查看器代码按项目CC-BY-NC-4.0提供，内嵌three.js适用独立 [MIT许可证](THREE-LICENSE.txt)。来源为 `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js`，未修改引擎。

本地复核可用 visualize 技能的 `scripts/render.py` 包裹为临时预览，再通过仅绑定127.0.0.1的HTTP服务打开；输出放入忽略目录 `work/`，检查后停止服务。不要用 `file://` 做浏览器验证。
