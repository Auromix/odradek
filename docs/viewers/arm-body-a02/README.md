# A02 七轴构型交互查看器

对应 [A02 构型提案](../../arm-body-architecture-a02.md)，用于拖动七个关节、切换预设姿态、绕模型观察。它是独立的构型讨论工具，不是已选外观图或制造 CAD；不修改并行工作的底座设计。

`arm-body-viewer.html` 是对话交互视图的 HTML 片段。三维引擎 three.js r160 已内嵌，模型不请求远程资源；片段使用宿主提供的主题和基础控件样式。原始查看器代码按项目 CC-BY-NC-4.0 提供，内嵌 three.js 仍适用独立的 [MIT 许可证](THREE-LICENSE.txt)。来源为 `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js`，没有修改引擎。

## 操作

- 七个滑条分别控制 J1–J7；选中轴高亮，轴线随上游关节一起转动。
- 鼠标拖动画面改变观察方向，滚轮或双指缩放；可选斜视、侧视、正视。
- 低位收拢、抬起互动、参考伸展使用同一套几何。
- 四瓣头保持展开；本轮没有夹爪开合或接触模型。
- TCP 数值为桌面坐标，单位 mm；不是已验证的工作空间或承载能力。

## 可复核的示意几何

局部轴序为 `Z, Y, X, Y, X, Y, X`。世界 Z 向上，零位沿 +X 伸向桌内。每个关节先平移到父坐标系中的轴心，再按右手方向绕局部轴转动。转动轴 Y 为正时，局部 +X 向 −Z 转动。

| 项目 | 本轮假设 |
|---|---|
| J1 轴心 | 桌面上方 65 mm |
| J2 肩轴心 | 桌面上方 150 mm |
| 肩→肘 | 260 mm；J3 位于肩后 90 mm |
| 肘→腕 J6 | 240 mm；J5 位于肘后 90 mm |
| J6→J7 | 沿腕后局部 X 偏置 65 mm |
| J7→头中心 | 沿局部 X 偏置 45 mm |
| 头中心→TCP | 沿头部法线偏置 90 mm |
| 肩→TCP 零位展开长度 | 260＋240＋65＋45＋90＝700 mm |

关节壳体是简化体，非供应商 CAD，不代表表中候选电机的完整包络。滑条角域仅供探索：J1 ±150°、J2 −110～80°、J3 ±160°、J4 ±150°、J5 ±160°、J6 ±120°、J7 ±160°；不代表真实限位或允许动作范围。

| 预设 | J1→J7，度 | 头中心 XYZ，mm | TCP XYZ，mm |
|---|---|---|---|
| 低位收拢 | 0, −72, 0, 132, 0, −70, 0 | 308.7, 0, 208.5 | 397.3, 0, 224.2 |
| 抬起互动 | 0, −78, 0, 72, 0, −6, 0 | 400.3, 0, 452.3 | 488.4, 0, 471.0 |
| 参考伸展 | 0, 0, 0, 0, 0, 0, 0 | 610, 0, 150 | 700, 0, 150 |

两种互动姿态中，头中心提升约 244 mm。低位的肘部仍高约 397 mm，所以这是头部降低和前臂回收，尚不是全机贴桌收纳。后续应结合这个真实比例讨论肩高、连杆长度和轴线偏置。

## 验证记录

2026-09-30 在 localhost 预览中核对：

- 七个滑条的角度与界面同步；实际拖动 J7 改变整头姿态，鼠标拖动画面改变观察方向。
- 独立齐次矩阵计算与界面对照：角度 `[25,−60,35,100,−30,−50,45]`，TCP 计算为 `(241.631,426.200,296.776)` mm，界面显示 `(242,426,297)` mm。
- 上述姿态只把 J7 改为 −45°，轴线上的 TCP 数值不变；不是把 J7 错接为额外的俯仰轴。
- 低位与抬起预设的界面数值与上表一致；检查了深浅背景，以及宽屏和 390 px 窄屏布局。
- 片段小于 1 MB；无远程模型加载和硬件通信。宿主状态保存仅记录角度和视角，不发送执行命令。

未进行碰撞、扫掠体、热、强度、线束寿命或制造公差验证。TCP 标记沿法线设置，不能代表所有被抓物体的质心位置。

## 在 Codex 本地复核

用 visualize 技能附带的 `scripts/render.py` 将本片段包裹为临时预览文档，再用仅绑定 `127.0.0.1` 的 HTTP 服务打开。临时预览放入项目忽略的 `work/`，检查后停止服务。不要通过 `file://` 做浏览器验证。
