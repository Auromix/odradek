## 自由度和质量边界

广义坐标依次为 `q=[J1…J7, UR, UL, LL, LR]`，均为rad；后四项是指根转角。推杆的摆角和伸长由各自指角约束，不另算八个自由度。继承的角域只是研究输入，不是已经通过结构、线束或厂商限位审查的执行范围。

六段24个金属件使用名义6061均质实体积分；另有各段明确的紧固件质量/惯量代理。关节仍使用目录整模块质量、上游壳体归属及圆柱惯量代理，真实转子/减速器分配未辨识。头部采用13个聚合刚体，包含原J7适配件与EXT24，因而从旧模型移除 `head_budget` 和 `L7_budget=0.15kg`，避免重复。

当前运动链模型小计 **21.383620 kg**，包含固定J1、六段连接及其预算、2.802491 kg头部和2 kg净工件；**没有计固定底座，也没有计头部仍未明确运动归属的185～450 g余量**，不能称整机重量。未知转子惯量、摩擦和热不能因当前数组为零而视为不存在。

净工件暂刚性附着于头部TCP，home世界Z914 mm。该假设可用于臂轴的载荷计算，却没有求解四指与工件的接触闭环。后四轴输出是自由灯爪的自重/惯性需求，不包含夹紧物体所需的接触力；2 kg防滑抓取仍需要已有接触Jacobian、力分担、摩擦及实测另行整合。

## 推杆的解析关系

令 `D=0.123m`、`a=0.026m`、`u=q_f−68°`，各指的基端销在其根坐标 `A=(0,−0.018,−D)`，曲柄销在 `B=(a cos u,−0.018,a sin u)`，左右机械镜像按已冻结manifest处理。

```text
L(q_f) = sqrt(D² + a² + 2Da sin u)
β(q_f) = atan2(a cos u, D + a sin u)
dL/dq_f = Da cos u / L
dβ/dq_f = −a(D sin u + a) / L²
```

β从头部+Z向本指径向计角。case+guide绕基端销转过 `β(q)−β(0)`；slider+tip在同一转动基础上，再沿杆轴平移 `L(q)−L(0)`。它们不能刚性附着在夹指上。质量分配使用HEAD-MASS04的名义代理，每台87.917875 g本体、7.082125 g滑动件；比例未实测，源文件另给0～95 g移动质量的敏感性输入。

若 `t` 为基端摆动轴、`p` 为某COM，推杆本体对其指角的速度列是 `β' t×(p−A)`，角速度列为 `β't`。滑动组还要加上当前杆向乘 `L'`。四根指轴自身使用标准转动列 `a_f×(p−pivot)` 与 `a_f`。这些局部列经J7世界旋转变换，再与七个臂轴列合并。

推杆理想轴力与指根广义力矩满足虚功关系：

```text
τ_f = F_axial × dL/dq_f
F_axial = τ_f / (dL/dq_f)
τ_f q̇_f = F_axial L̇
```

本研究角域内 `dL/dq_f>0`。公式没有额外凭空加入减速器效率，也不把目录300 N当作任意电流、速度和20%占空条件下的持续力。施加夹持接触后，应将对应广义接触负载合并，再转换轴力。

## 质量矩阵、重力和速度项

对每个刚体，用世界COM、中央惯量 `I_world=R I_home Rᵀ` 以及11列线速度/角速度Jacobian求和：

```text
M(q) = Σ[m JvᵀJv + Jωᵀ I_world Jω] + 已知折算转子惯量
U(q) = −Σ m gᵀp
g_q(q) = ∂U/∂q = −Σ Jvᵀ m g
τ = M(q)q̈ + c(q,q̇) + g_q(q)
```

`c_i = Σ_jk [∂M_ij/∂q_k − ½ ∂M_jk/∂q_i] q̇_j q̇_k`。当前代码对M用中心差分构造速度项；没有将其称为符号解析动力学。模型保留7×4的臂/指交叉块，而不是把两套控制量完全解耦。

例如在inspect姿态，四指从全开变为上109°/下122°时，仅由当前模型质心变化，J4静重力补偿从23.263083变为23.371629 Nm，J6从−8.586694变为−8.695240 Nm。该对比不是连续开合过程的峰值，也没有加入未计量头部余量；完整矩阵和各指自重矩见JSON。

## 独立检查及结果

八组随机数学状态同时改变七臂轴、四指、速度和加速度，用于检查公式；未检查其全部结构可达性，**不得发送给实物执行**。历史reach姿态已有真实肩部碰撞，详见[整臂碰撞研究](integrated-collision-study.md)。

| 复核 | 最大差或最小值 | 方法与意义 |
|---|---:|---|
| 解析与数值Jacobian | 8.97×10⁻¹¹ | 直接对COM/旋转矩阵差分，不使用解析Jacobian求参考值 |
| 重力与势能梯度 | 1.46×10⁻⁸ Nm | 对独立标量U逐坐标差分 |
| M/C/G与直接刚体力矩 | 8.13×10⁻⁸ Nm | 沿二次时间轨迹直接差分COM和姿态，求各刚体牛顿/欧拉力矩；时间步0.2/0.1ms两档 |
| 动能一致性 | 4.62×10⁻¹¹ J | 数值速度/角速度逐体能量与½q̇ᵀMq̇比较 |
| 速度项能量恒等式 | 3.28×10⁻¹¹ W | q̇ᵀ(c−½Ṁq̇) |
| 推杆虚功 | 3.44×10⁻¹² W | 指力矩功率与直接差分长度所得轴力功率比较 |
| M最小特征值 | 1.17635×10⁻⁴ kg·m² | 八个样本均对称正定，非全域机械稳定性证书 |

以上微小数值误差反映算法一致，不代表同量级物理精度。独立刚体力矩检查使用同一输入质量/姿态函数，因此能发现Jacobian、坐标、速度项和量纲错误，但不能证明供应商惯量代理正确。

## 复现与后续输入

```sh

```

需要已生成的六段连接、HEAD-MASS04与原参数；依赖NumPy、SciPy、CadQuery。输入与脚本哈希写入JSON。该脚本只输出模型和数值证据，不生成控制指令。

下一步应把实际控制轨迹限制在经检查的结构/线束域内，明确真实惯量、完整头部质量分布、四指接触负载、摩擦/效率及加减速周期后，计算峰值、RMS、再生能量和热。数学关系通过不替代这些硬件选型条件。
