# A06｜ARX 方舟无限官方资料核验

访问日期：**2026-10-02**。本记录仅以 ARX 官方网站、官网链接的 GitHub 组织及其原始文件为证据；不把经销商、媒体转载或论文中的产品数字转录为原厂已核实规格。

## 结论

ARX X5 可以作为轻型 QDD 科研机械臂的构型和控制方式参考，但本轮可访问的官方材料**不足以验证“700 mm 肩至 TCP、2 kg 净工件另加灯瓣头”这一组合工况**。原厂 SDK 能确认 X5 的六个本体关节、独立夹爪控制以及附加末端质量需要纳入重力补偿；本轮未取得同代、明确试验条件的额定/峰值负载与臂展规格表。

不能因演示视频完成抓取或动作，就推出最大臂展下的持续负载、温升、偏心容许值或本项目七轴构型的承载能力。以下“未核实”仅表示本轮列明的公开材料没有提供相应口径，不表示厂家没有相关资料或产品不具备相应能力。

### 重力补偿的有效证据

[S2] 第 5 页、[S3] 的重力补偿与修改末端质量章节说明：默认末端质量参数只包含夹爪；增加摄像头等设备后，应调整末端 link6 的质量参数。

这支持本项目把灯瓣、显示、双相机、驱动与壳体计入末端附加质量。它**没有**说明某一公布负载数字是否排除夹爪，也没有证明增加该质量后仍满足原额定工况。质量参数可调不等于驱动、结构和散热能力随之提高。

### 官方模型能证实什么

[S4] 固定版本 `X5/X5A/urdf/X5A.urdf` 含 `joint1`–`joint6` 六个 revolute 关节，以及 `joint7`、`joint8` 两个夹爪 prismatic 关节。结合 SDK 的单夹爪控制入口，可避免把 URDF 中的八个非固定 joint 误称为八自由度机械臂。

该 URDF 文件名是 X5A，没有在文件中给出与 X5（2023）/X5（2025）的完整量产版本映射，因此本记录不把其惯性质量求和当作某代产品的原厂整机自重，不把 joint origin 的长度之和当作正式臂展，也不把其 effort/velocity/角度字段当作已验证的硬件极限。

## X5 Lite 与 X7 的范围说明

- **X5 Lite：**本轮检查官网产品年表和官方 GitHub 产品索引，未取得这个确切型号的官方原始规格。保留“型号待核”，不假定其等于 X5（2023）、X5（2025）、A5 或某一经销商套装。
- **X7：**[S1] 分别列出 2024-08-27 的 X7 和 2025-01-01 的 X7 2025；2024 X7 被描述为轮式双臂平台。它们不是本轮已核实的独立桌面单臂规格。官方还有 `X7s` SDK，但没有充分证据将 `X7s` 名称与上述网页两代全部一一对应，因此不拼接参数。
- **视频边界：**查看了官网 X5、X7、X7 2025 发布视频的抽帧；所见为运动/操作演示，未取得用于本项目对比的载荷规格页。没有从画面估算质量、臂展或测试时长。

## 对本项目的使用方式

1. 可以引用 ARX X5 说明“QDD、较轻量构型、外部计算机通过 CAN 运行控制 SDK”是已有公开产品方向。
2. 不可据本记录写“ARX 已证明同样尺寸可持续承载 2 kg，所以当前选型通过”。本项目是七轴本体，且灯瓣头的质量与重心不同；应使用自己的连杆、关节、线束和头部质量预算计算。
3. 对标负载需至少绑定：明确硬件代际、原装夹爪包含项、肩/基座至法兰/TCP定义、工件重心、姿态、速度/加速度、保持时长、环境温度及散热条件。现有官方公开材料中的缺项继续留空，待原厂规格或实测补齐。
