## 原点、安装面与设计选择

主参数 SHA-256 为 `4349d1797b906b67a7bc396fcb84bc439c2d70dd0b337659e552cee293d2dd81`。本研究未修改主 baseline、主 BOM 或旧总装。

J3 和 J4 均使用真实 RH20 原厂输出 PCD62 / 16×M3 以及固定 PCD84 / 8 个非均布通孔。输出孔以 0° 为相位，每 22.5° 一孔；固定孔角为 30°、60°、120°、150°、210°、240°、300°、330°。来源为 [MYACTUATOR RH 下载页](https://www.myactuator.com/downloads-rhseries) 的 RH20 3D A / 2D A 与已核对接口提取，原厂 STEP 的 SHA 在加载时验证，文件不公开分发。

2. LOW从+Z套住输出螺钉头，4×M4×16固定。

## 几何和可装配性证据

名义静态检查含真实原厂J2/J3/J4/J5、既有L23三件和28个螺钉。逐solid Boolean交集门槛为1e−4mm³；AABB只作可证明的排除。40个螺钉用完整已选杆长或明确限定的OEM已知自由段建模，只对其对应原创螺纹拥有者排除预期啮合，其余外壳穿透仍报告。

最终通过225组原创件静态配对、2420组硬件配对、2400组工具进入和2400组已知螺钉形状连续插入检查，均无超过1e−4mm³的非预期交体积；7个预期承力接触面均具有正的实际平面接触面积。J4连续插入对70个已装对象检查，六原创件连续插入分别对33/50/55/60/65/71个对象检查，q3旋转包络对32个上游对象检查；所有原始结果逐条保留，不把包络的零相交当作全机械臂认证。

工具直杆为Ø4/M3、Ø5/M4、长60，按装配阶段检查。每个螺钉的已知形状另建立60mm连续轴向插入包络，并检查该阶段已安装的其他螺钉；没有建模手或扳手柄。

J4的47个原厂solid先用Boolean差验证包含关系，再用两个圆柱的并集覆盖局部+Z / 世界−Y的0～160mm连续插入。六个原创件也先检查各自被保守包络包含，再检查覆盖完整平移的棱柱/胶囊体包络；OUT/LOW/TUBE/UP/CARRIER/FRONT的范围分别为100/40/110/40/100/120mm，并保留最大5mm间距的离散站点记录。包络只允许扩大实体，不能缩小以绕过碰撞；前环保留沿插入轴不变的原装帽头避让孔，防止把真实空孔错误填实。

新增q3相对上游接口的连续证明：输出板、16个输出螺钉已知段和4个LOW螺钉完全包含在世界轴[0,55,Z]、R48、Z217～242的旋转不变圆柱中。该圆柱与J2每个原厂solid及L23三件/28螺钉分别无体积相交。余下L34零件和螺钉的Z下界228，高于上游所有被检件最高Z226；绕Z转动保持该分离。故本连接六件和40个已知螺钉形状相对J2/L23在q3完整一周连续避让；仍未证明OEM关节内部转子、线束、其他上游结构和全臂运动。

这些证据证明指定装配顺序中的名义几何可行，不包括制造公差、完整手柄、线缆、其他关节运动全行程或同样零件在任意装配顺序下都可用。

## 质量、惯量与载荷

六件金属CAD估重 **1.054990566 kg**，加权COM为世界 `[约0,51.975380167,306.432547474] mm`；另加0.15kg紧固件代理，合计1.204990566kg。全部六件归属 **preceding_joints=3**。质量和惯量按6061均质材料、密度2.70g/cm³对含底孔与避让的名义CAD积分；不是称重。未建螺旋牙型和全部工艺倒角，因此保留小数仅为复算。每件记录世界和零件局部COM、关于质心的完整惯量张量，单位kg·m²，并检查张量正定、对称和平移不变性。

本轮替换L1/L2/L3/L5/L6预算，分别使用实际L12/L23/L34/L56/L67的金属质量，加0.20/0.15/0.15/0.10/0.10kg紧固件代理；代理均位于对应金属加权COM。关节模块仍采用目录质量、外形中点COM、整模块归属上游壳体；实际厂商COM和转子分配尚未获得，其余梁和头部仍有预算。

载荷计算2/3.5/4/4.5kg完整头和2kg净工件；沿用旧face780、TCP890、头COM760，**没有采用根线程另行研究的24mm头部延伸**，若采纳必须重算。头COM偏移50mm和工件COM偏移100mm以重力矩范数增量计入，再乘1.5研究倍率；这不是规范认证的安全系数。

对附着于J3的截面点P，下游pre≥3质点按 `mg×(|P−J4|+…+|Jn−COM|)` 给出三维重力矩模三角界；pre=3则用 `mg×|P−COM|`。脚本另以200个姿态的独立正运动学和直接三维重力矩检查该界。中心化螺栓组等刚度模型用721个力矩方向复核反力守恒。为使截面筛查载荷不偏小，各截面统一保留全部pre≥3质量，包括位于某些切面近端的本连接零件；这不是每个真实切面的精确自由体载荷。

梁弯曲使用含侧孔的实际净截面，考虑矩方向任意变化；挠度假定长92mm的理想固支梁。无孔均匀段另用闭口薄壁Bredt公式给出扭转剪应力和92mm参考扭转角，内外角的中线面积、周长和t=3均记录在JSON中；**这不适用于有孔端部、插头接触和侧螺钉载荷分配**。组合应力将矩模同时用于弯曲和扭转，是中央均匀段的敏感性计算，不代替真实端部接触模型。

输出板使用沿四角方向、宽16mm的实际BREP净截面条带，假定在原厂支承外缘r34.7完美固支。后环从脚根至轴线的实际截面（含下方固定孔中心截面）用于直梁等效敏感性。两者都不是整个零件的保守强度界；接触环柔度、预紧、抬离、侧孔承压、螺纹剥离、孔边集中与疲劳仍需接触FEA和实测。

  --rh25-step '/local/vendor/RH-25-100-E-B-D 3D-A0.STEP' \

需要CadQuery、NumPy、trimesh、ezdxf、ReportLab、pypdf以及既有候选的稳定接口/质量文件。生成器检查主参数及原厂STEP的hash，禁止将带原厂CAD的装配写到仓库内；公开输出只含原创件。STEP和STL逐件重读，DXF进行审计；图形投影不是数控刀路。

一般线性±0.10、孔中心±0.05、接触平面度0.05、螺纹6H仅为候选建议，插头/内腔有上文单独的匹配尺寸约束。PLA/PETG只用于手动无载试装：板和环平放、插头沿Z、梁竖直、后环脚朝床并加支撑；关节必须另用外部托架承重。

制造和带载前仍需：原厂输出M3有效牙起止/允许伸入和最终全长、固定法兰夹持许可、预紧/防松/剥离验证、材料和表面工艺、公差链与刀具评审、完整接触FEA、侧螺钉与插头承载、疲劳、轨迹惯性/急停载荷、全关节行程碰撞与内走线验证。不能用某个条带低于屈服或名义无碰撞来宣布2kg任务通过。
