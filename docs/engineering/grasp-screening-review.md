# 抓取线性规划独立审查

审查版本：**R4-layout-03**。范围包括点接触受力符号、16射线摩擦锥、指根力矩约束、八块楔面在名义80 mm型面姿态的法向，以及全部72个场景的重算。本轮还验证了法向输入复制/归一化、二级最小峰值、每个名义接触至少2 N和显式零自重/惯性/摩擦力矩偏置。没有修改共享实现。

结论：**当前 LP 的核心静力符号和锥约束正确；其可行性是给定接触几何、摩擦、工件 COM 和可用关节力矩下的条件结论。** 它不是实物抓取、力闭合或 2 kg 额定能力的证明。

## 1. 核心约束复核

把 fᵢ 定义为手指作用于工件的力，pᵢ 为接触点，c 为工件 COM，则工件平衡为：

$$\sum_i f_i+F_{ext}=0,\qquad\sum_i(p_i-c)\times f_i+M_{ext}=0.$$

因此 `G = [I; skew(p−c)]`，`G f = −wrench` 的符号正确。手指受到反力 −fᵢ，若 Jᵢ=∂pᵢ/∂qᵢ，则忽略其他手指力矩时执行器静力平衡为 τᵢ=Jᵢᵀ fᵢ。代码的 Q 与 `[Q; −Q] λ ≤ cap` 正确约束了双向指根广义输出力矩。

令单位内向法向为 n、与之正交的两个单位切向为 t₁/t₂，每条射线取 n+μ(cosθ t₁+sinθ t₂)，系数 λ≥0。合成法向力 N=Σλ；由三角不等式可得 ||fₜ||≤μN。16 条等角射线的非负锥确实位于圆形 Coulomb 锥内，不能产生拉力接触。它是保守内近似：LP 不可行不自动证明真实圆锥或其他接触位置不可行。

`min Σλ` 是最小总法向力目标，不是最小峰值关节力矩。同一最优总法向力可能有多种分配，求解器碰到某一轴上限不代表上限是不可降低的最优峰值。可在保持总法向最优值容差的约束下，引入变量 t、`−t ≤ Qλ + bias ≤ t` 做二级最小峰值；该二级结果仍须重新检查原平衡、锥和 cap 约束。

## 2. 新同高接触例子的独立构造

给定 R70 mm、目标半径40 mm、名义接触面偏置 h11 mm、上根 z0 / 下根 z50 mm，指定四个接触中心都在 z110 mm。由二维刚体关系得到：

| 参数 | 上指 | 下指 |
|---|---:|---:|
| 接触沿片位置 s | 113.485681916 mm | 66.174013026 mm |
| 对应闭合角 q | 99.718818063° | 107.127163122° |
| 固定接触垫法向补偿 β=q−90° | 9.718818063° | 17.127163122° |

独立检查得到 r=40 mm、z=110 mm，接触位置 Jacobian 与中央有限差分的差小于 10⁻⁹ m/rad。局部楔面法向必须由 e_z 朝 +e_r 倾 β：转动后 `n(q)=−sin(q−β)e_r+cos(q−β)e_z`。只在该例目标角上它才等于 −e_r；换物体直径/姿态后不能继续无条件写成径向法向。

对质量2 kg、载荷系数2、重力朝头部 −z、COM=(0,0,110 mm)，存在如下显式左右对称平衡解。各指竖向摩擦取 μN；上/下法向力比由 φ=35°/45° 的力平衡决定。表内力矩未包含指片自重、惯性、摩擦或传动损失。

| μ | 每个上指法向力 / N | 每个下指法向力 / N | 每个上指输出 τ / N·m | 每个下指输出 τ / N·m |
|---:|---:|---:|---:|---:|
| 0.3 | 36.0971322 | 29.2805344 | 3.6458104 | 1.4933073 |
| 0.4 | 27.0728492 | 21.9604008 | 2.6531392 | 1.0540992 |
| 0.6 | 18.0485661 | 14.6402672 | 1.6604681 | 0.6148912 |

所有力/矩残差小于 10⁻¹⁰（对应 N / N·m 数值），且这三组都在给定 3.7 N·m 上限内。μ=0.3 的上指约3.6458 N·m，距离目录上限只有约0.0542 N·m，不能称为已有实用余量。μ=0.4 的显式对称方案上指峰值约2.6531 N·m；若仅最小总法向力 LP 返回3.7 N·m 的某个非对称解，不应误报为此任务必需3.7 N·m。

这里每指两块实际垫被合并为单接触点，接触中心和法向是否真的落在 名义80 mm 物体上必须从实物型面/软垫变形证明；两个离中心的平垫对圆柱不自动等价于一个中心切点。

## 3. 全部场景的独立复算

使用报告中三维点位、Jacobian和工件COM，独立搭建力/矩平衡与16射线锥，再求解全部72组参数：**54组可行、18组不可行，均与报告一致**。对54组可行解另外重解保留总法向最优值的二级最小峰值，结果全部一致。每个名义指接触均满足2 N下限；它不是每块实际软垫都保证2 N。

| 全部可行结果的最坏数值 | 结果 |
|---|---:|
| 力平衡残差 | 1.102×10⁻¹³ N |
| 关于工件COM的力矩平衡残差 | 5.688×10⁻¹⁰ N·m |
| 法向力报告与力向量投影的差 | 7.106×10⁻¹⁵ N |
| 真实圆形Coulomb锥超限量 | 1.777×10⁻¹⁵ N，浮点量级 |
| 指根力矩cap超限 | 0 |
| 2 N法向下限超限量 | 2.221×10⁻¹⁶ N，浮点量级 |
| 总法向力相对一级最优的最大增加 | 1.000000154×10⁻⁷ N，符合所设二级容差 |
| 独立二级最优峰值与报告峰值差 | 9.770×10⁻¹⁵ N·m |

射线权重没有保存在公开报告中；本次独立重解确认同一内锥的可行性，另外从报告的最终力向量直接检查圆锥、力矩及平衡。浮点残差接近零不等于形式验证；上述数值是当前求解器快照的复核证据。

## 4. 已修复审计项与仍有的模型边界

| 前次审计项 | 当前核验 |
|---|---|
| 非单位NumPy法向会被原地修改，Python list会产生错误摩擦诊断 | **已修复**：入口复制并统一归一化。两倍法向的数组/list结果一致，调用者数组逐元素保持不变，真实摩擦锥检查通过 |
| `motor_equilibrium_Nm` 易被误认为裸电机轴转矩 | **已修复**：输出为 `finger_joint_equilibrium_Nm`，含义是指根输出广义力矩 |
| 最小总法向可能返回非最小峰值分配 | **已修复**：追加二级峰值目标，并保留一级最优总法向+10⁻⁷ N约束；54组重算一致 |
| 允许某个名义接触完全不出力 | 当前主场景显式使用 **minimum_normal_N=2**，全部可行结果满足；回归用例仍可单独选择0下限 |
| 法向/摩擦/预载等输入无检查 | 已验证负μ、负预载、少于4条射线、零/NaN法向均拒绝；闭合角还核对了物理研究区间及 pad_target_q |
| 手指自重等偏置被隐含忽略 | **已明确** `finger_self_weight_inertia_friction_torque_bias_Nm=[0,0,0,0]`；这是模型假设，不是证明真实偏置为零 |

实际仍需 `τ_drive=Jᵀf+τ_finger_gravity+τ_inertia+τ_friction`，再核对传动、热与供电。代码目前只是明确记录零bias，不是已经实现任意非零bias工况的模型。3.7 N·m仍是齿轮目录边界，不能全部视为实机可用夹持能力。

当前四个名义接触中心均在 z110 mm，属于**共面**例子。前次审计指出的“four noncoplanar contact heights”旧版措辞已修复；代码及报告均已明确三维接触点按实际位置计入，而本例名义接触共面。措辞修改后再次独立重算，72 组结果和残差不变。

工件COM仍是假设值，不是由未知物体自动确定。每指两垫的对称分力可在理想条件下等效于中点力，但真实两点是否同时接触、软垫压缩与受力分配没有验证。楔面在指定目标角才具有径向法向；当前证明只对指定型面，不能外推到任意圆柱或其他直径。单一重力场景可行也不等于完整力闭合、接触损失鲁棒性或失电保持。

建议后续在报告中显式记录一/二级求解状态与目标容差，并在代码内自动执行与本审查相同的最终物理残差检查；目前虽然二级失败会回退一级解，本次54组的二级都已独立验证成功。
