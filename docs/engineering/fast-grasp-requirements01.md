# FAST-GRASP01：发光面夹持与一秒空载开合

用户明确：**正常夹持是灯片的主功能，灯片发光面本身就是夹持面；快速张合属于附加能力，但空载全闭→全开→全闭须不超过1秒。** 接触物体后转入限力夹持，不要求带物体完成空载全行程。此确认替换“选低速间歇推杆还是连续呼吸”的旧需求理解。

## 确认输入与设计判据

| 项目 | 当前要求 | 对工程设计的约束 |
|---|---|---|
| 夹持功能 | 2kg工件净重，末端自重另计 | 驱动须满足持续夹持，而非只达到瞬间峰值力矩；对象尺寸、摩擦与外部加速场景必须列明 |
| 抓取接触面 | 发光灯片面本身作为夹持面 | 透光接触表层和承力基体共同设计，不能只用独立尖端小垫替代整个面。LED/PCB不作为主载荷路径 |
| 速度 | 空载完整往返≤1.0s | 从静止全闭开始，经全开再回到全闭静止；先按每程0.5s分配，无额外停留，曲线必须满足速度、加速度、驱动能力和碰撞约束 |
| 接触动作 | 接触后限力夹持 | 快速空载轨迹遇到物体时退出位置快移并受控减速；检测延迟、允许接触冲击与力限制待计算/验证，不能由电流设定直接声称指面力已知 |
| 自由度/外形 | 四瓣可单电机联动，上长下短、左右镜像 | 用户取消四个独立驱动的要求，允许1主驱动＋3瓣mimic。保留参考图的折线肩部、宽灯面与截短端部，避免纯三角片与周边突出电机。原109°/122°只作历史角域起算 |
| 主体与接口 | 7轴本体、约700mm、EtherCAT、双GMSL/GMSL2、内走线、外置计算 | 新指驱动供电、通信节点数、重量和转动惯量必须重新并入主臂与线束，不能沿用旧8从站/P16电源预算 |

“≤1秒”描述完整往返能力；持续每秒循环的占空、次数和热稳态尚未指定。正常持物时不能为了灯光或呼吸表达主动改变夹持力。表达可使用LED亮度变化或空载动作。

## 当前路线处置

P16-50-256-12-P分支的现机构单程约17.5～19秒，无法满足新要求，**停止作为主末端驱动路线推进**。其CAD、数学和电气记录留作历史比较；不继续把其低速演示作为目标能力。既有七轴本体、相机、中央屏和灯板可以作为下一轮的输入，但可复用性需结合新发光承力面确认。

| 已有成果 | 下一轮用途 |
|---|---|
| P16/HEAD03/HEAD04、DRV8874四路控制及12V电源研究 | 历史分支；不可作为一秒末端采购或运行配置 |
| HEAD-MASS04指片几何积分与独立角域计算 | 提供初始指片惯量/姿态，剔除P16机构及将改动的承力面后重新计算 |
| FPL01灯板、CD-PCB01中央屏及可拆杯座 | 可复用电子/安装候选；FPL是否继续保留需看接触层厚度、承力/散热及闭合关系 |
| 七轴关节/实体连接、肩部加强候选 | 本体结构研究继续；新头重、质心与反力确定后重算，旧载荷结果不自动成为新头的资格证据 |

下一轮按“保留外形的发光承力面 → 单驱动四瓣联动和接触顺应 → 一秒往返运动/夹持需求 → 中央隐藏伺服与传动 → 四瓣总装”推进。选择时同时校核持续零速扭矩、速度—扭矩能力、编码器、失电行为、反射惯量及电热限制；不以最大空载转速和堵转扭矩拼成不存在的工作点。

发光面方案至少应明确透光可更换接触层、支承跨度、主受力骨架、光学腔、LED/PCB防压空间及受压后的闭合间隙。接触层的摩擦、磨损、污染、透过率及局部温升需实测。四瓣单驱动不能独立分配四个夹持力；抓持模型要处理接触点分配、摩擦锥和物体力矩平衡，并使用适当顺应/差动，避免第一瓣接触后锁死其余接触。

上下瓣的mimic关系可由机构实现，不预设1:1角度。四连杆/凸轮约束可能非线性；URDF的线性mimic不能替代真实运动学。当前保留4个可见瓣关节，首选1个主动广义坐标，不再把旧“4DOF末端”当作强制输入。

本体与末端分开开发，风格保持协调。本体仍以2kg净物体和约700mm为目标，末端自重不作零处理；接口分别给末端质量、质心、惯量与外载荷。工程上暂以整头≤1.5kg作为轻量化争取目标，尚非用户确认的重量规格，也不是已实现值。

此页为确认后的设计输入，不是新驱动已选完、1秒硬件已实现或制造发布。
