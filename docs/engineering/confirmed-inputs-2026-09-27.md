# 2026-09-27 用户确认的载荷、臂展和相机接口

用户在设计任务中明确确认以下输入。载荷、臂展和相机接口取代初期研究中的 A01、A02、A04 待确认状态；随后确认的一秒开合与发光面夹持触发末端驱动重选。旧计算快照及其哈希保留，用于复现历史结果。

| 输入 | 已确认需求 | 工程解释 |
|---|---|---|
| 末端负载 | **2 kg 工件净重，另计末端模块自重** | 腕部、肩部和抓持计算须同时计入工件及可拆头；不能把 2 kg 当作头部加工件的总质量。当前计算采用相同口径，无需仅因本次确认改变数值 |
| 臂展 | **约 700 mm**，按提问中肩关节到工具中心的尺度理解 | 这是近似设计目标。当前抬升布局肩关节到 TCP 的零姿态距离约746mm；零姿态距离不是全姿态最大伸展或无碰撞工作空间。工作空间、公差及最终几何仍需核验 |
| 相机接口 | **GMSL／GMSL2 同轴接口** | 原“gxxx”的含义已明确。两路鱼眼视频通过各自同轴链到外置采集/计算端，独立于 EtherCAT 运动总线 |
| 灯片功能 | **发光面本身就是夹持面，正常夹持为主功能** | 透光接触层、承力骨架与LED/PCB隔离共同设计，不能以独立尖端小垫替代全部面接触 |
| 空载速度 | **全闭→全开→全闭，总计≤1秒** | 用户确认该工况；接触物体后转限力夹持。P16历史方案不能满足，见[FAST-GRASP01](fast-grasp-requirements01.md) |

此确认没有指定具体相机、串行器/解串器型号、线束料号或接口代际混用方案。现阶段 `ZED-414012`、ZED Link Duo 和 PoC 链仍为需完整配套验证的候选；确认接口类别不等于相机、线束、穿轴、弯扭寿命或实时性能已经合格。

机器可读输入见 [confirmed-inputs.json](../../engineering/parameters/confirmed-inputs.json)。该文件只记录需求，不替换旧几何参数或自动改变任何关节角域、负载额定和制造状态。新研究引用本记录；旧文稿中“gxxx尚未确认”“2kg口径待确认”“约700mm为工作假设”等表述只描述其原始研究时点，以本记录和[当前基线](current-baseline.md)为准。

仍待任务层输入的项目包括本体速度/加速度、连续循环占空、精度和重复定位要求、工作对象形状/摩擦。空载单次往返时间已经确认，不能再将其列为未知；P16已退出主驱动路线。
