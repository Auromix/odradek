# CD-MOUNT01 独立几何审查

2026-09-27。审查最终 `MOUNT_X=35.25mm`、带背面 GH12 参考体的 CD-MOUNT01。**未发现阻止进入空载装配样件的名义几何问题**：PCB、光学叠层及两耳紧固路径有真实接触，全开姿态下的工具空间探针和分步前拆扫掠无穿透。未修改主脚本、总装或参数；这不是制造放行。[独立数据、源哈希与可提取复算脚本](../../engineering/generated/central-display-mount01/independent-review.json)记录全部检查。[硬件来源](hardware/central-display-hardware01.md)单独维护精确料号与原厂尺寸。

| PCB → 绝缘圈 | −2 | 256.856615 |

紧固件压缩链为螺钉头—前垫—前压框耳—cup 耳—后框—后垫—螺母。cup 圆筒底缘为 R30.1…32，后框主体为 R32.5…38，两圆环互不接触；**真正承载到后框的是左右耳**，不可把整个圆筒底周长计入支承。

PCB 座为 R28…30，有连续支承。绝缘圈和窗口的受压接触环为 R28.5…29.9。光学叠层与 cup/前框硬限位在名义尺寸下同时合拢，但制造误差可能把夹紧力分配到其中一条路径；需后续决定软垫、叠层公差或可控压缩量。当前上侧绝缘圈并不隔离 PCB 背面与座的接触：若 cup 采用导电材料，PCB 的 R28…30 支承环需禁露铜/过孔，或另设实际绝缘结构。材料尚未确定，不据此否定几何候选。

两孔移至 X±35.25、Y0，中心距70.5。最大Ø5后垫片的整个偏心圆足印径向范围为 `35.25±2.5 = 32.75…37.75`，因此对后框 R32.5…38 内外缘各有 **0.25mm 名义余量**，不限于某个剖面。旧四根 X±35/Y±22 光学柱不变；0.25mm不是已分配的制造公差。

## 可装拆范围

对 HEAD03 全开姿态的全部 named solids 加本次 CD 共995件逐对象、逐 solid 检查。17个空间/扫掠检查共16,291个对象对，AABB排除后336个布尔检查，穿透体积阈值为 `1e−4mm³`，结果为零；名义接触允许存在。

- 前方Ø3、长60的圆柱工具轴空间无穿透；未包含手柄、真实批头或外观壳体。
- 螺母从后方装入的六角扫掠，以及包含其全部转角的外接圆环扫掠均无穿透。螺纹按名义包络处理，实际旋合/防松与末端有效牙未认证。
- 完整 M2×20 螺杆和头部向前抽出60mm无穿透；随后依次取出前压框、窗口、绝缘圈、PCB，及随 PCB 一起移动的 GH12 参考体，各自连续向前60mm扫掠无穿透。每步只排除已拆零件，不把尚在位零件一并隐藏。

样件操作顺序：全开、断电、无载；**先解锁 GH、断开并释放导线固持**，再从背面取螺母/后垫、向前抽螺钉/前垫，按上述顺序取光学叠层和 PCB。安装反序进行，并在头部最终封装前从背面接线与检查。已证的是实体移动空间；GH锁扣按压、完整拔出行程、导线及其固持均未建模。若在位无法触及 GH，须把整个光学架作为台架维护子装配，其拆卸路线需要另核，不能把本次 PCB 的60mm前拆证明转用到整架。不能带着未释放的线束强拉 PCB。

## 连续证明审查

旋转件采用其各 AABB 角点到单位转轴的最大垂距，正确包住整个实体的旋转速度；角度转为弧度。对区间端点距离使用 `min(d端点)−V·区间角宽/2`，源于距离对 Hausdorff 位移的 Lipschitz 界，数学形式成立，不是把离散采样直接当连续结论。

P16 中 `L²=D²+a²+2Da·sin(q−68°)`，q范围0…122°使余弦为正，故 Lmin位于q0，等于99.371686mm。Lmax=144.842924mm；最大伸长时全部原生包络 AABB 角点离基点不超过149.084925mm，小于采用的160mm。`|L′|≤26`、`|β′|≤26·149/Lmin²`，得到88.770311mm/rad，当前速度界充分。

本轮独立审查公式、包含体及源文件；未重复执行主脚本全部运动距离计算。最终主报告中上指0…109°、下指0…122°对显示模块的连续下界均为正：上指旋转件17.781620mm、P16为39.706073mm；下指旋转件44.699331mm、P16为30.670274mm。新耳盒需到X±38.25；根脚本已同步，GH参考体亦包含其中。旧光学框仅减去两孔，其运动空间继承 HEAD03 原证明。范围仅是显示件对相关手指/推杆，不扩大整臂或任意维护姿态许可。

## Ø60圆PCB背面静态建议

R28、Z−10…−3 空间足以容纳 GH12 与两颗 LP5860 的**静态器件包络**：

| 对象 | 建议位置或包络，head mm | 余量 |
|---|---|---|
| GH12既定参考体 | X±9.475，Y−19.8…−11.05，Z−7.45…−3 | 最大半径21.950299，距R28为6.049701；后方Z余量2.55 |
| 两颗LP5860 | 中心(−10,+5)、(+10,+5)，每颗6×6，Z−4.1…−3 | 最大半径15.264338，径向余量12.735662；与GH体最近13.05 |
| 每颗驱动周边暂留区 | 中心不变，各10×10 XY | 最大半径18.027756，径向余量9.972244；与GH体最近11.05 |

LP5860 官方 RKP0040B 图给本体4.9…5.1方、1mm最大高；推荐焊盘外界5.4方。6mm方与额外0.1mm高是本次规划余量，10mm方仅用于排布周边元件，均不代表已布线的电路。原厂第51页要求近端去耦、电源回路和焊接散热焊盘，须在实际 PCB 中落实。[TI 数据手册，第51、58–59页](https://www.ti.com/lit/ds/symlink/lp5860.pdf)

保持 GH 的背装刚体变换与 pin1 契约，出线−Y；R28…30留作机械支承环。圆PCB当前无机械角向键，样件装配需明确 GH 朝向；正向定位特征或摩擦夹持能力可在样件后收敛。导线折弯、完整无源器件/铜层、热与供电预算仍需电气布局验证，不影响这里的静态放置结论。
