# 当前集成基线与硬件选择

本页汇总正在继续推进的 **SHOULDER-RAISE01 + HEAD-INTEGRATED03 + FPL01 + HEAD-CTRL02** 条件分支，避免把历史方案的尺寸、数量和接口叠加使用。各项仍是工程候选；完整采购表、带载资格和制造发布尚未完成。新研究只有在明确集成后才改变这里的整机基线。

## 接口和数量口径

当前P16分支是 `外部主站 → J1…J7 → HEAD-DC`，共 **8个EtherCAT从站**。四路H桥由同一头部控制器驱动。旧BLDC分支的4个独立指伺服和12站拓扑是替代路线，不与本分支共存。

RH的B闸从模块自身DC口取电，未增加独立24V抱闸母线；J7 N无闸。相机两路GMSL2均有自己的PoC路径。HEAD-CTRL02的三路外置台测输入为12V电机、3.3V逻辑与3.3V LED，属于电路验证接口；通过整条机械臂输送低压大电流的压降、线规与板端稳压尚未设计完成，不能照台测接口直接制作整机线束。

四灯片FPL01电流与功率按它们自己的130/42映射计算，基线2.264W含各自规划逻辑开销。CD-EC01中央285点的平均VLED预算0.51818A、规划功耗1.810W；二者合计4.074W，不含控制器、电机与相机，满20mA灯点仍需热验证。旧HLIO01的609点总功率、旧12站框图和24→5→3.3V电源候选不再代表这条支线的完整已设计电路。

## 历史与下一次集成

[初期主BOM](hardware/bom.csv)保留各种驱动/传动分支及早期未定尺寸，用于追溯，不能把其中所有行求和采购。当前细项分别由FPL01、HEAD-CTRL02、光学台架与单轴台架的原生BOM管理。材料、紧固件、线束和电源的整机汇总需在这些分支收敛后再生成。

下一次集成须同时更新实体、质量/惯量、孔和安装路径、数学模型、碰撞依据、Blender与图纸。只有独立通过的局部候选不能自行扩大整机可执行角域。制造发布仍需关键供应商接口、选材/公差、预紧、结构与热分析，以及相应实物验证。
