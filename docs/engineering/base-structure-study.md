## 静重力与结构手算

输入仍是2 kg净工件 +2 kg末端本体；手臂点质量模型总质量19.17 kg（包含固定J1及工件）。本次原创底座零件按2700 kg/m³估算约4.25965 kg；紧固件/线缆再留0.5 kg显式预算。底座固定质量不加入关节下游负载，不能写回驱动重力预算。桌面垂向载荷则计入这些质量。

### 基座倾覆界与载荷不确定性

肩关节的55.944741 N·m是J2轴向重力矩三角界，不能原样称为基座轴承倾覆上界。J2壳体属于J1下游、J2上游，当前质量2.74 kg，COM代理在J1轴线外50.6 mm，额外界为：

`ΔM = 2.74 × 9.80665 × 0.0506 = 1.359633 N·m`。

J1、L1的当前COM在竖直基轴上；J2原点位于同一竖直线上。对于J2下游COM，其水平距离不大于自J2起算的几何路径长度，故可以将肩三角界作为其**水平力矩向量模长**的上界，再加上述上游偏心项：

`M_base ≤ 55.944741 +1.359633 = 57.304374 N·m`。

5001个配置的独立Rodrigues变换和直接 `Σ r×mg` 求和均不超过此界；最大采样模长48.397246 N·m只是样本结果。`q=[0,90,0,0,0,0,0]°` 的基座力矩向量为 `[-1.875090,47.003489,0] N·m`。这些配置尚未全部通过实体与线束可达性验证，不能作为已获准运行范围。

本轮增加以下**指定**预算：2 kg工件COM任意方向偏移100 mm带来1.961330 N·m；末端质量增加0.2 kg带来1.346525 N·m路径界；按增重后的2.2 kg末端COM偏移50 mm带来1.078732 N·m。总计61.690961 N·m，乘临时研究倍率1.5得到 **92.536442 N·m**。这不是认证安全系数，也不能覆盖未定义的接触力、急停惯量、碰撞、J1偏航扭矩、电缆拖曳、所有其他零件COM偏差或实际质量增长。

垂向预算按 `1.5×g×(19.17+0.2+4.259646+0.5)=354.9465 N`。为使简化反力筛查偏保守，四柱及M4计算也使用全部底座重量；真实位于柱下方的底板/背板不会通过柱向上传力。

### 连接组与支柱

对于四个相同刚度、同一平面、以 `(±a,±a)` 布置的连接，`Σx²=Σy²=4a²`，附加轴向反力：

`F_i = (Mx·y_i − My·x_i)/(4a²)`。

将力矩方向遍历721个角度，合力矩重构误差小于 `3×10⁻¹¹ N·mm`。接触翘起、连接刚度不同、孔隙滑动会使分配改变，以下不是单个螺钉的保证最大载荷。

| 筛查量 | 公式或条件 | 结果 |
|---|---|---:|
| 四柱最大绝对轴向力 | N/4 + M/(2r)，r=65 mm | 800.56 N |
| 8个M4最大外加轴向力 | N/8 + M/(4×51)，真实孔阵Σx²=Σy²=10404 mm² | 497.98 N |
| 四桌面锚最大拉力，未减重力 | M×√(110²+110²)/(4×110²) | 297.42 N |
| 不依赖四锚均分的单锚敏感性 | 全M由一锚与110 mm假设压反力臂平衡 | 841.24 N |
| M6仅外载拉应力 | 800.56/20.1 mm² | 39.83 MPa |
| M4仅外载拉应力 | 497.98/8.78 mm² | 56.72 MPa |

螺纹拉应力面积20.1/8.78 mm²按公制粗牙标准近似；这两项**未叠加预紧力**，不构成螺栓强度或螺纹连接合格结论。841.24 N也不是所有柔性桌板工况的严格上界：若撬力增加或压区迁移令力臂不足110 mm，锚固力会更大。

支柱采用截面扣除M6大径圆孔的面积和惯性矩：`A=24²−π×3²`，`I=24⁴/12−π×3⁴/4`。将实际上下支撑区形心的偏心绝对值相加，计算 `σ=P/A +P·e·12/I`；接触面积、形心和结果见[evidence.json](../../engineering/generated/base-study/evidence.json)。这只筛查名义轴压/弯曲量级，不包括预紧/局部孔边应力。柱长细比约4.72，属于短粗柱，Euler公式会给出不适用的极高值；脚本仅记录诊断值并明确禁止拿它当允许压载。

### 底板、背板与桌面

以每个支柱沿对角线到外锚的24 mm宽、16 mm厚、90.5635 mm长条带作悬臂敏感性估计，取上表800.56 N：

`σ = 6PL/(b·t²) = 70.80 MPa`；

`δ = PL³/(3EI)，I=b·t³/12，E=70000 MPa → 0.346 mm`。

这不是有严格保守性的板壳上界：24 mm有效宽度没有接触/有限元证据，开孔、柱底沉孔、双向板效应、锚点撬力和桌面柔度均会改变结果。背板依赖实际桌板接触来扩散压力，不能仅凭厚8和覆盖260方形就承诺抗拔通过。

材料一手参考为 [thyssenkrupp EN AW-6061数据表](https://ucpcdn.thyssenkrupp.com/_legacy/UCPthyssenkruppBAMXUK/assets.files/material-data-sheets/aluminium/aluminium-6061.pdf)，第2页对应厚度T6/T651板材、第3页对应棒材及物性；相关范围Rp0.2≥240 MPa，指导E=70000 MPa、密度2.70 g/cm³。必须核实采购状态、牌号、厚度、方向和批次材证；不能把70.80与240之比直接当整底座安全系数。

**不能自立使用：** 即使把全部手臂及底座重量计入，260方形底座绕X/Y边的恢复力矩只有约30.51 N·m，低于上述水平姿态47.00 N·m的对应分量。桌面锚固仍需把载荷传递到有足够稳定性的桌架/基础；在不稳定的轻桌上加背板不能解决整桌倾覆。

PLA/PETG打印大平面朝下，名义1:1；打印机收缩、孔径补偿和支撑去除须先用接口样片标定。完整260 mm底板需要可容纳它的打印平台。所有打印装配都要另设独立支架托住关节；不通电、不挂工件、不承托整臂。

2. 底板翻面，用4个M6×25由底侧连接四柱；确认头部完全沉入。
3. 放后环，用4个M6×20从上方连接柱顶；核验柱高、接触平面和孔位。
4. 由独立支撑托住RH25，从上方使后壳穿过后环与底板中央孔，固定后接触面落在后环顶。
5. 保留原厂4个装配螺钉，放置有让位孔的前压环，装8个M4×45。拧紧规范尚未定义，不执行负载装配预紧试验。
6. 在审核通过的工作台上装背板、8垫圈、4个M8螺钉/螺母；按实际桌厚复核长度。
7. 从桌下接线，落实接头插拔、弯曲半径、应变释放、接地及维护空间。
8. 关闭材料、接触/预紧、螺纹、桌架和动态载荷缺口后，才讨论分级承载试验与动力运行。
