# 四灯片夹爪：接触、驱动与保持分析

状态：工程候选，未冻结；2026-09-27。本文中的计算不是 2 kg 抓取实测，也不是制造放行。器件来源、尺寸和选型边界见 [夹爪候选器件](hardware/gripper-candidates.md)。

## 设计输入与本轮结论

保留四灯片各自独立 1 DOF、上大下小、中央圆形显示和主动注意力动作。暂以 **2 kg 净工件**评估；末端自身质量另计入机械臂载荷。下文 90/70 mm 接触位置用于早期解析量级示例，已不代表当前 CAD。R4-layout-03 的上/下片长为 140/100 mm，接触沿长位置为 113.485682/66.174013 mm，详见[当前布局与六维接触计算](r4-layout-and-grasp.md)。头部质量预算为 **1.8–2.2 kg 候选范围**；此前 1.2 kg 已失效，不能作为已实现质量。

短电机 `2214X024BXTH + 22GPT HT 829:1 + IE3-1024 L` 适合先验证约 5 s / 90° 的慢速开合；`2250X024BX4 + 22GPT HT 330:1` 保留为较快备选。两者都没有在当前头部内完成零速热验证、制动集成和寿命验证。开合时间是比值估算，尚未包含加减速和物体接触。最终任务节拍仍待确认。

## 运动与接触定义

与 [`engineering/gripper.py`](../../engineering/gripper.py) 一致，头部局部坐标的 `+z` 指向前方，方位角 φ 从 `+x` 向 `+y` 增长：

```text
er = [cosφ, sinφ, 0]
et = [-sinφ, cosφ, 0]
正闭合转轴 = -et
p(q) = R er + z0 ez + s(cosq er + sinq ez) + h(-sinq er + cosq ez)
J(q) = s(-sinq er + cosq ez) + h(-cosq er - sinq ez)

τ_finger_joint = -J(q)^T f_on_finger
```

`s` 是实际接触点沿片方向的距离，`h` 是接触垫的法向偏置。一般情况下，法向力、摩擦力、片自重和惯性均影响关节力矩；`N × s` 仅在特定方向下成立。根部位置、接触垫朝向和接触点随夹持对象变化，必须由最终 CAD 和任务物体重新求解。

## 必要下界与早期解析示例（不是当前 CAD 的抓取结果）

取 `g=9.80665 m/s²`、质量 `m=2 kg`、设计系数 `k=2`，示例要求抵抗 `W=kmg=39.2266 N`。当所有接触法向与重力垂直，且摩擦均可用于抗重力时：

```text
Σ μ Ni ≥ W
μ=0.4: Σ Ni ≥ 98.0665 N
μ=0.3: Σ Ni ≥ 130.7553 N
```

这只是必要条件。R3 方位角 `UR=35°、UL=145°、LL=225°、LR=315°` 并非中心对称；四指法向力相等会产生横向合力。在 μ=0.4 的等分下界处，残余力幅值为 6.547 N；μ=0.3 时为 8.730 N。独立执行器需要不等力分配，不能只给四指相同电流。

下面给出一个**明确限定几何的摩擦 LP 可行解**。它用于检查计算和驱动量级，不代表现有四指能接触任意 80 mm 工件：

- 工件质心取原点，重力沿 −z；四个接触点 `pi=0.04 er,i`，位于同一 z 平面；接触法向径向向内。
- `qi=90°`、`h=0`，上接触距离 90 mm、下 70 mm。实现此示例需根部轴向位置分别为 −90 / −70 mm；它不是把未错层的 R3 模型直接套入此解。
- 仅使用 z 向摩擦 `fi`，不使用接触面的周向摩擦或接触力矩；物体受到 `Fi=-Ni er,i+fi ez`。
- LP 为最小化 ΣNi，约束 ΣFi=(0,0,W)、Σ(pi×Fi)=0、Ni≥0、0≤fi≤μNi，以及各指 |JiᵀFi|≤允许力矩。载荷力在这里已乘系数 2，不能再在同一步重复乘 2。

左右对称后可解析解出 `Nupper/Nlower = sin45°/sin35° = 1.232803`，并令 `fi=μNi`。代入全部力/力矩约束，数值残差小于 2e−14 N 和 3e−16 N·m；法向力总和达到上述下界，因此也是这个受限 LP 的最优解。

| μ | UR / UL 每指 Ni | LL / LR 每指 Ni | UR / UL 每指 fi | LL / LR 每指 fi | 上指力矩 | 下指力矩 |
|---|---:|---:|---:|---:|---:|---:|
| 0.4 | 27.073 N | 21.960 N | 10.829 N | 8.784 N | 2.437 N·m | 1.537 N·m |
| 0.3 | 36.097 N | 29.281 N | 10.829 N | 8.784 N | 3.249 N·m | 2.050 N·m |

两个解都满足 22GPT HT 四级的 3.7 N·m 目录连续上限，但 μ=0.3 时上指仅有 **3.7 / 3.249 = 1.139** 的目录比值；这不是额外安全系数的验证。接触误差、切向力、加速度、传动损失和热降额很容易消耗此余量。若采用 1:1 外加传动，传动损失还会提高齿轮箱所需力矩。

此示例只有一个受力工况，摩擦恰好位于设计载荷下的边界，**不证明六维力闭合**。对任意物体应将各接触块 `Gi=[I; skew(pi-c)]` 横向拼成抓取矩阵 G，求 `Gf+w_ext=0`、各接触摩擦锥、单边接触、关节力矩/角度限制。可用内接多面体摩擦锥作保守 LP；若要证明力闭合，还需验证可抵抗所有方向的小扰动力矩，而非只平衡重力。不同物体尺寸、偏心质心、加速、少一接触点均需单独求解。

若全改成 120 mm 接触距离，即使错误地假设均分，μ=0.3 时单指也需 3.923 N·m，已超过 3.7 N·m；增大减速比不能修复齿轮箱输出上限。接触垫前移或后移必须与可抓物体尺寸一起决定。

## 90° 以上闭合：必须有真实承力面

平面灯片的法向为 `-sinq er + cosq ez`。当 q>90° 时，内侧接触的夹紧分量会出现轴向分量；四指不应把这部分力推到中央 LED、透镜、PCB 或相机上。需要可更换的定角接触垫，或中央显示外围的独立掌部承力止靠，并将其反力作为额外接触纳入力平衡。止靠须接入金属掌架，显示模块在其后留保护间隙。

超过 90° 不能自动称为自锁；硬限位也不能在任意物体尺寸上维持夹紧预载。灯片根部应是金属承力骨架、独立指轴和可替换软垫，发光面作为独立覆盖件。空载允许呼吸开合，已经夹持工件时改用灯光和整体姿态表达呼吸，避免周期性卸掉接触力。

## 装配包络与重量

首版优先用 **与指根切向轴同轴的真实短驱动包络**，四个驱动通过轴向错层避让。短版的暂算长度为 70.1 mm（后端至齿轮前安装面）加标准轴伸 16.3 mm，即 86.4 mm；编码器、齿轮装配基准见器件文档，电缆弯曲、联轴器和指轴支承空间另加。

若指根轴中心距头中心 R=65 mm，保守地把整个 86.4 mm 单边投影放在切向，点包络直径约 `2√(65²+86.4²)=216.2 mm`，仍未含电机半径和外壳。因此 **约 220 mm 是检查起点，不是已通过干涉检查的成品外径**。较快 2250 组合含轴约 127.5 mm，对应点包络约 286.2 mm。不能在 CAD 中把它们缩成虚构的小圆柱以维持前脸 Ø150 mm。

同步带备选保持电机轴平行于指轴，将电机向掌内和后方平移，用有独立双轴承支承的中间轴驱动指根。固定比传动不增加主动 DOF，但引入张力、柔性和寿命要求；可先验证约 Ø180–210×140 mm 包络目标，尚未证明装得下。轴向电机加锥齿轮则需要完整的转角传动，不能省略。

1.8–2.2 kg 是整头设计预算，不是以上零件和证明的实重；选择重型输出端制动器后必须重算，不能靠忽略制动器勉强达标。

## 持续夹持与释放

目录效率可用于运动中的预选，零速时机械功率为零，不能用效率推导“零速连续保持电流”。应在实际金属散热夹持和封闭外壳内，测电机温升、驱动器温升和接触力衰减；电流法测力需校准齿轮摩擦、方向迟滞和软垫压缩，建议原型加接触力传感器或经标定的弹性件。

当前没有已验证、可直接装到这套电机上的失电保持器。小型输入端弹簧制动器需要原厂提供可用输入轴/定子安装面，并解决编码器占用后轴的问题；输出端 4 N·m 制动器虽有商品，但四只质量不可接受，详见候选表。行星齿轮减速比高、丝杠推力大或电机失能都不等于已证明失电保持。

台架阶段采用有接物托盘的低高度实验，先标定单指持续力和最大容许温度，再逐步测试受限工件；该安排不构成产品载荷认证。正式夹持中“停机”不得默认直接打开手指；应区分停止运动、受控维持、放置工件、机械保持和断电，每一步需要可验证的载荷路径。机械锁止固定角度也不能防止软垫蠕变导致夹力下降。

## 冻结前的具体未决项

1. 确定任务物体的尺寸、材质、表面状态、质心和时间要求；实测垫材料的 μ 下界，包含污染和磨损。
2. 用最终根部坐标、接触垫 CAD 和工件模型重求六维接触可行性；确认四指实际接触，而非仅角度到位。
3. 向 FAULHABER 获取电机+829:1+编码器的组合订单号、组合 STEP、实际质量和热条件；短版受载零速保持尚未通过。
4. 选择直接同轴或同步带方案，完成全行程干涉、走线弯曲、装配工具空间和齿轮输出耦合验证。
5. 选定失电保持的产品要求和可制造方案，再冻结外壳；目前不能宣称“断电不掉物”。
6. 验证金属承力路径、指轴配合与疲劳、末端偏心惯量、柔性垫压缩以及实际工况寿命。3D 打印件仅先用于形态和装配验证。
