# 工程发布检查

此清单用于追踪尚需完成的实际工作，不代表每项已经验证。

| 编号 | 项目 | 当前证据要求 | 状态 |
| --- | --- | --- | --- |
| R01 | 载荷／臂展／任务 | 净工件、模块自重、质心包络、速度、加速度、使用周期 | 输入澄清及显式假设 |
| R02 | 关节选型 | 连续／峰值输出、RMS扭矩、温升、轴承载荷、制动、寿命 | 官方资料研究中 |
| R03 | 相机闭环 | 模组、镜头、串行／解串、采集板、主机、驱动版本 | 官方资料研究中 |
| R04 | 线束 | 线径、接头外形、最小动态弯曲半径、自由扭转长度、应变释放 | 研究中 |
| R05 | 机械臂数学 | FK、Jacobian、IK、重力矩、惯量和动态估算，单位一致 | 待计算 |
| R06 | 夹爪数学 | 四指独立坐标、接触Jacobian、力矩、摩擦与释放 | R3仅有理想板闭合，待深化 |
| R07 | 配合接口 | 供应商真实孔位、定位面、紧固件啮合、装配工具通道 | 待工程图 |
| R08 | 整机碰撞 | 自碰、独立指运动、桌面、工件、镜头、线束 | 待同版模型 |
| R09 | 结构 | 材料、截面、局部应力、刚度、疲劳、连接与公差 | 待计算／制造审核 |
| R10 | 制动与停止 | 重力轴保持、夹持保持、急停、断电顺序、驱动实际功能 | 待系统验证 |
| R11 | 工艺 | 打印方向／支撑／嵌件；金属毛坯、刀具可达与表处 | 待分件 |
| R12 | 出图 | 零件号、版本、尺寸链、基准、公差、表面、材料、数量 | 待与实体一致性检查 |
| R13 | 复现 | 固定依赖版本、生成命令、参数、检查结果、文件哈希 | 待建立 |

外部供应商资料和样件验证若成为最终阻塞，需给出具体未满足项、可继续的独立工作和所需证据；不得以一项阻塞掩盖其他未完成工作。
