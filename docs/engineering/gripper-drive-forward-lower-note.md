# 下指根前移 +50 mm：驱动包络复算

**该紧凑驱动方案已被后续真实支承研究否定。** 本页14 mm轮宽只是占位；真实轮总宽20.6248 mm且需联轴器、独立轴/轴承后，四组实体仍相交，见[双支承研究](gripper-shaft-support-study.md)。本页数值是历史快照，不能用于新传动的空间或光学放行。

状态：**单一修改方案的数值检查，未冻结、非制造发布**。原研究保留于 [原驱动包络](gripper-drive-packaging.md)，本次独立结果见 [forward-lower JSON](../../analysis/gripper-drive-packaging-forward-lower.json)。

下指根由 z=−25 改为 **z=+50 mm**，下电机轴随之由 z=−50 改为 **z=+25 mm**。上指根 z=0、上电机轴 z=−25 不变；R=70、四指 φ=35/145/225/315°、机身中心切向偏置 s=∓40.7、两轮平面 q=±2.5、镜像轴端朝向均不变。两轮径向差仍为 37.416574 mm、z 差 25 mm，因此中心距仍为 45 mm。

| 检查项 | 结果 |
|---|---:|
| 4 个机身 + 4 根输出轴 + 8 个轮外包 OBB | 非预期接触检查通过 |
| 名义最小非预期 SAT 轴间隙 | 1.15 mm，本组安装面至轮侧 |
| 假定皮带与其他驱动组的保守包络 | 通过；最小所测 SAT 轴间隙约 6.1017 mm |
| 同轴圆柱外包直径 | **175.0343 mm** |
| 全部驱动件 z 范围 | **−42…+67 mm** |
| 裸驱动包络深度 | **109 mm**，原研究为 84 mm |
| XY 轴对齐包络 | x=−84.3815…+84.3815；y=−68.2358…+57.6831 mm |

“通过”只对当前几何输入及保守盒子成立，排除了轴装入本机机身和驱动轮的预期接触。它不是完整机械装配通过，也不是精确最近点间距。前轮廓的 XY 外包虽然相同，**侧面下指根确实比上指根前伸 50 mm**；不能在造型图中把它抹平。后端界限同时向前收了 25 mm、前端界限前移了 50 mm，净深度增加 25 mm。

下指根前移的出发点是零宽、直杆、尖端汇聚的简化关系：R70、上长140、下长100时，上尖端前深为 √(140²−70²)=121.2436 mm，下指根需前移约 49.8293 mm 才使下尖端达到同一前深。取 50 mm 后，理想尖端深度差约 0.1707 mm。**这只解释层高选择，不证明有限宽厚、指根实体、软垫和真实物体的有效闭合**；夹指全实体、掌面碰撞与扫掠由主 CAD 分析继续校核。

仍沿用机身 Ø22×70.1 mm、轴伸16.3 mm 和轮总包络 Ø34×14 mm：70.1 是未冻结的组合估算，轮包络是占位假设。皮带宽9、厚3 mm 是本次包络输入。当前模型仍不含独立输入/输出轴支承、联轴器、张紧、螺钉/安装凸台、线束、显示、相机、掌面或指骨架。尤其把驱动轮从电机轴移至独立双轴承输入轴会改变整个轴向堆叠，必须更新后再算。
