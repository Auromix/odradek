## 连续装入与旋转证明的范围

检查包含真实J3/J4/J5/J6、既有L34与L56各六个原创件和各40个已知螺钉形状。静态按逐solid Boolean公共体积检查，门槛1e−4mm³；AABB只用于可证明的排除。四个预期承力界面另求实际共面接触面积。

三个原创件有完整平移包络：OUT沿−Y120mm、CARRIER沿−Y120mm、FRONT沿+Z140mm。先对实际件做Boolean包含证明，再检查扩大的棱柱/胶囊包络；保留中央阶梯避让及前环沿轴不变的帽头避让孔。同时记录最大5mm站距的离散位置，离散检查本身不替代连续证明。

J5的34个实际solid由两个局部同轴圆柱包含：后段R33.55、Z−102.1～−35.7；前段R42.1、Z−35.7～2.1。把前段向+Z扩展到182.1，连同后段覆盖完整0～180mm插入。原厂孔、内部件没有简化成一个圆柱后直接宣称真实组件已检查；包含关系逐solid计算。

**q4本连接范围：**将L45原创件、外部螺钉形状和真实J5外壳包含在J4轴系旋转不变体：外R70，Z0～3留R27.8中心空区，Z3～105为填实保守体。该体对J3/J4/L34检查无碰，即覆盖本范围完整q4一周。输出螺钉进入原厂转子内部的已知段另用R32.5、Z−3～0柱体对外部L34/J3检查；不把原厂STEP里的静态输出孔当作转动后仍固定的孔，亦不声称已验证OEM转子内部。

**q5相对L45范围：**L56/J6中Z450以下的输出M3杆段，被J5轴R28.5柱包含；该柱延伸Z300～450后仍对L45全部原创件/硬件避让。其余几何在Z450以上，而L45最高Z446.5，保留3.5mm平面分离。绕q5保持Z和轴向柱包络，因此本相对关系覆盖q5一周；共同q4刚体变换可以取消。它没有证明L56/J6相对L34在q4、q5同时运动时无碰，也不是全臂联合运动或线束运动证明。

## 线缆：现有首弯路线不闭合

首先保留系统级限制：既有示例整束毛面积113.44mm²，大于RH20/RH17 Ø12孔的113.10mm²，还没计保护衬套和填充余量。OUT的Ø52只让开中央凸台，不改变原厂中空孔瓶颈，参见[电气与相机研究](hardware/electrical-camera-candidates.md)。

为形成实际几何证据，本轮用圆线截面沿**精确90°圆弧**扫掠，起点为J4输出中心，初始切向世界−Y；转弯平面从+X朝+Z每45°采样，共8个方向，分别检查三个半径。这不是完整线束路径搜索，也没有固定点、端接外壳和全关节运动。

| 几何对照 | 检查结果 | 能否用于动态设计 |
|---|---|---|
| R15、Ø3.1 | 向下侧225/270/315°三条首弯无碰；其余碰后环或J5 | 单次弯曲对照，不能用于动态许可 |
| R34.5、Ø3.45 | 8/8首弯都撞真实J5；部分也碰后环 | 只作条件几何对照，来源有冲突 |
| R75、Ø3.1 | 8/8首弯都撞真实J5；部分也碰后环/前环 | 明确否定这些首弯，不等于证明所有空间路径不可能 |

[Basler文档](https://docs.baslerweb.com/basler-cable-gmsl-fakra-z-1x-f-f) v134（2026-09-16）对2200002798写最大Ø3.45、移动R34.5/5M弯曲、机器人应用；[同料号官方商店](https://www.baslerweb.com/en/shop/cable-gmsl-fakra-z-1x-f-f-3m/) 却标static。尚未获得同批次书面澄清、扭转和复合运动条件，也未确认与ZED链路适配，因此本研究没有把它替换成已认可的动态线缆。

本轮读取的 [Rosenberger现行官方资料](https://www.rosenberger.com/fileadmin/content/headquarter/Downloads/_Other/HySpeedVision_Flyer.pdf) 为April2026 / Info1HYVFlyEN 100/2026，第7个PDF页（印刷12/13）写Similar RG316-d **CG:03**、Ø3.1、动态R75/3M弯曲、±180°/m与5M扭转、单次R15。既有项目的CG:02记录属于不同资料快照，不能静默拼接名称和寿命条件。本几何对照只使用Ø3.1/R75，不以不同版本组合形成采购承诺。

下一步应研究绕开中空轴首弯约束的**可拆关节侧腔、明确两端固定点的活动余量或其他传输路线**。需要真实端接外壳、最低动态R、复合弯扭和全行程扫掠；单条R15首弯成功不能推导一整根相机线能布好，更不能外推整束电源/EtherCAT/相机线。

## 质量、载荷与EXT24条件分支

三件金属CAD估重 **0.352707224 kg**，加权COM为世界 `[约0,−28.649245070,405.957183336] mm`；加0.15kg硬件预算共0.502707224kg。所有零件 **preceding_joints=4**。每件质量与完整质心惯量按6061密度2.70g/cm³积分，记录零件/世界坐标下COM和kg·m²张量，并用解析长方体、对称正定与平移不变性复核。这不是称重，螺旋牙型和全部工艺倒角未计。

本轮以L12/L23/L34/L45/L56/L67实际金属替换L1～L6预算，并分别在对应金属COM加0.20/0.15/0.15/0.15/0.10/0.10kg硬件代理。历史分支保留face780、COM760、TCP890，含2/3.5/4/4.5kg头。EXT24分支为**4.5kg预算头、face804、COM784、TCP914，加2kg净工件**；轴原点不变。

**EXT24不是逐件实装头部的质量模型。** 不随整头移动的adapter例外需由整机真实质量整合另算。这里仍保留旧`L7_budget=0.15kg`的J7到头部接口余量；后续真实整头已含adapter和延长件时必须移除该旧余量，避免重复计重。不能把本分支的统一预算COM位移冒充全部真实零件都平移24mm。

对pre≥4质点，任意附着于J4的截面点P使用 `mg×(|P−J5|+…+|Jn−COM|)` 三角界；pre=4则用 `mg×|P−COM|`。各截面保留全部pre≥4质量，包括某些切面近端的自重，是包络载荷而非精确切面自由体。脚本另用200姿态独立正运动学求直接三维矩模检验该界，以721方向复核中心化螺栓组反力守恒。

EXT24三角界为 `[0,77.380920,65.560873,39.751872,31.647077,16.507788,11.736108] Nm`。本连接最大截面矩39.751872Nm；头COM±50mm、工件COM±100mm使矩模增加4.167826Nm，再乘1.5研究倍率得 **65.879548Nm**。这不是规范认证安全系数。

该工况角部M6/输出M3/固定M3的等刚度组最大外载轴向反力约896.49/276.45/466.74N，不含预紧和撬力。输出筋实际16mm净截面条带约54.286MPa/0.005434mm；侧桥实际18mm条带约19.354MPa/0.002556mm。筋假定在r34.7、侧桥在X34完美固支，**二者都不是整个零件的保守强度界**。环柔度、接触抬离、孔边集中、螺纹剥离、载荷分配和疲劳仍需接触FEA与实测。

材料数据参考 [thyssenkrupp 6061表](https://ucpcdn.thyssenkrupp.com/_legacy/UCPthyssenkruppBAMXUK/assets.files/material-data-sheets/aluminium/aluminium-6061.pdf) 的E70GPa、适用目录范围内T6屈服参考240MPa，批次/厚度/状态待核实。80Nm另列RH20单一接口作用敏感性，不是所有轴同时峰值或零速保持额定。输出面摩擦预紧敏感性只用假设μ和r31计算，不是预紧推荐值。

## 复现与未放行项

```sh
python engineering/build_link45_study.py \
  --rh20-step '/local/vendor/RH-20-100-E-B-D 3D A.STEP' \
  --rh17-step '/local/vendor/RH-17-100-E-B-D 3D-A.STEP' \

```

依赖CadQuery、NumPy、trimesh、ezdxf、ReportLab、pypdf，以及已稳定的五段连接质量/接口数据。生成器检查主参数和原厂输入hash；带原厂几何的私有装配禁止写进仓库。原创件STEP/STL逐件重读，DXF审计；PDF逐页渲染检查。

一般线性±0.10、孔心±0.05、接触平面度0.05、螺纹6H仅为候选。PLA/PETG只做无载手动装配：输出板接触面朝床、后环平放并支撑侧腿、前环平放，实际关节另由外部夹具承重。

制造与带载前仍需原厂有效牙/夹持许可、完整紧固件订单与批次尺寸、有效啮合/预紧/防松/剥离、材料与公差/工艺审查、接触FEA与疲劳、动态和急停载荷、整臂联合行程，以及线束完整路径/动态寿命。连接桥的名义实体闭合不等于这些项目已经完成。
