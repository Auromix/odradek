# 硬件 BOM 使用说明与采购澄清

版本：2026-09-27。配套 [bom.csv](bom.csv) 共 **121 行**，覆盖本体、四指驱动、双相机、显示照明、控制电气、外部电源、线束、支承和结构制造占位。它是可审查的工程候选清单，**不是已完成全部选型的采购单，也不是完整 PCBA 生产 BOM**。当前 54 行 `candidate`、6 行 `blocked`、61 行 `TBD`，0 行 `selected-for-prototype`。没有询价、报价、库存、交期、采购或实机验收记录。

## 1. 字段和加总规则

| 字段 | 解释 |
|---|---|
| `qty` / `qty_unit` / `quantity_basis` | 每台研究样机数量及其依据。线材米数、紧固件、PCB 器件等未知数量明确为 `TBD`；不能转换为 0。总成的数量不是该总成内所有零件的完整数量 |
| `model_or_part_number` | 确切目录料号、带说明的配置请求，或 `TBD`。FAULHABER 的 `X` 系列写法、RH 的 SH1.0 接头描述、CG:02 线组均不能当成已确认完整下单号 |
| `branch` / `alternative_group` | 互斥路线，见下一节。先选路线再汇总，不得把全部 121 行相加 |
| `unit_mass_g` / `mass_basis` | 只有已核实目录质量才填数字；标称/典型、是否含法兰/编码器都有区别。未知为 `TBD`，不是无质量 |
| `unit_price` / `currency` / `cost_status` | 本轮全部 `TBD` / `TBD` / `not-quoted`。未收到可比报价，不能给出可信总成本或以 0 元补齐 |
| `source_url` / `source_document` | 外部一手出处与仓库内依据；多个 URL 以 ` | ` 分隔。自制/未选件使用 `TBD`，没有虚构目录链接 |
| `selection_status` | `candidate` 有来源的研究候选；`blocked` 已发现阻止下单/集成的明确缺口；`TBD` 型号或结构未定义；`selected-for-prototype` 仅在完整配置及使用阶段得到项目明确选择后使用，本轮无此状态 |
| `stage` | 仅指拟用阶段，不等于该阶段已获安全/制造放行。打印外形、光学/电子台架和金属结构的验收边界不同 |
| `procurement_group` | 同一供货组合的组成行，防止重复采购。例如电机、齿轮箱、编码器和原厂法兰组成四套工厂总成；不能按四种散件随意拼装 |
| `open_items` | 本行尚未闭合的问题；主型号存在不等于整个接口、寿命或安装已完成 |

当前 CAD 的接触垫为每指两片，共八片，ME-06 按八片记；楔形/曲面修改后需要重新核对该行。所有数字均为单机器人研究配置，未含备件、良率损耗、验证试片数和采购最小包装数。不得将尺寸/来源核查称为“产品验收”。

关节源文档的早期末端工作假设为 1.2 kg，后续夹爪候选给出 1.8–2.2 kg 的研究预算；二者不是已经互相验证的同一质量基线。当前 R4-layout-03 参数采用 2.0 kg 末端预算，按 1.8/2.0/2.2 kg 作敏感性研究；它仍是预算。应依据完整装配质量/COM 重新计算本体重力与动态载荷。**本轮暂按2 kg净工件并另计末端自重；用户给出的2 kg负载口径尚待确认。**

目前没有货币预算。采购询价应按同一数量、币种、税费、运费、配置、交期、保修和有效期记录；不同配置报价不能仅按单价排序。原厂总成与单独部件报价只能使用一种，避免重复合计。

## 5. 3D 打印、电子台架与金属加工的分阶段使用

| 阶段 | 可以验证 | 本 BOM 的使用方式 | 未获得的结论 |
|---|---|---|---|
| 非动力几何打印 | 风格比例、四片关系、完整手动开闭、零件装入/拔出、线束路径和工具空间 | 自制外壳/骨架/替身关节按几何件制作，实际材料与打印参数单列。可用非动力替身，不必先采购整套关节 | 不证明 2 kg 抓取、关节承载、疲劳、温升或停机保持 |
| 独立光学/LED/通信台架 | 双鱼眼模式、曝光/光斑、点阵效果、EtherCAT 状态机和单轴控制 | 按已确认配置采购必要评估器件；评估板不直接被当成装机主板 | 不证明四指闭合碰撞通过、整机线束寿命或整机失电安全 |
| 受保护的驱动与传动台架 | 单指接触力、驱动热、带张紧/回差、支承反力、故障保持 | 先完成台架受力与捕获支撑、接线/保护，再做测量；不直接用外观打印件承担全部负荷 | 不把单轴结果自动推广到四指、全臂姿态或寿命 |
| 金属结构样机 | 完整载荷路径、定位/配合、真实内走线和制造公差 | 用正式材料、基准、形位、配合、紧固件/预紧和表面处理图纸；按实物质量重算；保留非承力打印盖板的明确边界 | 不因改成金属即自动取得 2 kg 额定、长期寿命或安全等级 |

金属版至少需要明确：关节定位台阶和孔的真实归属；螺钉有效啮合而非仅螺纹标称深度；双支承预紧/定位；负载与灯板隔离；电气保护连接；线束弯扭寿命和端接安装顺序。拆头按卸载、断电和锁紧接头维护设计，首版不承诺高速信号盲插或无限滚转。

## 6. 制造 BOM 放行还差什么

当前尚缺最终零件数量/图号、全部采购订单号、供货包组成、完整 PCB 元件级清单、线束 pin-to-pin 图、裁线/端接工艺、紧固件标准/长度/等级/扭矩、质量/重心、版本和进料试验。BOM 中 `TBD` 行清楚列出这些缺口，但占位行本身不等于已经解决。

下一次修订应由完整 CAD/ECAD 与实测数据反向更新：先淘汰互斥分支，再冻结真实配套组合，最后填写供应商确认、报价和具体试验阶段。确认之前，不能把这份候选表转成“全部硬件已选定”或直接下单全部行。
