# SHOULDER-PROC01：加强肩部的厚板与长螺钉订料定义

为 [RAISE02 独立结构候选](../shoulder-raise02-study.md)补齐具体产品来源：八根长螺钉优先候选为 **Fabory 07000.040.100**；后叉原料明确为 **6061-T651 轧制厚板**。这是选型与订料要求，尚未采购，也没有把候选替换进整臂。原 RAISE02 的几何、质量计算和报告保持冻结，本页是其材料/料号补充。

## 长螺钉：选到具体条目

| 项目 | 优先候选 | 备选来源 |
|---|---|---|
| 品牌与料号 | Fabory **07000.040.100** | Würth **00834 100** |
| 规格 | M4×0.7×100，12.9级，钢本色 | 同名义规格与等级，钢本色 |
| 圆柱头 | 最大Ø7、高4；内六角3 | 目录Ø7、高4；内六角3、槽深2 |
| 螺纹段 | 表中 b=20；本长度为部分螺纹 | 已确认部分螺纹，本次页面未列b |
| 目录单重 / 八根 | 11 g / **88 g** | 9.5 g / 76 g |
| 使用状态 | 连接校核用首选候选 | 未批准直接替代 |

数据来自两家自己的产品页及 [Fabory 单页规格 PDF](https://www.fabory.com/nl/p/07000040100/generatePdf)；Würth 的[西班牙官网规格](https://www.wurth.es/ddu-tornillo-metrico-allen-cabeza-cilindrica-din912-12-9-3-m4x100)还列了通用扭矩/预紧范围，但本项目没有采用。Fabory PDF 的 b=20 是目录几何值，不能把它自行解释为所有批次的完整牙最小长度。实际长度公差、末端倒角和螺纹收尾仍须受控数据或检验。两者目录质量不同，换供应商时应更新质量账，不把它们混为一件。

现有轴向堆叠不加垫片：头下座面 Y−11.5，钢块前面 Y−104.5，夹紧长度93；100长螺钉进入钢块的**几何长度为7 mm**，尖端到钢块后面名义余量1 mm。若按b=20的名义位置，牙段从头下80 mm开始，比钢块入口早13 mm；不会把光杆画成已进入螺纹孔。真实有效啮合仍须扣除两端不完整牙和倒角，最小值应按：

```text
有效啮合下界 = 螺钉最短长度 − 最大夹紧堆叠 − 螺钉端不完整牙 − 钢块入口不完整牙
```

本轮只核对名义尺寸和先前Ø7.22×4头部包络能容纳目录Ø7×4；没有假设上述四项公差已经闭合。M4在薄铝通孔中的偏载、头下面压、钢块偏心、预紧散差、电机固定法兰允许压紧力和松弛仍需继续校核。**目录5.2 N·m不是本项目的拧紧指令。** 不添加目录推荐垫片后仍沿用93 mm堆叠；若加垫片，必须重算长度和工具空间。不要自行电镀12.9级螺钉作为外观处理。

88 g可替换现有紧固件账中“这八根”的条目，不能直接叠加到原0.20 kg余量再保留其重复份额。本页未修改该余量或全臂总重。

## 厚板：供货状态、方向和可用尺寸

后叉真实STEP包围盒为 **130×86.5×141.8 mm（世界X/Y/Z）**。建议从4英寸（101.6 mm）厚 **6061-T651非包铝轧制板**切料，板厚沿世界Y，优先把轧制方向沿世界Z并标记。T651明确了拉伸消除应力的供货状态；不能用同名6061铸造工装板、无证明的T6挤压料或退火料替代。

订料请求为 X140×Y101.6×Z150 mm 毛坯，验收前须确认能得到 **X140×Y96×Z150 mm完整可用矩形体**。这些是本项目提出的原料要求，**不是供应商承诺的锯切公差**；毛坯锯切尺寸要考虑负偏差、锯痕、翘曲及找正后实际可用区域。供应商须依据需求给出留量，再核对来料。

用真实BRep对两个居中盒体作包含检查，后叉盒外体积均为0。毛坯各边名义余量X5/Y7.55/Z4.10 mm；上述可用体余量X5/Y4.75/Z4.10 mm。这仅证明可容纳几何，不证明夹持、刀具到达或加工变形合格。按原比较密度2700 kg/m³，名义毛坯约5.761 kg、成品后叉约0.720 kg，材料保留率约12.5%；深腔、八条肋和多次装夹仍会影响制造成本。

[OnlineMetals产品12672](https://www.onlinemetals.com/en/buy/aluminum/4-aluminum-plate-6061-t651/pid/12672)列出4英寸6061-T651板、ASTM B209/AMS4027、可定尺及可提供MTR，说明这种供货形态有具体销售条目。本轮未确认其接受上述小块尺寸、批次、产地、交期或价格，也不假定实际轧厂为Kaiser。

### 材料证明要求

[Kaiser官方厚板资料](https://online.kaiseraluminum.com/depot/PublicProductInformation/Document/1010/Kaiser_Aluminum_Sheet_Plate.pdf)第20页，对原板厚2.001–4.000英寸6061-T651列出最低抗拉42 ksi、拉伸屈服35 ksi、适用试样伸长6%。换算约289.58 MPa和241.32 MPa。**原表转引2006年AA资料，页码版本1.09；本轮只确认该旧资料仍由厂商托管，没有核验它是现行标准。** 这些数值用于提出订料最低要求，不能替代真实MTR，也不是零件许用应力。原板厚101.6 mm决定所用厚度行，不能按加工后的局部24/16/8 mm厚度换用薄料数据。

要求随料保留轧厂、炉/批号、6061-T651、原始厚度、适用标准及版本、取样方向和实测抗拉/屈服/伸长。若实际证书、试样或适用标准与上述要求不一致，须重新审查后才可将材料值用于结构判断。纵向、长横向和短横向不自动等价；螺钉压紧、接触、孔边及疲劳也不能仅凭拉伸屈服值放行。

本页没有以目录典型276 MPa替代批次下限，没有改变原E=70 GPa比较假设，也不宣称当前FEA已经获得屈服或疲劳合格结论。后续任何制造版本应明确继承本订料状态并绑定实际材质证明。尾部插头空间、连接校核及整臂复算完成前，RAISE02仍是独立候选。
