# R5-CABLE-HARDWARE01：两级差动钢索条件选型

**建议继续集成一套升级组合：叶索 Sava 2037 + SP3106，二级索 Sava 2050 + SP4125。** 在下述弯曲强度代理、原厂寿命优化建议和已验证终端的条件下，它们覆盖每叶 50 N、二级 100 N 的中档筛选；75 / 150 N 不覆盖该筛选。真实允许张力仍为 **TBD**，不能把表中的条件上限写成组件额定工作载荷。线径全公差、压接保持力、锚点、轴隔套和反复弯曲寿命没有闭合。

本包只研究钢索、滑轮、终端。输入拉点为各瓣局部 `A=[R+13,0,−12] mm`，`R=31…91 mm`，沿 `−er` 拉动闭合；`head Z<−17 mm` 只是初始可布置区域。没有证明整条钢索可穿过、叶索不会松弛、三只动滑轮可装入或整头抓持通过。原始数据、公式和结果分别在 [catalogue-data.json](../../../engineering/electronics/r5-cable-hardware01/catalogue-data.json)、[calculate.py](../../../engineering/electronics/r5-cable-hardware01/calculate.py)、[budget.json](../../../engineering/electronics/r5-cable-hardware01/budget.json)。

## 张力区间：分别核算弯曲段和终端

Sava 的 [滑轮设计指导](https://www.savacable.com/sava-expertise/pulleys-design-information) 建议 7×19 裸索槽根径至少为线径的 25 倍；其弯曲强度表在 `D/d=20` 时给出 0.91，在 30 时给出 0.93。本包对 26–28 的名义比值取较低档 **η_b=0.91**，不臆造插值。这个数是破断力折减指导，不是传动效率。

Sava 历史设计指南 DG1007 的寿命优化建议为直索最小破断力至少为工作张力的 10 倍。本研究进一步把它施加到各薄弱处的破断代理：

`B_system,proxy = min(B η_b, B η_terminal, F_anchor, F_other)`

`T_screen = B_system,proxy / 10`

其中 `/10` 是本研究采用的寿命筛选，不是用户规定、法规强制系数，也不是十倍寿命保证；它与动力学中工件重力因子 2 分开。给定 25/50/75、50/100/150 N 已是条件张力，本包不再次乘 2。压接处和绕轮段在不同位置，默认取最小值，不能机械相乘；也不按经过几只轮把 η_b 乘几次。所有试验、冲击和预紧造成的实际峰值仍要进入 `T`。

| 组合 | 条件张力 N | `B η_b / T` | 达到 10× 所需终端保持率下界 `10T/B` | 本轮结论 |
|---|---:|---:|---:|---|
| 2037 + SP3106 | 25 / 50 / 75 | 25.91 / 12.95 / 8.64 | 35.13% / 70.25% / 105.38% | 低、中档有条件可用；高档失败 |
| 2050 + SP4125 | 50 / 100 / 150 | 21.86 / 10.93 / 7.29 | 41.63% / 83.26% / 124.89% | 低、中档有条件可用；高档失败 |
| 较小 2032 + SP3088 | 50 | 9.71 | 93.67% | 中档已因弯曲代理失败 |
| 较小 2037 + SP3106 用作二级 | 100 | 6.48 | 140.51% | 中档失败 |

若终端实测保持率足够，主候选的弯曲筛选上限为 **64.766 / 109.293 N**。仅作灵敏度演示，假定终端保持率 85%，独立薄弱处模型上限为 **60.496 / 102.087 N**；85% 不是本候选压接的已证保证。若额外采用保守乘积 `η_b×0.85`，上限则为 **55.051 / 92.899 N**，二级 100 N 不再覆盖。这个乘积是另加的假设，必须写明，不能混入主表。完整逐项数据见 [load-scenarios.csv](../../../engineering/electronics/r5-cable-hardware01/load-scenarios.csv)。

旧指南的 `.036… .065 in` 裸索外径容差为 `+ .008 / −0 in`。若把它和旧根径负偏差组合，主候选最差 `D/d=22.674 / 22.364`，**未达到 25**；名义满足不等于全公差满足。若沿用旧根径负公差，要保证 25 比，实际最大线径必须不超过 **1.059688 / 1.249680 mm**。反过来使用旧钢索最大径，所需实际最小槽根径为 **29.210 / 34.925 mm**。这是供下一轮实物测量/受控图审查的约束，不是把当前商品筛成一个新 SKU。旧容差是否仍适用于本批产品未知。

两主候选均无加长内圈版本。SP3106 名义轴承每侧突出尼龙 0.3937 mm；旧最差宽度组合且假定居中时仅 0.1397 mm。SP4125 名义突出为 0，旧最差甚至可能由尼龙突出。**必须独立设计只接触轴承内圈的隔套、支承叉和轴向保持件。** 内圈承压台阶外径、实际居中/轴向偏移、安装配合、轴承内部型号和轴静承载证据均未取得，故没有给出虚构通用垫圈/销轴型号。原创 [包络图](../../../engineering/electronics/r5-cable-hardware01/component-screen.svg) 和 [mechanical-interface.json](../../../engineering/electronics/r5-cable-hardware01/mechanical-interface.json) 不包含这些零件。

## 滑轮载荷、速度与寿命

SP 是尼龙轮配精密双防尘盖单列球轴承，网页标为 ABEC3；这不等于轮体全尺寸为 ABEC3。三个型号官网 `Load Rating=90` 没写单位；旧同型号表明确为 **90 lbf = 400.340 N，500 rpm 基准**，并列出恒载、恒速、正常润滑/安装条件下 2500 h 平均寿命语境。当前版本一致性待确认。不能读成 90 N、最大转速 500 rpm 或保证寿命 2500 h。旧表的寿命换算排版不足以建立可靠公式，本包不自行补指数。

同张力、转向角 `β` 的轴载为 `P=2T sin(β/2)`：180° 时，叶索三档为 50/100/150 N，二级三档为 100/200/300 N。中档二级轴载 200 N 小于 400.340 N 的旧额定基准，**只是一项比较**，不是对往复载荷、叉座或尼龙压配保持的寿命证书。两侧不等张力应取矢量和；动滑轮自身质量与惯性、预紧、偏航和轴向分力另计。严禁把钢索 T 直接作为 180° 动滑轮的轴载。

固定滑轮无滑动时近似 `n=60v/[π(D_root+d)]`。对 0.225 / 0.450 m/s 两个显式线速场景，叶轮为 153.66 / 307.32 rpm，二级轮为 130.44 / 260.88 rpm。它们是场景值，**没有证明当前差动的各轮就是这个线速**。对同向坐标下两条平行索支路，动轮中心速度 `v_c=(v1+v2)/2`，`|ω|=|v1−v2|/(D_root+d)`；必须从实际路由求支路速度，不能把载体径向速度直接套到每个轮。制造商没有在已读资料中给出本工况允许最高 rpm、温度和逆转寿命。

旧指南的 7×19 寿命曲线明确针对包塑型号，不能给本包裸 7×19 批次读出循环次数。一次开合循环不等于每个索段一次弯曲，折返/反向弯曲数量由实际路径决定。钢索的结构就位伸长、弹性伸长、迟滞和滑轮摩擦需测量；不采用实体钢棒 `Eπd²/4` 代替索刚度，也不假定 η=1。持续 1 Hz 占空未确认。

## 制作前的具体输入与检查

下一机构包需要先确定三只差动动轮与各转向轮的数量、轴线、包角、中心轨迹、护罩和端环摆角，保持索路共面并避免侧缘摩擦。任何索向改变都要回算实际张力和速度；返程回位和防松弛是独立设计任务。端孔、绳夹或弹簧不得仅因本包已有候选而随意添加。

样件验证应记录本批线径、槽根径、装配偏摆、环套尺寸、模腔/工具和操作者；在独立受保护的试验夹具上先测端部拉脱/破断与滑移，再测完整路径的迟滞、摩擦、松弛和目标循环谱。载荷等级、试样数、允许损伤/伸长与更换判据需事先定义。本文没有下达按索破断力某一固定百分比做现场预拉的操作指令。进入抓取验证前仍须独立托住工件；候选目录参数不等于抓 2 kg 已通过。

`bom.csv` 中滑轮/端套数量按“每个轮/每个端头”给出，系统总数、截索长度、压接耗损和总质量 TBD。只有线质量可按实际长度累加；不以包围盒体积推尼龙轮、轴承、环套的重量。
