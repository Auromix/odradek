## 2. M2×20 的条件堆叠核算

以下跟随CD01最新输入：耳顶承压面Z1.75，每处使用上垫片、M2×20、后框背面垫片与螺母。按垫片0.35、螺母1.6的上限：

| 结构或紧固件 | 名义 Z 范围 / 位置，mm |
|---|---|
| 上垫片 | 1.75…2.10 |
| 螺钉头下座面 / 头顶 | 2.10 / 4.10 |
| 螺钉末端 | −17.90 |
| 既有框 | −15…−11 |
| 后垫片 | −15.35…−15 |
| 螺母 | −16.95…−15.35 |
| 螺母后方名义凸出 | **0.95**，约2.375个螺距 |

公式为 `凸出=20−[16.75+t上+t后+m螺母]`。仅把两垫片/螺母公开厚度范围代入，得到0.95…1.40mm；未包含螺钉L、耳/框位置、垫片压缩和不完整牙公差，不能据此宣称最小有效啮合已放行。初始任务曾以Z1作为起点；最新实际头下座面为Z2.1，两者不可混用。本节是尺寸链筛查，没有改变CD01脚本或给出紧固预紧值。

两螺钉、四垫片、两螺母按目录质量合计约1.48g，不含压缩柱或耳件。X±35.25 的Ø5垫片相对Ø64主体的名义最小径向间隙为 `35.25−2.5−32=0.75mm`；它只是圆柱包络之间的算术间隙，未含壳体筋、倒角、孔位公差和工具。当前孔位由X±35修订到±35.25，让最大Ø5后垫片的整个偏心圆盘位于半径32.75…37.75之间，对后框R32.5内缘和R38外缘各留0.25mm名义余量；这不包含公差。原四根光学柱的X±35/Y±22位置不变。Ø60 PCB本身不到X±35.25，必须由耳件和实际支撑实体承压，不能让垫片压在空处。耳底至框顶的压缩承力路径、绝缘隔离、螺母防转/防松、预紧力、塑料蠕变和整段螺杆干涉仍需结构方案验证。

### 局部 footprint 契约

从**连接器安装面**观察，定义u向右、v向上，h离开PCB安装面；原点取下列焊盘的几何基准，pin1位于左上，线向−v出。整体背面安装时应给出完整刚体变换；不要直接把顶面观察的pin序镜像复制到背面。

| 特征 | 名义坐标或范围，mm |
|---|---|
| 信号焊盘1…12 | 中心`u=−6.875+1.25(i−1), v=1.85`；每个0.6×1.7 |
| 两固持焊盘 | 中心`(±8.725,−1.35)`；每个1.0×2.7 |
| 全部铜焊盘外界 | `u[−9.225,9.225], v[−2.7,2.7]` |
| 板座主体参考外界 | `u[−9.125,9.125], v[−2.45,1.60]` |
| 对插本体参考外界 | `u[−9.125,9.125], v[−5.55,1.60], h[0,4.35]` |
| 加上向后0.8mm焊尾后的保守参考外界 | `u[−9.125,9.125], v[−5.55,2.40], h[0,4.35]`；深7.95 |

第2页side-entry的原始标注为：节距1.25±0.05且不累积；信号pad宽0.6±0.05；固持pad宽1±0.1、长2.7±0.1；外侧信号中心到固持pad内缘1.35±0.1。沿v的原始总基准5.4±0.1与3.7±0.1相减得到名义信号pad长1.7，不自行给这个差值套±0.1。上述中心坐标由这些尺寸推导，完整数组在JSON。铜焊盘尺寸不等于阻焊/钢网开口。

对插本体7.15mm不包括板座背后的0.8mm焊尾，因此不能拿7.15做整个连接器的实体深度截断。锁扣按压、完整拔出行程、12根导线的收束和弯曲半径没有已确认数值；必须另留可操作空间，本文不虚构“再留2mm就够”的维护距离。目录没有赋予这组GH12特殊高速/安全接口能力，电气pin-to-net和中央LED供电需要单独审查。CD01现明确采用背装变换：`headX=−u, headY=−14+v, headZ=−3−h`。旋转矩阵diag(−1,+1,−1)的行列式为+1，是绕Y轴180°旋转；出线−headY。原厂图中的pin1映到head `(6.875,−12.15,−3)` 的焊盘中心，不能再做一次镜像。该变换来自主线布局，不是原厂零件数据；裕量包络和装配干涉另由CD01验证。本文件保持名义源尺寸。HEAD-CTRL02另一端J15目前为BM12B-GHS-TBT顶插候选，其包络与本文SM12B侧插不同，不能共用4.35/7.15尺寸。
