# B05 SHAPE08 与 A11 臂根协调

2026-10-08，本体会话按已确认的“底座微调、臂身重构、四瓣保留”修改共享B05外观源。读取和修改的权威目录是`engineering/base_b05`；本体没有另做一份分叉底座。

SHAPE08保留SHAPE07的魔鬼鱼平面轮廓、左右一体翼肩、独立前鼻和后盖、两半外罩支撑框，以及18颗M3螺钉/18颗螺母。中央装甲环外径170mm、最高Z74mm；内径由104改132mm。A11根部四柱需要开口，外观环台仍不承担臂载。冠部到裙体的过渡从0.69–0.77收敛到0.715–0.755，留下更明确的折面。

8件打印STL经过闭合、单连通体、正体积、无重复/退化面及220×220×250打印床检查，XY各留5mm。两半外罩支撑框的原生网格表面未检出相交；这不覆盖包含关系、整体装配、承力底盘或真实工具入口。微小布尔边在最终封闭框件源网格中按1微米构造网格清理，非导出后修补STL。

A11臂根装配盘D140/PCD120，名义8×M6×20及1.6垫片保留；本体轴心统一为(0,75)，Z34.6mm。外观环台/外罩框不是M6螺纹承力件，正式承力底盘、桌夹和线束集成仍需验证。

另一个底座会话正在研究紧凑B06；该研究有自己的冻结输入与范围。新B06几何尚未与A11联检，不能把B05/A11的检查结果移用到B06。后续以新底座正式几何和接口契约更新同一权威来源。
