# RH 运行、保持与接口证据复核

**RH-OPERATION-EVIDENCE-01 · 2026-09-27 · 原厂公开资料审查，未作采购、带载运行或停止功能放行。** 本次不改变关节选型、肩部结构、主参数或已冻结 CAD；补充 [候选表](hardware/joint-candidates.md) 的运行条件与接口缺口。机器记录见 [rh-operation-evidence.json](sources/rh-operation-evidence.json)。

可以确认：四个精确候选均有 48 V 标称、20–55 V 范围；B 版集成保持闸，由模块 DC 口供电；官网已有可下载的 ESI。仍不能确认：**各轴零速持续保持额定、保证的输出侧制动力矩、抱闸动作时序、实机固件与 ESI 一致性、有效螺纹起止及允许深入量**。这些缺口直接影响电源、失电保持和紧固件放行。

全部 PDF 页号从文件第一页计数。原厂 PDF、STEP、XML 和 SDK 留在本地研究目录；本仓库仅保存摘要、来源、哈希与独立测量，不重新分发原文件。没有外联询问、采购、下载后执行 SDK 或向硬件发送指令。

四者额定转速均为 25 rpm；脚注明确额定测试在 **24°C 环境、无其他散热措施、额定转速、温升 60°C 达到热平衡**。它证明的是该测试条件下的运行额定，不能改写为 0 rpm 持续保持；温升测点、起始温度、安装散热边界和全封闭打印壳内降额尚不完整。用户手册 PDF p8 的环境 0–50°C 也不是整个温区恒扭矩保证。[原厂共享资料包](https://www.myactuator.com/_files/archives/cab28a_be98b58973d34f7aaa50bdf3f2aa12ed.zip)

同页另有 5–15 s 短时堵转数据；完整数值已在 JSON 按列人工视检记录。例如 RH25 的 162 / 216 / 256 N·m 对应 15 / 10 / 5 s、18 / 22.1 / 24.6 Arms，超过同页 157 N·m / 14.1 Arms 的目录峰值。RH17、RH20 也存在类似超出。两表的允许值、试验值及限流定义需澄清；**短时测量既不能替换较低目录峰值，也不能拼接成连续保持或重复工作循环**。RH14 的堵转电流亦可超过其目录峰值电流。

## 2. 抱闸与供电：已确认到模块接口层

用户手册 V1.4 PDF p27 §7.1 明确保持闸由模块自身 DC 连接器供电，无需另一路外部供电。因此本候选不新增“关节抱闸专用外供 24 V”。这不代表内部线圈就是 48 V，也不代表线圈电流、起动/保持 PWM、释放/接合时间已经公开。[用户手册下载入口](https://www.myactuator.com/downloads-rhseries)

| 型号 | 手册表 7-1 静态制动力矩 N·m | 可用结论 |
|---|---:|---|
| RH25 B | 1.2 | 表内未明电机侧/输出侧，不能乘 100 得到保证输出保持 |
| RH20 B | 0.8 | 同上 |
| RH17 B | 0.5 | 同上 |
| RH14 N | 通用 RH14 行为 0.2 | **对当前 N 版不适用**；不能补成 J7 抱闸能力 |

手册 PDF pp27–28 定义其为静态保持闸，并限制高载、高速动态制动；其寿命次数没有配套载荷、速度、能量或磨损后最小保持条件，不能作为整机急停验收依据。尚缺失电自然接合时间、欠压下动作、释放前建立转矩条件、故障时顺序、机械到位反馈及允许停止能量。J7 N 版失电后不能靠减速器摩擦或软件位置环保持姿态。

## 3. 电源、端口和针脚证据

共同电源是 48 V DC，产品允许范围 20–55 V；手册 PDF p24 警告超过 55 V 可损坏驱动。产品脚注还限制高于标称电压时不超过额定转速。实际电源调节误差、制动回馈、开关过冲必须共同落在边界内。

| 项目 | RH14 N | RH17 B / RH20 B | RH25 B |
|---|---|---|---|
| 原厂电源附件称谓 | XT30(2+2) | XT30(2+2) | XT30U-F |
| 随附电源线 | 18 AWG，200 mm | 18 AWG，200 mm | 14 AWG，200 mm |
| EtherCAT IN / OUT | SH1.0 mm 4 pin，附件线 480 mm | 同左 | 同左 |
| CAN / 多圈电池附件 | GH1.25-2P | 同左 | 同左 |
| BAT± | 有，多圈记忆电池用途 | 有 | 有 |
| RES± 泄放口 | **无** | 有 | 有 |
| 外部独立抱闸控制/供电针 | 无公开端口定义 | 无公开端口定义 | 无公开端口定义 |

以上来自四份产品册 PDF p2 及用户手册 PDF p25。`SH1.0` / `GH1.25` 是原厂目录称谓，未获得连接器制造商完整料号、镀层、锁扣和压接端子受控图。接口图给出 DC±、CAN_H/L、BAT±、RES± 与 EtherCAT T+/T−/R+/R−；图中左右排列已保存，但图示编号只是引出标号，**不直接等同于连接器 pin 1–4 或线侧视图**。制作线束前仍需实机标签、键位和对插面受控图。RES 是泄放电阻接口，BAT 是多圈记忆电池口，均不得接成抱闸外供电。EtherCAT 屏蔽双绞要求在手册 PDF p27。

额定/峰值 A rms 是电机电流资料，短时表明确为相电流，不能相加为 DC 母线电流。公开资料没有给出七轴同时运行 DC 需求、启动/抱闸瞬态、最低泄放电阻、斩波器连续/峰值电流与能量、开启阈值和滞回。手册 PDF p24 的 **1000 µF / 100 V** 只是开关上电过冲参考；pp29–30 的电阻、电容、电池是原理方案，不能代替本臂再生能量和器件定额计算。RH14 无 RES 口，必须在公共母线层解决其回馈；不能认为其供电模块天然吸收回馈。

Setup Software 截图可见过/欠压、堵转时间和抱闸 duty 配置项，但空白截图不提供出厂数值或写入许可。当前 [电气候选表](hardware/electrical-camera-candidates.md) 的 RSP-1000-48 仍是容量候选，未由此次审查获得停止能量或同时率验证。

## 4. EtherCAT：公开 ESI 已取得，实机适配仍待核

本次新增确认了 [英文 ESI 下载页](https://www.myactuator.com/downloads-ethercatesi) 与 [中文协议下载页](https://www.myactuator.cn/downlaodrj)：`MT-Device_260424.xml` 对应网页所列固件 `26042402`。英文、中文 ZIP 字节相同；XML SHA-256 为 `e102e7cbbff93480f7d2e5008b3031b034107f3ce2dead9349d80d48bacf2362`。XML 可解析，含 79 对象、CoE/PDO 配置与 FoE 描述，尚未做 XSD、EtherCAT 主站或实机验收。旧 `250702` XML 仅 40 对象，不能混用配置。[官方新版 ZIP](https://www.myactuator.com/_files/archives/cab28a_f94084d537ab4cbf87d90bd780e7120f.zip)

两版均只有通用 `MT_Device`，没有四个精确订货型号条目。新版顶层 Vendor `0x202008`、ProductCode `0`、Revision `0x00010000`；其 `0x1018` 默认字节却对应 Vendor `0x282`、Revision `0x10`。这是模板内不一致，不能据任一默认值伪造实机身份。需读取每台从站身份、实际硬件/固件、PDO 和单位后，再锁定匹配文件。[原厂固件页](https://www.myactuator.cn/gu) 要求联系销售取得最新固件，本次未联系、未取得受控固件或刷写。

| 运行接口 | 公开证据与边界 |
|---|---|
| 驱动使能 | 协议 V2.0 PDF pp11–12、17–18：`0x6040` 控制字、`0x6041` 状态字，状态机使能；实施前必须按返回状态推进，不能以固定延时发送命令串 |
| 运动与反馈 | 默认 Rx `0x1600` 含控制字、位置/速度/转矩目标、最大转矩、模式；Tx `0x1A00` 含状态、位置/速度/转矩反馈、`0x603F` 错误与模式反馈；具体字宽见 JSON |
| 温度/电压 | `0x2009` 电机温度、`0x200C` 驱动温度、`0x200A` 电压存在；单位、测点与实际保护阈值必须对应协议/固件核实 |
| Quick stop | PDF p50 在 Operation Enabled 状态下给 `0x6040=0x0002`；在 `0x605A=0` 时按 `0x6085` 减速后进入 Switch On Disabled。这是该厂文档定义，不能换成未经核验的通用 CiA402 假设 |
| 故障响应 | `0x605E` 有对象，但本次检查的协议和 ESI 未提供支持值与完整动作/时序表；XML 原始默认 `2000` 按小端是 32，不能误读成 2 |
| 故障复位 | PDF pp12、55–56 说明 `0x6040` bit7 上升沿 / `0x0080` 触发系统复位，运行参数回到默认后需重配；不能假定复位后保留全部限值 |
| 抱闸 | 最新 XML 与协议未找到抱闸命令或状态对象；未证明 `0x6041` 提供机械抱闸到位反馈 |
| 失联、看门狗与停止安全 | 缺完整时限和转矩/抱闸反应表；未取得 STO / SBC / SS1 / FSoE 认证及硬接线端口证据。普通 PDO Disable / Quick stop **不是 STO** |

CAN 是单独的接口证据：共享包中的 CAN V4.4 PDF pp131–133 给 `0x77` 释放、`0x78` 锁闸，并称失电状态为锁闸；但没有接合时间。PDF pp53–54 的 `0x9A.DATA[3]` 只回读控制指令状态（1=释放、0=锁闸），不是机械到位反馈。PDF p68 要求带闸型号在 `0xA1` 转矩指令前另发 `0x77`；pp138–139 的 `0xB3` 是 CAN 超时保护，0 禁用，文档称超时切断输出并锁闸。**这些不能自动映射为 EtherCAT 对象、EtherCAT 断线反应或 N 型的抱闸能力**，仍需确认所购固件和双总线控制仲裁。[CAN / EtherCAT 原厂共享包](https://www.myactuator.com/_files/archives/cab28a_be98b58973d34f7aaa50bdf3f2aa12ed.zip)

协议页码与 XML 对象字段已列入 JSON；新 XML 的 `0x200D…0x2011` 在协议 V2.0 中未找到对应说明。额定电流等 XML 默认零值属于模板，不是型号电流额定。[协议包](https://www.myactuator.com/_files/archives/cab28a_be98b58973d34f7aaa50bdf3f2aa12ed.zip)

只读检查官方中文站 `IGH 260620` 样例还发现 `main.cpp` 填充 PDO 仍用 `0x5FFE`，新版 ESI 则为 Rx `0x2FFD` / Tx `0x2FFE`；样例 `quick_stop` / `fault_reset` 标志的设置未在主循环消费。该样例未执行，不能直接作为本项目的停止实现或验收工具。[官方 SDK ZIP](https://cloud-1251007531.bcdn8.com/maita0712/uploads/20260630/MyActuator_IGH%283%29.zip)

## 5. 输出螺孔：图纸名义深度仍不足以冻结长度

统一坐标为输出安装接触环面 `z=0`、向外为 `+z`。孔阵已从原厂 STEP 独立提取，见 [接口证据](sources/rh-interface-extraction.json)。下列 STEP 数值是已核光孔段，不是保证牙段。

| 精确候选简写 | 图面孔阵 | 图面螺纹深度 | 图面避让孔深 | STEP 已核光孔段 |
|---|---|---:|---:|---|
| RH25 B | 16×M4，PCD77 | 6 mm | 13 mm | Ø4.4，z=−3.5…0 |
| RH20 B | 16×M3，PCD62 | 6 mm | 10.5 mm | Ø3.4，z=−3…0 |
| RH17 B | 16×M3，PCD54，非均布 | 6 mm | 9.6 mm | Ø3.4，z=−3…0 |
| RH14 N | 8×M3，PCD44，非均布 | 5 mm | 9 mm | Ø3.4，z=−3…0 |

依据各型号选定 B/N 的 2D-A / 2D-A0 图 PDF p1 和配对 STEP，哈希在 JSON；[官方下载入口](https://www.myactuator.com/downloads-rhseries)。**不能把避让深度减名义牙深，当作满牙起点；不能把光孔段与牙深相加，就当作最大允许插入。** STEP 未建真实螺纹，且名义深度可能包含钻尖、导入与不完整牙。需要按版本给出有效满牙起/止、盲孔底及内部旋转件最小间隙、最大总深入量。

用户手册 PDF p23 表 4-1 的通用 M3×0.5 / M4×0.7 扭矩分别为 17 / 40 kgf·cm，即约 1.667 / 3.923 N·m，并要求螺纹胶、分阶段对角紧固。表未充分限定螺钉等级、摩擦、母材和胶型，不能据此放行本项目薄转接环或未知有效牙长。当前 OEM 输出螺钉长度继续保留 TBD；已做装配几何检查不能替代啮合强度与防顶底确认。
