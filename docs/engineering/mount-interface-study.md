# R4 J1 与 J7 真实安装接口研究

本研究使用本地原厂 **RH-25-100-E-B-D 3D-A0.STEP / 2D-A0.PDF** 和 **RH-14-100-E-N-D 3D-A0.STEP / 2D-A0.PDF**，核对接触平面、真实孔位、壳体穿出、原装螺钉和工具轴向通道。坐标与 [统一接口提取](sources/rh-interface-extraction.json)一致：输出安装接触面的轴心为原点，+Z 朝输出，X/Y 保留厂商 STEP 装配相位。

**已得到三个可复现的自制适配件候选，尚未制造放行。** 正确候选与原厂每个实体逐一求交，没有发现名义几何穿透；强度、螺纹剥离、预紧、装配公差与实物配合仍未完成。J7 原厂 M3 的完整螺纹起点证据不足，螺钉长度明确保留未选状态。

[三页安装与剖视图](../../engineering/generated/mount-study/ODR-mount-interface-study.pdf)和[机器可读证据](../../engineering/generated/mount-study/evidence.json)是本研究的对应输出。原厂 CAD 和二维图仅在本地使用，没有随仓库再次分发；输出 STEP/STL 是重新构造的三个原创候选。

## 来源与追溯

原厂文件来自 [MYACTUATOR RH 下载页](https://www.myactuator.com/downloads-rhseries)：[RH25 CAD 包](https://www.myactuator.com/_files/archives/cab28a_bc732701dadf4512a0d917ecaab12747.zip)、[RH14 CAD 包](https://www.myactuator.com/_files/archives/cab28a_bcc022d169b448ff82894171aa9ae1ce.zip)。两个二维图均为 A0 修订、第 1 页。`evidence.json` 记录输入 STEP/PDF 文件名与 SHA256、原厂面索引、接触面的圆边界、孔轴坐标、逐实体碰撞事件及原创导出文件 SHA256。

原厂二维图题名是尺寸参考/电机装配图，未给出客户支架的平面度、允许预紧、紧固扭矩、疲劳寿命或唯一指定的安装基准；本文件不能替厂商补出这些指标。

## J1：RH25-B 固定侧接到底座支架

### 两侧真实接触平面

| 几何 | joint frame 数值 / mm | 可以说明什么 |
|---|---:|---|
| 固定侧前接触面 | z = −15.5 | 朝输出方向的一面，可从 +Z 侧接近 |
| 前面同轴边界 | r = 48.0～54.2 | 局部有孔/倒角，不能当完整实心圆环 |
| 固定侧后接触面 | z = −45.7 | 朝电机后壳的一面，本候选的基准 A |
| 后面同轴边界 | r = 47.4～54.7 | 内侧由 Ø94.8 后壳穿出 |
| 固定孔贯穿轴向距离 | 30.2 | 两接触面间距，不是螺纹深度 |
| 后壳外径 | 94.8 | 不能只按中央线缆孔给底板开孔 |
| 后端最低包络 | z = −103.2 | 低于本候选后环底面 47.5 |
| 可用固定孔 | PCD102 / 8×Ø4.5贯通 | 使用独立提取的 30/60/120/150/210/240/300/330°孔位 |

后接触面可以连接带中央避让的环形支架；前接触面可以连接压环或支架，但必须避开输出端的 Ø85 外圆及四颗已有装配螺钉。两面均是几何可接近候选，未把其中一面宣称为原厂唯一指定安装面。

四个角度为 0/90/180/270°的既有装配螺钉保持原状，不拆用、不改作本次八个固定孔。另有 CAD 内部孔/台阶，不因为圆心在同一个 PCD 上就视为可用固定孔。

### 自制后环和前压环

| 候选 | 材料假设 | 尺寸与轴向位置 | 孔位 / 作用 |
|---|---|---|---|
| ODR-J1-REAR-R4 | 6061-T6 | Ø150 / 内径95.4 / 厚10；z=−55.7～−45.7 | 原厂八个孔对应 **M4×0.7 通孔螺纹**；CAD 先表示 Ø3.3底孔 |
| ODR-J1-FRONT-R4 | 6061-T6 | Ø116 / 内径90 / 厚4；z=−15.5～−11.5 | 8×Ø4.5螺钉通孔；4×Ø7.6孔避开既有螺钉头 |

后环内径95.4相对后壳94.8，名义直径间隙0.6。它是避让孔，**不是已经冻结的定位配合**。后环还提供 4×Ø6.6 通孔，PCD130，角度45/135/225/315°，用于连接后续支架。对应中心是 `(±45.96194, ±45.96194) mm` 的四种组合。

前压环扩大螺钉头的自制承压面，同时保留原厂螺钉头让位。前环不承担“覆盖掉原厂装配螺钉后继续拧紧”的作用。实际接触只发生在原厂平面上，超出平面的径向区域是悬伸，必须在后续预紧与局部弯曲分析中考虑。

螺钉从 +Z 侧沿 −Z 穿过前压环4 mm、原厂固定法兰30.2 mm，再进入自制后环10 mm螺纹。原厂的八个安装孔为通孔，本方案**不假定这里有原厂 M4 螺纹**。

[Accu SSC-M4-45-12.9](https://www.accu.co.uk/metric-cap-head-screws/16031-SSC-M4-45-12-9)可作为几何候选：M4×45，螺距0.7，头径上界7.22、头高4、最小螺纹长度20。名义夹持总厚 `4+30.2+10=44.2 mm`，45 mm杆长在自制后环背面伸出0.8 mm。最后20 mm外螺纹覆盖自制后环所在区间，不会把光杆误当啮合段。本次已用 Ø7.22×4 的头部包络核验，而不是只按名义7 mm判断。

这个长度只对**本文件定义的无附加垫圈结构**成立。完整有效啮合仍要扣除内外螺纹导入、倒角及末端不完整牙，并核对实际螺钉和材料强度。前后环厚度、公差、表面处理或垫圈一旦变化，应重新计算。尚未选定预紧扭矩或批准强度等级，不把商品存在等同于紧固设计放行。

后环总质量按密度2700 kg/m³估计约0.279 kg，前环约0.042 kg；这是候选 CAD 体积换算，未包含螺钉和底座支架。后环属于固定底座结构，不能重复加入 J1 输出侧运动质量。

### 仍需完成的桌面连接

电机后壳穿过后环并再向后伸出47.5 mm。桌面支架必须形成开放支腿、筒形空腔或桌面开口，另给出接插件、线缆弯曲和维护空间。不能把这片安装环直接压在未开槽的平桌面上。本次外侧四孔提供支架连接界面，**完整支架、桌面锚固及抗倾覆能力未定版**。

后壳与 PCD102 孔很接近；在后方随意增加标准垫圈、螺母或套筒工具可能与后壳相碰。本候选使用自制后环螺纹以避免默认存在螺母空间，但这也要求后续检查靠内径一侧的薄边螺纹强度与拉脱。

## J7：RH14-N 输出到可拆头法兰

### 已核实的原厂界面

输出接触面 z=0，平面的同轴边界为 r18.5～24.7，另有八个孔及两处原装螺钉附近的外缘缺口。因此它不是完整的 Ø50 实心平面。中央凸台 Ø37，高2，只作为本候选避让对象；外侧定位圆柱 Ø50 h6 的直线段是 z=−3～−0.3，二者不能混用。

八个可用输出孔在 PCD44 上且非均布，中心详见[坐标 CSV](../../engineering/generated/mount-study/J7-output-hole-coordinates.csv)。它们从 +Z 侧向 −Z 接近。两个原装螺钉及其它内部孔不计入这八孔。

### 自制候选 ODR-J7-TOOL-R4

| 特征 | 候选值 / mm | 目的 |
|---|---:|---|
| 外径 | 70 | 提供外侧头部连接区域 |
| 主板 | z=0～6，厚6 | 在原厂输出面支承 |
| 中央贯通孔 | Ø37.6 | 避开 Ø37×2 中央凸台 |
| 后裙 | z=−2.5～0，内径50.05 | 避开/围绕原厂 Ø50 外圆，直线重叠长度约2.2 |
| 后裙孔候选公差 | 50.05 +0.02/0 | 名义径向间隙0.025；不宣称高精度重复定位 |
| 原厂螺钉通孔 | 8×Ø3.5，真实孔坐标 | 保留非均布图案 |
| 前间隔环 | z=6～10，内径52 | 为 M3 螺钉头留下空间 |
| 头部接触面 | z=10，r26～35 | 保持当前 J7 到头部的10 mm距离 |
| 头部接口 | 4×M4×0.7 通孔螺纹，PCD60、0/90/180/270° | 用螺栓拆装头部；不是已定版快速锁扣 |

材料候选为6061-T6；体积换算质量约0.073 kg，未包含螺钉。若后续纳入整机质量预算，需要明确它属于 L7 还是末端预算，避免重复记账。

前环内径52大于八个螺钉头的外径向边界，头部接触面比 M3 头顶高约1 mm。[Accu M3 规格页](https://www.accu.co.uk/metric-cap-head-screws/16008-SSC-M3-20-12-9)确认该头型直径上界5.68、高3；本次按更大的 Ø6×3.2 包络检查。引用该页面只用于头部尺寸，**没有选用该页面的20 mm杆长**。

后裙不是新的零速承载证明。后续须定义配合、公差链、同轴度、摩擦传矩、接触压力与止转方案。前部四个 M4 是本项目自制螺纹，CAD 用 Ø3.3 底孔表达，非已经建模的螺旋牙。头部侧螺钉进入适配件的长度暂限制不超过8 mm，以避免伸入后方；真实头部板厚和紧固件仍需匹配。

### M3 螺钉长度为什么仍未选定

原厂2D-A0第1页写 `8× Ø3.4 沉入9 / M3深5`；本地 STEP 的圆柱证据如下：

| 区域 | 孔径 / mm | 轴向区间 z / mm | 解释 |
|---|---:|---:|---|
| 前盖通道 | 3.4 | 0～−3.0 | 前盖实体中通道 |
| 深部通道 | 3.5 | −3.0～−9.0 | 名义螺杆自由穿入区 |
| 过渡区域 | 不单独冻结 | −9.0～−9.6 | 不能擅自当完整螺纹开始 |
| 最近底孔圆柱 | 2.5 | −9.6～−17.5 | M3底孔几何，没有真实螺旋牙型 |

完整有效螺纹始端、导入牙、末端不完整牙、钻尖/盲底余量及相应公差未被分别定义。`L=6+d+e` 中，6是本候选螺钉座到输出面的距离，d是**完整有效螺纹起点深度**，e是要求的有效啮合；当前不能把9、9.6或17.5中的一个数随意代入并宣称螺钉长度已验证。M3深5也不能解释为从输出表面开始已有5 mm螺纹。

八个前孔与最近底孔的 STEP 轴线横向偏差为约0.0289～0.1081 mm。证据包含每对孔轴坐标和原厂面索引。它可能与厂商装配模型简化/相位有关，但当前没有证据确定原因；须让供应商解释，并用实物销规/螺钉对中检查。不能因为外观装配图看起来同轴，就忽略这个差异。 将自由杆段改为沿最近底孔轴线放置后，与原厂部件及自制适配件的逐实体相交仍为0；按前通道Ø3.4、杆径3.0和最大偏移保守估算，名义径向余隙仍约0.0919 mm，尚未扣制造公差。这只说明这份CAD的自由通道仍可通过，不消除实际螺纹起点和装配偏差的核验要求。

## 干涉与通道证据

所有碰撞均以原厂 STEP 转到统一 joint frame 后，**逐候选实体与每个原厂实体求交**。RH25 有42个实体，RH14有32个实体。本次发现，直接对原厂 Compound 执行一次 `intersect()` 可返回0，却漏掉原装螺钉头的真实相交；脚本因此禁止使用这一结果作为无碰撞结论。

| 检查 | 逐实体相交体积和 / mm³ | 结论 |
|---|---:|---|
| 错误后板：仅Ø22.6中央孔 | 66,881.60 | 大量穿透后壳/内部实体，拒绝 |
| 错误前环：未给原装螺钉让位 | 553.52 | 与4个螺钉头各相交138.38，拒绝 |
| 正确后环 | 0 | 当前名义 CAD 未发现穿透 |
| 增让位后的前压环 | 0 | 当前名义 CAD 未发现穿透 |
| 八个 M4×45杆部 / Ø7.22×4头部 | 0 | 原厂部件范围内通道通过 |
| J7适配件及未开孔的轴对称外廓 | 0 | 支持外廓旋转避让，仍不证明完整工具总成可达 |
| 八个 M3 头部 Ø6×3.2 / 自由杆段至z=−9 | 0 | 只验证头部及自由通道，不验证螺纹啮合 |
| 两处 Ø6 轴向工具包络 | 0 | 不包括完整工具手柄、线束和后续装配遮挡 |

“相交体积和”是所有相交实体对的体积累加，用于检测；原厂零件若彼此重叠，可能重复计数，因此不把该值当材料并集体积或加工去料量。判定阈值为1e−4 mm³，几何容差与实物间隙仍要独立检查。

本次没有将螺钉的理论实体强行穿进未建模的螺纹底孔，然后把这类必要啮合错误标为干涉；M3杆段只验证到已确认的自由通道末端。反过来，也没有因为底孔存在，就证明螺纹长度、牙型或承载合格。

这些文件是名义几何候选：STEP/STL没有螺旋牙型、通用倒角/圆角或表面处理；DXF 是平面特征及底孔参考，轴向台阶以 STEP 和剖示说明为准。尚无完整尺寸公差、基准形位、接触面粗糙度、螺纹检验、倒角控制及紧固预紧定义，不应直接作为金属加工放行包。

可先以 PLA/PETG 打印检查尺寸与工具进入，禁止用这些未经承载验证的打印件进行动力运行、悬挂工件或承担机械臂重量。金属候选6061-T6只是材料方案，仍要根据预紧与疲劳校核决定保留或更换。

[mount_interface_study.py](../../engineering/mount_interface_study.py)需要 CadQuery、NumPy、trimesh、ezdxf、reportlab、pypdf 和中文 TrueType 字体；第三方文件必须由本地命令行参数传入，脚本没有用户机器路径硬编码：

```sh
python engineering/mount_interface_study.py \
  --rh14-step /path/to/RH14-N.step \
  --rh25-step /path/to/RH25-B.step \
  --rh14-drawing /path/to/RH14-N-2D.pdf \
  --rh25-drawing /path/to/RH25-B-2D.pdf \
  --font /path/to/Chinese-font.ttf
```

脚本校验原厂 STEP 哈希与接口提取记录匹配，再提取证据、逐实体求交并导出本项目零件。三件均通过有效单实体、STEP重读体积、STL水密及DXF重读审计；三页PDF已逐页渲染检查。下一步要取得螺纹有效深度/允许预紧的明确证据，完成实体试装，再进入受力、公差与完整底座/头部装配设计。
