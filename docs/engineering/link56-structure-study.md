# J5 → J6 金属连接候选：R4-LINK56-01

状态：独立结构候选，**不用于制造放行、整机负载验收或采购下单**。六个原创零件构成实际接触链，已取消原 L5 斜梁对 J5/J6 壳体的交叠。本研究保留 R4-layout-03 的所有关节原点和轴向，不修改共享总装。J5 输出螺钉的有效螺纹证据仍不完整，因而整段连接尚不能投入带载使用。

输出孔坐标取自真实 STEP，不使用均布阵列替换 RH17 的孔位。中央 Ø47.6 孔仅避让原厂 Ø47 高2凸台，**不是定位配合**；本候选不宣称法兰同心度已靠该孔保证。孔位需要对实物进行 CMM/样片核对，再决定定位销或另设定位界面。

梁从实体料铣出通腔，不直接把未经验证的市售方管内圆角当成模型尺寸。插头建议尺寸 `0/−0.05`，内腔 `+0.10/0`，每侧名义间隙0.10；这些是待制造评审的提案。平面接触承担压载，螺钉和孔壁承担装配后的拉载/剪载；间隙导致的滑移、预紧摩擦和孔口局部应力仍需计算与验证。75mm深通腔与R3内角需要评审刀具伸出和双面加工接刀，不能默认任一普通加工店均能达到提案公差。

原厂前装配螺钉头实测包络 Ø5.5、高2.9，PCD74四个正交位置。前环的 Ø6.2让位孔不借用这些螺钉进行固定。后壳实测半径33.5，后环ID67.6提供单边0.30名义避让。后环最高世界 Z647；不能据此直接宣称所有未来末端零件都有3mm安全间隙。

装配顺序已具体化：

1. J7、头部和相邻连架尚未安装。先将 OUT 固定在 J5 输出面；该步骤必须等原厂输出螺纹和M3长度确认后才能真实紧固。
2. LOW从+Z方向落下，其底面让位孔套住输出螺钉头，用四颗M4×16固定。
3. 闭口梁从+Z插入下插头16mm，装下部四颗侧M4×12；再从+Z装上端块，装上部四颗侧M4×12。
4. 带脚后环从+Z落在UP，用四颗M4×20紧固。必须在安装J6之前操作该组上向螺钉。
5. J6整模块从+Y方向穿过后环，至固定后接触面；从+Y装前环，再装八颗M3×40夹持。
6. 后续再装 J6→J7 连接与头部。本研究的直杆工具路径不能推广为整机组装后的维护可达性。

工具检查使用 M3 直杆Ø4×60、M4直杆Ø5×60；它证明指定阶段的直杆通道，不包含扳手横柄、扭矩扳手头、手指或电缆。每个插入步骤按0、0.1、0.5、1、2mm与后续每5mm离散检查，同时包含此前已安装的紧固件；不是连续扫掠无碰撞的数学证明。

## 受力筛查的边界

载荷源为 R4-layout-03，净工件2kg；头部质量分别取2/3.5/4/4.5kg。头COM暂仍为 `[0,55,760]`，不是新末端CAD实测值。用本研究六件6061体积质量替换旧L5的0.5kg预算，另加0.10kg紧固件/局部线束预算，其他连杆和关节仍沿用原质量/COM模型。

对每个候选截面，位于J5→J6刚体上的质量采用该截面至COM的实际直线距离；J6以后质量采用截面→J6→后续轴→COM的路径长度三角上界。取各截面最大值作为共同静力矩筛查量，追加工件COM100mm和头COM50mm，再乘研究系数1.5。这个系数不是标准规定或经风险评估确定的安全系数。该矩是**全三维重力矩大小的距离上界**，不是把某轴电机输出力矩直接当整个连接的弯矩。

梁使用75mm悬臂梁敏感性模型；取侧孔中心截面的最小惯性矩沿全长计算，`σ=M·30/Imin+F/Amin`，`δ=M L²/(2 E Imin)+F L³/(3 E Imin)`。几何切片来自真实原创CAD，带孔区已扣除；没有覆盖连接微滑、螺钉接触和孔口应力集中。另列不带孔的梁中部薄壁闭口扭转敏感性，取中线57×37、壁厚3、假定泊松比0.33；不能将它推广为带孔梁端的扭转/翘曲上界。

四角M4、固定侧8个M3及输出16个M3用真实非均布坐标的二阶矩阵进行等刚度螺钉组拉力分配；代码以361个力矩方向反算合力矩校验分配公式。侧M4另外按管壁中面 `[X±28.5,Y±10]` 的四点组计算剪力；用4×3mm的投影面积筛孔壁承压，并以 `2×(8−2.25)×3` 估算梁端剪出平均应力。它们都是需求值与局部平均应力，不是螺纹/螺钉/管壁的已验证允许值。

输出板采用宽12mm、厚6mm的径向条带；后环采用两条8.2×14mm直腿作敏感性近似。**这些不是已证明保守的实际板或曲环应力上界**，必须补接触FEA、螺纹拉脱/劈裂、疲劳和实物载荷测试。未选择预紧扭矩；摩擦系数0.08/0.15/0.20只用于展示所需夹紧力对摩擦的敏感性，不当作实测摩擦。

材料暂按 [thyssenkrupp EN AW-6061 数据表](https://ucpcdn.thyssenkrupp.com/_legacy/UCPthyssenkruppBAMXUK/assets.files/material-data-sheets/aluminium/aluminium-6061.pdf) p2～3 的适用T6板/棒范围、E=70000 N/mm²与ρ=2700kg/m³；数据表的屈服值不能代替螺纹连接设计、表面处理验证或材料批次证书。关节厂家额定运行扭矩不能当零转速持续保持力矩，也不证明输出轴承倾覆/轴向能力。

## 内走线与3D打印

OUT的Ø47.6仅用于凸台避让；LOW中央Ø20，梁内腔54×34。UP改为局部 `[0,-5]` 的Ø16贯孔，对应世界Y−60；后环脚同位置Ø16出口避开14mm后环根部。最窄原厂过孔仍是RH17的Ø12。上端出口不能证明插头外壳、线束弯曲或关节运动期间没有夹线；接头选型与实际可穿尺寸仍需验证。

金属STL可作尺寸参考。早期打印只用于手动、无载的孔位/装配顺序试验；建议PLA/PETG、层高0.2mm，平板/端块以大接触面朝平台，梁竖直，后环以侧面朝平台并在试切片时确认支撑。任何打印方向、填充比例、塑料螺纹都未做承载认证。原厂关节应由独立支撑托住，不能把2kg工件挂在打印件上用来“验证”这些金属计算。先校准打印缩放、孔径及插头间隙；不要靠拧紧强行纠正孔位。

## 复现

工程Python环境须安装仓库 [requirements-lock.txt](../../engineering/requirements-lock.txt) 所列依赖。第三方CAD自行从 [MYACTUATOR RH下载页](https://www.myactuator.com/downloads-rhseries) 获取，必须与接口提取JSON中的SHA一致。示例路径都是占位参数，脚本没有硬编码下载目录。

```bash
python engineering/build_link56_study.py \
  --rh17-step '/local/vendor/RH17.step' \
  --neighbor 'RH14-N=/local/vendor/RH14.step' \
  --neighbor 'RH20-B=/local/vendor/RH20.step' \
  --font '/local/font/Chinese.ttf' \
  --private-assembly '/local/private/link56-with-vendor.step'
```

原来的 `work/r4-link-interface-study.py` 和 `work/r4-link-extra-probes.py` 已整理为可复现的 [link_interface_tools.py](../../engineering/studies/link_interface_tools.py)，保留非均布接口、分裂接触面、solid-pair common、最小BREP距离、J1板厚敏感性等算法，并将第三方路径改成CLI输入。输出新原始测量结果，不覆盖经过注释的 `link-interface-plan.json`：

```bash
python engineering/studies/link_interface_tools.py \
  --model 'RH14-N=/local/vendor/RH14.step' \
  --model 'RH17-B=/local/vendor/RH17.step' \
  --model 'RH20-B=/local/vendor/RH20.step' \
  --model 'RH25-B=/local/vendor/RH25.step' \
  --output '/local/work/reproduced-link-measurements.json'
```

[part-placements.json](../../engineering/generated/link56-study/part-placements.json) 记录各原创件局部坐标至世界坐标的刚体变换及体积估算COM；所有件均属于 J5 后、J6 驱动前的刚体质量，供下一轮预算整合使用。

公开目录只含我们原创的STEP/STL/DXF/PDF、坐标表与尺寸证据；第三方STEP总装只能写到仓库外，脚本会拒绝将它导出进仓库。此研究源稿及原创CAD依项目 `CC-BY-NC-4.0` 使用，归属 Auromix contributors；原厂资料仍归原权利人。
