# HEAD-INTEGRATED03 — 独立整头接口集成候选

本轮把 CARRIER02 钢根/窄舌、LED-POCKET01 灯腔、CONTACT02 带保持键软垫、FPL01 电路机械快照和 EXT24 延伸环装进同一个可复算模型。它是实际名义实体与明确供应商包络组成的 MCAD 研究，**不是制造放行、电子定版或 2 kg 抓取验收**。不修改 R4-layout-03 和其他历史模型。

## 当前结论

- 上片 0…109°、下片 0…122°，四根轴仍独立，轴位置和主体四瓣比例保持。x＜25 mm 近根实体与 CARRIER02 对称差为数值零；x＞25 mm 已实际合并灯腔和软垫保持孔。
- 四片各自全部名义实体两两检查没有非预期穿透。12 颗 M2 螺钉的名义大径与 Ø1.6 mm 底孔有预期螺纹区域交集，单颗 3.392920 mm³；它不是攻丝、预紧和剥牙验收。
- C1/C2 下方两个局部浅口把底面从 Z1.9 降到 **1.8 mm**，增大包络每边留 0.25 mm、竖角 R0.25；电容最低 Z2.05，名义间隙 **0.25 mm**。单片新增去料 1.845576 mm³，没有削薄整片底板。
- GH 完整配对参考框与金属最小距离 **0.875 mm**。这只检查目录参考框；未取得受控配对 3D、公差、插拔工具/锁扣行程及真实线束弯曲模型。
- 重新检查的连续包络：自身同轴支承最小 **1.00 mm**，四独立模块分离下界最小 **2.039835 mm**，GH 框对本路 P16 下界 **29.724998 mm**。结果覆盖本报告快照及指定角域；实际变形、制造/装配公差和线束不在证书内。
- 按新装配每一件重新求和，可计量模型 **2.802491 kg**；完整头部规划为 **2.987…3.252 kg**。后者包含独立未选型预算，不是已实现净重，也不包含 J7 电机、工件和机械臂。

## 坐标与零件归属

所有 STEP 和 GLB 的几何都是 **head face 局部坐标**。STEP 单位 mm；GLB 单位 m。home 装配只加世界平移 `[0,55,804] mm`，没有额外旋转。原 J7 轴原点仍 `[0,55,640] mm`，在新头坐标为 `[0,0,-164] mm`，夹持 TCP 参考世界 Z914。不能把本版 COM 直接套到旧 face Z780。

| 接口 | head Z / mm | world Z / mm | 说明 |
|---|---:|---:|---|
| 原 J7 输出接触面 | −164 | 640 | 轴原点不变 |
| 原 adapter 主板 | −164…−154 | 640…650 | 沿用原件，不随头前移 |
| adapter 含定位唇完整名义范围 | −166.5…−154 | 637.5…650 | 网格包围盒含导入数值膨胀，另见 manifest |
| EXT24 | −154…−130 | 650…674 | 新环；其余原头部整体前移 24 mm |
| 载体原后部主板 | −130…−122 | 674…682 | 保持旧头部局部坐标 |
| 四 M4×40 长螺钉 | tip −161.2；头顶 −117.2 | 642.8…686.8 | 4.7 g/颗目录质量；保持原 7.2 mm 几何啮合 |
| face | 0 | 804 | 上指根 Z0，下指根 Z50 |

上/下根半径 R70，方位角依次 UR35°、UL145°、LL225°、LR315°。正闭合轴为 `[sinφ,-cosφ,0]`。`*_rotor` 含指轴、钢根、片、灯板与软垫；`*_P16_kinematic` 单独按两销构形。**两态网格都已烘焙各自角度，若继续动画应施加相对当前角的增量，不能给 closed 网格再次加绝对闭合角。P16 本体、导杆/滑杆不能整组刚性 parent 到指轴**。原始 P16 原生 CAD 不在公开导出中，使用已核对能包含其实体的原创包络。

## FPL01 与机械镜像契约

上下 PCB 各只需要一种板，左右实物采用刚体旋转，不能镜像电路。机械驱动模块继续左右镜像；灯片局部电路坐标保持 X 沿片长、Y 沿对应右手切向、灯面 +Z。为抵消既有机械装配函数的镜像，新板/器件和随板的非对称 C1/C2 浅口先作坐标补偿。四瓣外轮廓及光点仍左右对称；内部电容浅口跟随真实板上 −Y 位置。

- 板厚 Z3.6…4.4，轮廓/三个 Ø2.4 孔与 FPL01 budget 布尔对照一致。
- 上板 130、下板 42 颗 LED，共 344 颗。采用 FPL01 每个中心坐标，显示实体为 2.4×0.9 mm 焊盘/器件最大投影包络，Z4.4…5.3 含规划焊高 0.10；透明片 Z6.0…6.6，名义混光间距 0.7 mm。
- J1 原点 `(44.975,0,3.6) mm`，官方安装侧映射 `X=44.975+v, Y=u, Z=3.6−h`。配对参考框 X39.425…46.575、Y±7.875、Z−0.75…3.6；出线朝 −X。
- `JST_header_reference` 与 `JST_plug_reference` 只是把完整参考矩形沿 X42.525 分成两个显示实体；该分割不代表真实塑件接合面或原厂 CAD。
- C1/C2 中心 `(50,-5.5)` / `(50,-7.8) mm`，最大本体高 1.45 加规划焊高 0.10。普通背面器件采用已有 fit 研究的包络尺寸库及当前 FPL01 placement map 的位置/投影角，不沿用旧 fit 的摆放位置。
- 预留地铜/候选热接口区 X62…66、Y−7…−3 保留，但未放入热垫、金属台或紧固。此处板底到原腔底 1.7 mm；热传导/压缩和电气绝缘尚未设计。上板 U1 已移到 X80，该区距 IC 更远，不能沿用“已构建 IC 散热通路”的表述。

**电子状态：J1、C1/C2、LED、PCB 和热区的上述候选接口已协调；普通背面电容/电阻仍在布线调整。** 本报告检查的是 `inputs/` 下有 hash 的快照，不是最终路由板。本版已更新电气逃线后的普通件候选：上 U1 移至 X80、下普通件改到根部及 X68 区域；共上 17、下 11 个元件改变位置。更新清单见 `placement-update.json`。末轮 LED 地址/CS 分配和 BOM 备注同步记录在 `electrical-address-update.json`；逐字段检查保证 ref、中心、封装与 MPN 未变，因此只刷新快照及 manifest 的 LED_index，几何证据不变。当前上板 placement SHA-256 为 `ce1d003c3217865c5680b4a75b0bfb4e023af3071ead1003989b4ad51f6e34d8`，下板为 `b0a7ff7bfe5c660ff2055e1d872858a5ab2e2e86154f06111f349461eb2440aa`。这仍是正在布线的候选放置，不是成品电路；若再变动不得自动继承这一结果。`input-snapshot.json` 记录来源和复制哈希；脚本默认不覆盖快照，显式 `--refresh-inputs` 后必须重新导出并检查。

## 软垫与安装边界

8 个真实软垫实体均包含穿透式保持键，每垫 549.667027 mm³；DS30 候选密度 1.08 g/cm³ 下 8 垫约 4.749 g。孔与键在灯片金属中配合，保持键完全位于原 CONTACT02 外部包络内。保留原始远端接触面，不用视觉贴块代替实际扣合。

它仍是浇注成型候选，不能将增大的背端直接从小孔压过。键根撕裂、剥离、剪切、疲劳和材料老化未试验；没有计入胶接承载。板上 3 颗 M2、绝缘环与螺钉头已实体化，但绝缘环材料/公差、PCB 压紧力和灯面透明片的保持框未定。拆装路径继承的范围只限未变根部/后架；GH、整块电路和透明片完整拆装尚未形成放行证据。

## 运动证据及继承边界

新金属、PCB、普通元件、LED 和带键软垫均逐件与 CARRIER02 旧远端外包实体求布尔差，外溢体积不超过 1e−4 mm³。GH 配对框单独加入运动集合。随后用该保守集合重算本路/其他固定物和四路独立角域，不把开/闭两帧当作全角域证明。

| 检查 | 连续下界 / mm | 范围 |
|---|---:|---|
| 本路同轴壳 | 1.000000 | 旋转不变包络，四指 |
| 上指运动件对其他固定件 | 9.669592 | 0…109° |
| 下指运动件对其他固定件 | 36.720912 | 0…122° |
| P16 对其他固定件 | 6.830967 | 全行程 |
| 四路任意独立组合 | 2.039835 | 六对包络分离证明 |
| GH 对本路 P16 | 29.724998 | 0…122°，比上指角域更大 |

实体距离采样配合速度上界形成保守区间下界，方法/步长/失败列表见 `motion.json`。不把目录框当作可弯折线束。

EXT24 的腕避让仅可在边界保持后继承：重算上两转动总成 world Z 下界 772.516597、下两 822.516597 mm；新固定头部（剔除低部 adapter/长螺钉单独例外）最低 Z650。未变 P16 包络/运动沿用受控原证据；低部 adapter 与长螺钉和 EXT24 一致。由此保留父研究 q5/q6/q7 ±90° 的**头对相关腕部**证明。它不覆盖 LINK67 自身运动、完整机械臂、q6 外侧 90…100°、线缆或新增外壳。

CARRIER02 的 300 N、18 mm 偏置、双轴承 10 mm 间距和 7×7.4 mm 钢桥净截面筛选只适用于未改变根部。本轮没有重新宣称整片、灯腔后的刚度或抓取额定合格。42CrMo4+QT 仍需受控毛坯/热处理证明，缺口、接触、疲劳和预紧开放。

## 新质量及 COM

从当前每一个实体重新计量，不用历史整头名义质量作差。目录质量用于 P16、轴承、指定销/锁紧件、相机和 M4×40；其余原创金属按密度计。PCB 层压板暂按 1.85、透明片/绝缘环暂按 1.20 g/cm³；这两种材料尚未选定，数值属于质量估计。LED/IC/GH 等组件不按包络体积乘密度。

| 状态 | 可计量质量 / kg | COM head / mm | COM world / mm |
|---|---:|---|---|
| 全开 | 2.802491 | [0.000003, 1.544704, −37.094678] | [0.000003, 56.544704, 766.905322] |
| 上109° / 下122° | 2.802491 | [0.000003, 0.981202, −32.273157] | [0.000003, 55.981202, 771.726843] |

目录部件质量放在外形质心只是 COM 代理，非供应商实测内部质量分布。四 P16 每台总计 95 g，不把四个显示包络各计一次。逐件 CSV 与 manifest 标明质量方法；惯量均未辨识，不能从 GLB 直接得到动力学参数。

另留明确规划余量：四板离散器件/GH/铜/焊料 20…60 g，中央显示/安装 25…60 g，头线束/FAKRA/应变释放 50…120 g，装甲/防护/剩余小五金 80…180 g，四透明片保持结构 10…30 g。合计 185…450 g；加到可计量模型得到 **2.987…3.252 kg**。这些区间和各项 COM 区域是规划输入而非供应商保证。

## 文件与复现

输出目录：`engineering/generated/head-integrated-03/`。

- `HEAD-INTEGRATED03-open.step`、`-closed.step`：每态 697 件/697 个实体，STEP 回读有效。
- 两态 `.glb` 及 `blender-parts-manifest*.json`：697 个独立命名网格，均水密；包含组别、finger、joint、world transform、材料/质量来源、COM 代理状态和未辨识惯量字段。没有封装原厂 BREP。
- `interfaces.json`、`motion-containment.json`、`motion.json`：接口、实体包含关系和角域结果。
- `mass-ledger-*.csv`、`export-mass.json`：逐件质量与两态 COM。
- `UR/LL_* .step`：新金属、PCB、两软垫的本地零件；LL 保留装配函数需要的局部镜像补偿，不能当成另一个电路变体。
- `inputs/` 与 `input-snapshot.json`：可复核电子机械快照。
- `HEAD-INTEGRATED03-audit-views.png`：实际导出网格的检查视图，透明片和空预留框隐藏以便观察元件；不是最终工业设计渲染。

在 repo 根运行（需 CadQuery、NumPy、trimesh、matplotlib）：

```sh
python engineering/head_integrated03_study.py --motion
python engineering/head_integrated03_export.py
python engineering/head_integrated03_render.py
```

`--refresh-inputs` 只应在电气更新时显式使用；之后必须重跑以上检查。脚本校验主参数 SHA，不改主参数。若只更新电气地址/备注，可运行 `python engineering/head_integrated03_export.py --sync-addresses`；它严格拒绝坐标、封装、MPN 等变化，不是跳过新几何检查的开关。来源索引见 [head-integrated03.json](sources/head-integrated03.json)，相邻详证见 [CARRIER02](p16-carrier02-study.md)、[EXT24](wrist-extension-study.md)、[FPL01 fit](final-petal-board-fit-analysis.md) 和 [softpad retention](contact-pad-retention-study.md)。
