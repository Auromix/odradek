# 六段关节承力连接空间审查 R4-LINK-PLAN-01

**后续进展：**本页及其JSON保留最初接口空间快照，包含已被后续候选解决的反例。J1→J2已形成[LINK12肩架](link12-structure-study.md)，J5→J6已形成[LINK56梁端连接](link56-structure-study.md)，两者已有实际接触路径、装配检查与尺寸图；仍未制造/承载放行。J2→J3正在设计，其余三段尚待完成。不要将本页的初始否定结果当成后续候选的当前状态。

本轮把已选的七个原厂关节按当前零位坐标放置，核对每段的上游输出接触面、下游固定接触面和安装空间。**它是连接路线审查，不是六段支架已经设计完成**。当前总装中的两个闭口梁仍缺少端部连接；不能把几何上靠近电机的梁称为完整承力链。

本轮仅新增此说明和 [machine-readable接口表](sources/link-interface-plan.json)，没有改动共享参数或总装CAD。参数SHA256仍为`4349d1797b906b67a7bc396fcb84bc439c2d70dd0b337659e552cee293d2dd81`。源文件、真实面索引、局部/世界孔坐标与逐实体结果保存在接口表；原厂CAD只在本地读取，没有加入仓库。

## 基准与接触面

坐标来自当前`R4-layout-03`：每关节局部+Z沿输出方向，局部X取世界+X在轴垂直平面内的投影，Y=Z×X。原厂STEP先转换到前一轮核实的统一joint frame，再映射到上述零位。圆孔的装配相位沿用原厂模型；它不代表电气编码器零位。

固定前面位于输出一侧，支架从+局部Z靠近；固定后面支架从−局部Z靠近，同时必须避开向后伸出的壳体。对本项目连接应固定下一级**壳体固定法兰**，不能将支架错误接到下一级输出面，从而锁死或跨越该自由度。

| 关节型号 | 输出接触圈径向边界 / mm | 固定前面：局部Z / 径向边界 | 固定后面：局部Z / 径向边界 |
|---|---|---|---|
| RH25-B | 34.5～42.5 | −15.5 / 48.0～54.2 | −45.7 / 47.4～54.7 |
| RH20-B | 27.5～34.7 | −11.5 / 33.75～44.7 | −37.5 / 39.0～44.7 |
| RH17-B | 23.5～29.5 | −10.5 / 29.5～39.7 | −35.7 / 33.5～39.7 |
| RH14-N | 18.5～24.7 | −10.0 / 29.8～34.4 | −30.5 / 29.0～34.7 |

表中是CAD平面圆边界，不等于无孔完整环形承压面积或允许接触压力。RH14固定后接触区域由两个分离的外环面组成；同一Z处另有内圈平面，接口表保留各面索引，没有把内圈自动并入承力接触区。输出外定位圆分别为Ø85/70/60/50 h6，与中央凸台Ø69/55/47/37不同。

## 每段承力路线与空间依赖

### J1→J2：低矮肩部托架

承力路线为J1输出环板→左右侧壁/后侧闭合肋→J2固定后接触环；J2固定前面另设薄压环，以原厂8个Ø4.5通孔夹持。后壳需要穿过后接触环，不能用一整块立板遮住。建议先做开放侧面的整体机加工托架或可用实证螺接的分体叉架，保留线束进入J2后端的通道。

已做真实孔位的头部包络探测：J1输出环板厚6，16个M4头按Ø7.22×4放在板上，与肩关节实体相交体积和约**0.098744 mm³**。虽然体积小，但名义CAD已发生穿透，不能接受。可选路线是降低局部头座、减薄面板或增加肩部轴距；任一选择都需重算刚度、公差和装配工具空间。提高J2原点会改变运动学、静力、外形与可达距，不能只移动可视模型。

上游输出面到下游最低壳体平面的距离为9.8 mm。为了仅通过轴向分离就保证4 mm高M4头不碰，板厚必须小于5.8 mm；这只是无公差的几何边界，不是推荐的最终厚度。当前6 mm方案已被实际实体否定。追加逐实体距离探测：5 mm板对应的螺钉头名义最小间距为0.93170 mm，5.5 mm板仅0.43289 mm，两者暂时没有穿透；减薄是否能承载和能否保留足够公差余量仍需审查，尚未选定。

直接将底座用Ø150后环转到J2固定后面，与J1原厂本体没有碰撞；因此不能用“外接圆柱相交”直接判死这一安装环。但它与其它新增支架、螺钉和全姿态空间的兼容性尚未因此获得批准。

### J2→J3：绕后壳的偏置叉架

J3固定后面位于Z182.5，离J2输出中心Z170仅12.5 mm；J3本体却向下延伸到约Z125.1。若从J2输出面中心向J3固定后面画一条宽实体桥，会经过J3后壳。合理路线是输出环板的两侧耳板向X两侧绕行，再接到J3后接触环的外侧；J3固定前面增加压环，夹持固定侧通孔。

这段应以实际RH20后壳半径39及外法兰44.7作为避让依据，而不是把整个壳体看作统一Ø90圆柱。需要给输出板M4头、J3夹紧螺钉和各自工具定义先后装配顺序。当前6 mm板与头部包络对下游壳体无名义穿透，但8 mm整体分离距离本身没有给出完整公差余量。

### J3→J4：上臂闭口梁与横轴端叉

上游输出面Z220到下游壳体最低位置约355，轴向净分离132.5 mm。宜采用可拆输出法兰→闭口梁→绕开J4壳体的端叉→固定前/后接触面的承力路径。J4输出沿−Y，后端壳体向+Y突出；端叉和走线都应服务这个方向，不能装反。

现有60×40×3闭口梁只是中心线包装候选：起点中心Z232、终点中心Z347。梁端面与Z不垂直，实际角点在中心之外；不能以“中心差8 mm”替代实体净空。实际梁的Z范围为223.37089～355.62911，与J4原厂实体相交 **4.07453 mm³**，上游没有穿透。必须修改端部角点/斜切位置，并增加有明确螺孔、定位、接触面和工具进入的两端连接件；当前梁不能直接下料。

### J4→J5：肘部偏置叉架

J5固定后面Z414.3，仅比J4输出中心高14.3 mm，后壳向下延伸到Z348左右。承力路线与J2→J3相似：在J4的−Y输出侧设置环板，再用左右叉耳绕过J5后壳，连接其固定后环，前侧压环完成夹持。不能直接在两轴心之间填实材料。

这段名义轴向间隙12.5 mm较肩部宽松，但固定侧M3孔附近仍有薄壁螺纹、拧紧与工具位置约束。外壳装饰板应随后覆盖已验证的叉架，不充当承力连接。

### J5→J6：优先完成的前臂梁端连接

这一段静载较低、两端都是RH17-B，轴向壳体分离113 mm，适合先形成一个完整可试装的金属连接候选。建议分成J5输出法兰、闭口梁端块、可检修横轴叉架、J6前/后夹持环。通过独立端块把梁的封闭截面与真实接触面连起来，避免只靠两条装饰筋。

可作为下一轮参数起点、尚未冻结的几何包括：J5输出法兰中心[0,−55,450]、中央凸台避让≥Ø47.6；J6固定后接触中心[0,−35.7,605]；后壳避让≥Ø67.6；输出16孔必须采用RH17实际非均布PCD54坐标。现有梁起点中心Z462、终点中心Z557，实际Z范围为451.97927～567.02073；上游端与J5穿透 **0.015024 mm³**，下游端与J6穿透 **60.840745 mm³**。当前梁已被真实实体否定，须重新定义两端斜切或缩短后用端块连接，不能直接认为两端已经避开壳体。

选择这一段作为首件，不表示当前梁可直接加工。下一轮应先确定两端板/螺钉和维护路径，再反推梁长、斜切面及端块长度；输出M3全牙起点未知，先完成几何和接触面，不冻结螺钉长度。

### J6→J7：腕部可拆叉架

J7固定后面Z609.5，仅比J6输出中心高4.5 mm。J7后壳却向下伸到约560.3，所以连接必须绕过后壳；直板封闭两中心之间的体积会侵占J7本体。以J6输出环板→左右叉耳→J7固定后面的两片实际接触区为路线，前侧压环通过4个固定通孔闭合夹紧。

J7固定后面存在分离的外圈接触面，同一平面的内圈不应擅自承担新的夹紧载荷。外观壳体可以延续细长、机甲式分缝，但应能拆下以接近J7固定螺钉、后端接线和线束固定点。

## 本轮探测的明确结果

除J1→J2的M4头外，统一采用6 mm输出环板和保守头部包络的其余五段，当前相位下对下游原厂壳体没有名义穿透。另以实际后壳边界+0.3 mm径向间隙、固定接触圈外缘+4 mm、厚8 mm建立了未开孔后环包络。对应外径/中孔依次为：117.4/95.4、97.4/78.6、97.4/78.6、87.4/67.6、87.4/67.6、77.4/58.6 mm；六者与上下游原厂壳体及上游探测环板均无名义穿透。

这些环仅用于证明一部分安装空间存在；没有叉耳、梁端连接、螺纹、前压环、预紧或结构校核，不能称为完整支架。环、输出板和头部的尺寸均保存于JSON，使下一轮可以复算而无需推测本轮用了什么。

| 被否定的当前组合 | 相交体积和 / mm³ | 必须处理 |
|---|---:|---|
| J1 6 mm输出板上的M4头 → J2 | 0.098744 | 改头座/板厚或轴距，并审查公差与刚度 |
| L3斜梁 → J4 | 4.074530 | 改下游端部/端块和装配界面 |
| L5斜梁 → J5 | 0.015024 | 改上游斜切端面/端块 |
| L5斜梁 → J6 | 60.840745 | 改下游斜切端面/端叉 |

相交量是所有实体对的体积和，不能当制造去料量；小数值也不意味着可忽略的实体穿透。在这份初始快照中六段均无完整承力连接，历史JSON全部标记`complete_load_path_designed=false`和`manufacturing_release=false`；后续状态以页首所链接独立候选为准。

## 内走线不能只画轴心连线

下表是根据原厂后端轴向极限得到的“后端轴线中心”，用于表示可能的后向穿线空间；它**不等同于已确认电气接插件中心或可插拔接口**。实际EtherCAT、电源、编码器线和相机链路的接头/弯曲半径仍应与电气选型表共同核实。

| 下游关节 | 后端轴线中心 / mm | 相对上游输出面的主要绕线方向 |
|---|---|---|
| J2 | [0,−103.2,170] | 向肩后侧并抬高 |
| J3 | [0,55,125.1] | 向+Y并下降，绕到J3后端 |
| J4 | [0,94.9,400] | 沿上臂向上，再向+Y到后端 |
| J5 | [0,−55,348] | 向−Y并下降 |
| J6 | [0,−102,605] | 沿前臂向上，再向−Y到后端 |
| J7 | [0,55,560.3] | 向+Y并下降；腕部需回弯和维护空间 |

J3、J5、J7的“下降后再沿本体中空轴向上走”可能使线束回弯比两安装面之间的距离更占空间。下一轮支架必须显式保留这种通道，并根据电缆寿命/动态弯曲半径决定是否增加偏置；不能以“有中空孔”替代整条内走线设计。

## 进入可制造连接前的顺序

1. 取得四种原厂输出接口的全牙起点、完整有效牙深、导入/退刀及允许预紧；固定接触面的平面度、粗糙度、夹持载荷也需确认。现有“沉入深度+M3/M4深度”不能自动决定杆长。
2. 解决J1→J2的实际螺钉头穿透，明确是局部头座/板厚调整还是关节位置变更；后者必须同步数学模型与静力预算。
3. 以J5→J6形成第一条完整承力链：真实孔位、端块、闭口梁、固定夹持环、紧固件、内走线和装配顺序一并建模。
4. 将已验证的端接方法扩展到J3→J4，再逐个设计短偏置叉架；不直接复制外观包络。
5. 在整链CAD中进行关节行程、非相邻壳体、工具、线束和可拆卸性的检查；更新从实际CAD取得的质量/COM，再做静力、动态与疲劳校核。

所有形态、厚度与候选梁截面在本阶段仍服从接触面和装配证据。当前没有任何一段被标为制造放行，也没有把额定动态输出扭矩解释成持续静止承载能力。
