# A05 RS 关节内走线与装配路径复核

日期：2026-09-30。范围：本体七轴与可拆头部之间的线束；不变更底座、桌夹、后接线仓或桌下控制盒。状态：**布置建议与线材初筛，未完成真实线束运动验证，不是制造放行文件**。

## 本轮结论

保留两路独立 GMSL2 同轴、直流供电和 CAN。RS03／04／06／00 均按**没有已证实可用贯通孔**处理；不能把查看器中的中心虚线穿过电机实体当成内走线成立。推荐在承力件内侧设置可开盖线槽，在俯仰/横摆轴的非驱动侧设置空心被动耳轴或侧边线腔；过轴处通过受导向的服务环吸收相对运动。

J7 建议先以 **−90°～+90°作为布局目标**，零位为头部左右对称正向姿态；旧 A03 的 ±160°只是查看器探索角域。±90°也尚未成为经过线束、结构和软件共同验证的实机行程。采用独立线腔内的盘绕/滚弯路径，不用一小段同轴承受整个 ±90°扭转。

紧凑走线已有元件依据：Times Microwave 的 PT-047、TF-047 官方目录明确给出动态弯曲半径，分别为19.05 mm和10.16 mm。可用 **R35 mm作为初轮实际曲率半径目标**，但需同时满足电源/CAN线的动态要求；这不等于 R35 的圆环画出来后，整个线束和关节就已通过。

## 隐藏走线如何跨过七个轴

这里的“固定”指把线缆护套的机械载荷交给支架，并不是在动态弯曲区把线束紧扎为一根硬棒。每个关节的动态段两端分别固定到该关节的上游和下游刚体，避免J5动作继续拉扯J6/J7线环。

| 区域 | 建议路径 | 必须在实体装配中保留的东西 |
|---|---|---|
| J1 | 从既有底座/本体边界接入，在J1壳内绕驱动外侧进入肩壳 | 独立有限转向服务环；不穿RS03中心，也不修改底座接线仓。J1的最终角域另验 |
| J2、J4 | 电机一侧传力；对侧被动耳轴内孔或叉架内侧开盖槽过线，在轴侧形成导向弧 | 耳轴孔是新增结构件的孔，不是电机中孔；孔径、轴承内径、承载壁厚需共同核算。两端出线不能在孔口立刻折弯 |
| J3 | 上臂roll的线束沿电机外周旁路，转动段放在独立环形/轴向线腔 | 壳体内实际恒长盘绕路径及上下游固定点；不能在细杆内短距离硬扭，也不能直接沿用±160° |
| J5、J6 | 每轴各一段服务环，优先从非驱动侧耳轴/载架背面进入下一刚体 | 两个互相垂直的动态段分开；J5的剩余线长不能被J6吃掉。折回时线槽位于叉架保护范围内，避开头部相机和关节闭合缝 |
| J7 | J6输出载架上设静端固定点；J7旋转法兰上设动端固定点；中间线段在可拆后颈线腔内盘绕/滚弯 | 双同轴各自导向，CAN与电源另槽；完整±90°扫掠及曲率、余长、摩擦均需验证。无普通滑环，无无限旋转 |
| 头部 | 动端固定点之后留短的无运动维修尾线，接到可拆头部接口 | 两路相机明确编号；接口可触达，拔插时不拉线，头部定位/锁紧件不靠连接器承力 |

隐藏线槽采用承力骨架内侧的开口U形槽＋可拆盖板，盖板与非承力外壳的折线结合。先装电机、轴承和叉架，再侧向放入已压接好的线束，最后装盖板；避免要求大接插件依次穿过七个小孔。线槽内不暴露螺纹尾端、锐边、支撑毛刺；夹持护套，不能夹在同轴接头的压接根部。分段固定不等于每关节都加一个同轴接头，优先减少高速通路上的可插拔过渡。

## 初轮CAD占位：通道与弯曲腔分开

以下是**净空设计假设**，只用于防止结构把走线空间挤没；没有选定电源线径、CAN线或接头。净空不含承力壁厚、盖板、螺钉和连接器。若实际材料比假设粗、动力线路需要额外并联或独立参考线，须增大通道，不反向用此表限制电气设计。

| 部位 | 暂定线束假设 | 建议先保留的直段净空 |
|---|---|---|
| 肩部主干 | 2根同轴，各按Ø3.2 mm占位；最多3组CAN各按Ø4 mm；直流正负各按Ø5 mm | **28×16 mm**开盖槽；同轴/通信和动力分区，允许侧向放线 |
| 上臂至前臂 | 下游CAN组数随分支减少；同轴不断开；动力分支在静态区域完成 | **24×14 mm**净空作为初排尺寸，按实际剩余线束重新排布 |
| 腕部至头部 | 2根同轴仍按Ø3.2 mm、1组CAN按Ø4 mm、2根头部动力线各按Ø3 mm | **22×12 mm**净空；同轴专用通道至少10×7 mm，其余另槽 |
| 仅双同轴穿过的被动耳轴 | 两线并列，预装接头不穿此孔，线束侧装或耳轴可拆 | **Ø10 mm净孔**作为几何起点；混入电源/CAN时不再适用 |

这些尺寸含排线余地，不是依据载流量算出的最小截面。RS手册相电流也不能直接作为48 V母线电流来选主干线。多组CAN只是为控制分组留空间，不在本轮冻结总线数量、控制频率和终端电阻位置。

**动态区另保留弯曲包络：** 初排采用R35 mm实际曲率目标；双同轴并排、按每根Ø3.2 mm建模时，一个独立180°回头弯的外侧跨度下界为`2×35+3.2=73.2 mm`，再加每侧3 mm运动净空约为80 mm。这仅是回头弯本身，不含切向直段、固定点、运动行程和动力/CAN线。若沿用CG03的R75，相同计算约为160 mm。R35在PT/TF候选的目录动态范围内，但尚不能说明整套线束都能采用R35。

**环形腔不等于现成滚弯机构。** 围着Ø57 mm RS00画一个R35圆，只能说明有一条盘绕中心线；几毫米环隙不容纳R35的U形回头弯。J7可采用非驱动侧的轴向后颈腔，或分层盘绕腔，把切向入口、切向出口和变形区一起建出来。若需要缩小回头弯，可针对PT-047测试R25布局；在电源/CAN未确定前不把R25写成整束共同半径。腔体最终外径和长度由恒长路径扫掠决定，本轮不虚构一个已经成立的小外径。

## J7角域与控制约束

对于只做均匀扭转的直线段，目录的每米扭转指标只能用来作数量级筛查：`角位移幅值 ≈ 每米允许角 × 有效自由长度`。以CG03的±180°/m为例，150 mm自由段仅对应约±27°；要达到±90°，均匀扭转长度至少为0.5 m。这个换算不是对短段的新寿命保证，更不能忽略端部集中变形、弯扭叠加与固定夹。

因此J7采用以下分层约束：

1. **设计/查看器目标：±90°。** 当前不提供已验证的实机极限；首次样机以小角度逐步检查后扩大，不能凭目录直接通电跑满。
2. 动态段在零位无预扭、保留对称余长；装配标记保证拆头后不会误装多绕一圈。
3. 控制器使用相对于装配零位的有限角域，禁止将±180°环绕归一化当作可连续绕圈；掉电重启后恢复可确定的机械角与绕线状态，否则先核查再使能。
4. 软件软限位、减速区和独立实体止挡逐级保护线束；止挡角与减速距离由实测扫掠和制动距离确定，不先拍定“±100°硬限位”。线束不能充当止挡。

J7达到±90°的通过条件包括：任意允许姿态下同轴的实际最小曲率半径满足所选线材；没有拉直、夹线、磨壳或接头受力；整个线束能拆装；动作前后两路GMSL持续正常。单轴弯曲检验通过仍不足以覆盖J5/J6/J7同时运动。

## 可拆头部与高速链路边界

头部接口先分为两路50 Ω同轴、一组低压动力和一组CAN，不强行合成普通多芯连接器。相机接头以具体相机板为准，FAKRA/HFM/RMC或微型RF接头须与线材的实际压接/焊接兼容；本轮没有选定完整接头BOM。优先设计有导向、带锁定且可维护的接口。若微型RF接头不适合频繁用户插拔，应由短静态尾线与面板接头隔离，而不是每次拆头直接拔板端微型座。

GMSL2不能接到CAN，也不在臂内改成USB；两路传感器通路继续导向既有外置盒的对应采集端。是否使用PoC由相机/解串器组合决定；细同轴的DC电阻、PoC电流、压降及接头额定仍需核对，不能因“同轴可供电”就删去夹爪和灯片的独立动力线。

按[ADI GMSL2 Channel Specification Rev.1](https://www.analog.com/media/en/technical-documentation/user-guides/gmsl2-channel-specification-user-guide.pdf)，完整链路须核插损、回损、串扰和裕量，包含PCB、接头、所有线段及最差温度/老化/PoC条件。50 Ω和50/70 GHz目录上限只是初筛；6 Gbps GMSL2并不等于要求“6 GHz线缆”即可通过。不要把额外转接头的频率标签等同于完整通道合规，也不假设普通滑环能透传双GMSL2。
