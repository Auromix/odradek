# P16-CARRIER-01 — 四轴支承、P16 基叉与 J7 后架

状态：**独立原创机构研究；名义 CAD 和可复核几何证据，不是制造或 2 kg 抓取放行。** 本分支承接 P16-PACK-01 和 CONTACT02 的远端占位，不改 R4-layout-03、旧总装、主 BOM 或灯片远端设计。许可证 CC BY-NC 4.0；Odradek — Auromix contributors。

**整腕明确阻塞：** 根任务已用真实 RH17 J6 检查：本载体绕现有 J7 原点到 q7 = −90° 时有 3150.555182 mm³ 穿透、+90° 时有 3146.012479 mm³；最终钻孔版已独立复核于 `wrist-cross-check.json`。q7 = −60° 样本无穿透、最短5 mm。后者不是连续角范围证明。−120° 越出基线 ±90° 的9822.808 mm³只作敏感性反例。故当前后架不能作为原 ±90° 的可用方案；还需 J7 抬高或后架重布并重算工具长度/载荷。本文不因本地指轴避让通过而覆盖这个失败。

这版形成一条明确的承力路径：灯片窄舌 → 可拆根叉 → 一体钢制曲柄/实心轴 → 双侧角接触轴承 → 金属载体立柱/径向后架 → 原创 J7 转接 → RH14 输出环。P16 的两销都由真肩轴和金属叉支承，基叉用两枚螺钉接到同一载体。四根指轴及上下根差 50 mm 保持不变，左右驱动镜像。这样可检查空间、接触面和装拆条件，但尚未闭合材料、配合、预紧及寿命。

## 输入、坐标与文件

- 共享参数 SHA-256：`4349…81` 的完整值由 `study.json` 保存并在脚本中断言；CONTACT02 的实际输入哈希另存，不把后来的灯板/软垫保持设计自动视为已合并。
- head 原点为中央 face，+Z 向前。J7 **输出接触面在 head Z = −140 mm**；MOUNT-01 转接前面在 −130 mm；载体最靠后实体在 −154 mm。因此基臂比输出接触面后伸 14 mm。
- 沿用基线 J7 输出世界原点 `[0,55,640]` 时，face 仍为 `[0,55,780]`，本分支没有自动前移 face。几何换算为 `world = head + [0,55,780]`。后架与 J7 的检查不等于与 LINK67/J6 及整个腕部全角域的检查；若后续需加延伸 Δz，face、TCP 和 COM 必须一起加 Δz。
- 抓取 TCP 由 CONTACT02 的具体接触几何决定，不把旧 `face+110` 圆柱示例当通用抓取中心。

## 装配与拆卸证据

1. 先将 MOUNT-01 转接接到 RH14 输出；使用真实 8 孔非均匀角度，不重画成 45° 等分。原厂输出 M3 的退距 9 mm 和有效深 5 mm 仍未给完整起牙/终牙，所以这 **8 枚螺钉长度未选定**；不能购买后直接盲装。
2. 四枚 M4 候选把载体主环接到转接。STEP 中名义螺纹大径穿过旧转接的 Ø3.3 底孔，记录为有意的螺纹材料包络交叠；不作为任意碰撞豁免。
3. 从各轴承座 +u 面装入轴承对，再从 −u 插入根叉/实心轴，装前盖、内圈隔套和端部锁件。控制轴承环的压装受力路径；不能用滚动体传压装力。实际公差和锁片弯折工序未放行。
4. 基叉、P16 两端肩销、金属垫块和外侧螺母沿 P16-PACK-01 的真实肩位装配。拆基座 M4 前，先卸载、断开两销、取下 P16，随后沿 +Z 接近两孔。
5. 最后装可拆光学前架。拆光学件需先断电并拔除 FAKRA/显示连接，再卸四个前端 M3 螺母。此顺序是几何装配方案；完整带线前架抽出轨迹、弯线和手部空间仍待验证。

`review.json` 保存 **32 条实体圆柱工具通道**：8 条 J7 Ø6 × 171 mm、16 条指轴盖 Ø4 × 35 mm、8 条基叉 Ø4 × 40 mm。通道体逐件检查没有正体积相交；螺钉自身驱动端从相邻件余量统计中剔除。它们是选择直工具的空间要求，不代表任意套筒、手柄或球头工具都可用。J7 工具检查以前光学件取下为前提；基叉工具检查以本路 P16 取下为前提。

近根 GH 改按父任务最新 pocket 的整个投影留背部盒体：local `x38.5…47.5, u−8.75…8.75, z−3.7…0 mm`，中心 X43。它覆盖直插方向估计的更低面；JST 官方侧插配对包络名义 15.75 × 7.15 × 4.35 mm，PCB 背面 Z3.6 时只到 Z−0.75，但实际封装原点还未冻结。旧 `x25…40/u±7` 是不同位置的历史预留，**旧 0.9 mm u 分离结果失效，不作本 pocket 结论**。

新探针对固定载体/光学件四路全角域下界均 **14.028218 mm**；对本路 P16，上 0…109°、下 0…122° 均 **27.091421 mm**，见 `led-interface-reservation.json`。这只是背部空间探针，不能称实物接头、板腔、插拔/线束、邻片运动或完整灯板已通过。x>25 实体仍未改动，后续必须以受控接口替换并与父任务灯腔逐面合并。

## 验证范围、质量与后续

- 原厂 P16 对新根叉：上/下各五个角态，逐 solid 无实体交叠；销/垫块配合承接 P16-PACK-01 原生 CAD 证据。新轴只增在 +u，未挤占原负 u 的执行器通道。
- 原厂 RH14 对新载体/光学拉杆：逐 solid 交叠 0；现有转接的接触/pilot 证据继续由 MOUNT-01 提供。新 LINK67/J6 由根任务另查，已经发现上述 −90° 碰撞；J7 电缆附件仍未覆盖。
- 连续指运动证据：自身轴承座/端盖/螺钉被一个同轴回转壳保守包含，其对根部的旋转不变距离为上 **0.226345 mm**、下 **0.379896 mm**。这些非常小的名义间隙 **没有给公差/挠曲留出可放行余量**，下一版应在 x≤25 的近根过渡让位并重验。其余固定件连续下界：上根9.669592、下根36.720912；P16对其他固定件6.830967 mm；四模块任意独立角的最小分离下界 **2.039835 mm**。完整角度和推导在 `study.json`，不是仅看端态图。LED/GH 和软垫保持的后续版本未自动并入；本分支不能代替它们的闭合检查。
- 驱动保守圆柱外包络 **Ø255.770 mm、Z −154.533…78.408 mm**，含1°采样间的速度余量；这是模块界限，不是最终外壳尺寸。固定主载体实际 Z −154…74 mm。
- 已计质量 **2,726.6 g**，包括本文已建模承力件/紧固件、四 P16、8 轴承及两相机；**不含 J7 本体 780 g**。开态 COM 代理为 head `[0,2.449,−31.233]` mm，即基线摆放约 world `[0,57.449,748.767]`。相机/P16 的内部质量分布未知，所以这是目录质量与原创实体质量组合的代理值。载体最终 871.954 g：已在融合后重钻四个孔，与先前检查体相比只去除 7,389.026 mm³（19.950 g）；`qa.json` 的包含关系证明旧的原厂 J7/工具通路通过结果对现体仍保守。
- 未定中央显示 25–60 g、完整四灯/软垫 80–160 g、线束/FAKRA/应力释放 50–120 g、护壳/余下保持件 80–180 g 是**规划分配，不是采购事实**。据此完整头部当前规划 **2.962–3.247 kg**，不能用此前 2 kg 预算验收。分配项各自 COM 区间已在 `review.json` 列出。
- 父任务新灯腔和软垫键不能用“全宽灯片减重差”直接加减本窄舌片质量。下一步必须逐面合并远端灯腔、软垫键、真实 GH/线缆后重新求体积、COM 与全部间隙。

最有把握的下一步是：在相同根轴界面下把 0.872 kg 单体载体拆为可加工闭口梁/节点，及比较钢实心轴配可拆轻金属根叉。须保持闭合承力路径和叉桥刚度，重新做连接/疲劳与空间验证；本研究没有擅自据外观压小轴承或取消双支承。P16 的 300 N 最大推力、20% duty、慢速、保持及寿命边界仍适用，绝不等于 2 kg 额定夹持完成。


## 复现与检查顺序

使用仓库既有 CadQuery Python 环境，保持原厂 CAD 在 `work/`，运行：

```sh
python engineering/p16_carrier_study.py
python engineering/p16_carrier_review.py
python engineering/p16_carrier_qa.py
python engineering/draw_p16_carrier.py
```

第一步默认同时做原厂核验和连续指运动；`--skip-vendor` 仅适于沿用已核验的本地证据，不能在没有原厂输入时宣称重新验证。第三步出五单件网格 QA、钻孔路径、近根预留、J6 冲突复核和最终插图，再生成四页 PDF。脚本只读共享参数并检查哈希。所有 STEP 都为原创零件或名义包络，不导出供应商 BREP。`mass-ledger.csv` 是逐个已建模项的质量账；[局部 BOM](hardware/p16-carrier-bom.csv) 包含未选定和未放行字段，未改主 BOM。
