# B04 底座：三维装配与加工审查

本轮主交付是可拆分的三维装配与零件实体；PDF 和坐标表用于辅助核对加工特征。B04 是新底座原型，不继承早期 R4 穿桌锚固底座的尺寸或承载结论。实际采购件适配、制造和实物验证状态以本轮审查记录为准。

## 同一套三维数据

- [参数源](../../engineering/base_b04/parameters.json)定义 X 左右、+Y 向桌内、+Z 向上，桌面为 Z=0、后桌边为 Y=0。
- [实体源](../../engineering/base_b04/model.py)建立真实孔、沉孔、螺纹底孔、槽、间隙及分件；每个零件保留全局装配坐标。螺纹不建螺旋牙型，攻牙要求由特征表定义。
- [装配清单](../../engineering/base_b04/build/manifest.json)给出实体路径、材料、工艺和特征；加工必须同时读取对应 STEP 与该版清单。
- [三维装配 STEP](../../engineering/base_b04/build/ODR-BASE-B04-P1.step)保留零件装配关系；[GLB 预览模型](../../engineering/base_b04/build/ODR-BASE-B04-P1.glb)用于交互查看。GLB 是显示网格，制造尺寸以 STEP 与特征表为准。
- [辅助图册](../../engineering/base_b04/build/drawings/base-b04-manufacturing-review.pdf)和[特征坐标表](../../engineering/base_b04/build/drawings/feature-coordinates.csv)暂存为较早 P1 机械骨架检查点。它们基于清单散列 `ad065c979d159c1636a3b4f45636eb2d2e782b9553024c0c5ffa4498b730d9ef`，**不对应当前三维装配，不能配合当前 STEP 用于加工**。详情见[检查点说明](../../engineering/base_b04/build/drawings/README.md)。新版外罩、底座灯与接口开孔协同完成后再重生图册。

采购螺柱、压脚和控制盒占位若标为 `hardware`／`envelope`，只是有明确范围的装配表示；不能据此加工替代件，或声称已经核对全部供应商实物。

## 承力与拆分边界

臂根试验法兰经四根金属支柱传到底板；底板连接左右钢制 C 板、下横梁和两套桌夹螺杆。上下软垫把夹紧压力传给桌面。外观罩壳、足部保持罩及 PCB 支柱不进入机械臂主承力路径。臂根法兰是本项目的试验接口，尚不代表某个商业关节可以直接安装。

桌下托架连接 C 板固定部分，不连接调节螺杆或可动压脚。托盘、限位条和束带共同约束外置盒；控制盒可按 +Y 方向取出，其质量和空间分配不等于已选控制器。

## 装配顺序与可接近性

1. **先做金属件检查。** 核对材料与工艺、孔径／螺距、有效牙长、接触平面和去毛刺。用同版全局坐标检查配对孔，不把螺纹底孔直径当成成品内螺纹尺寸。
2. **桌外预装主骨架。** 在底板下表面可接近时安装四根法兰支柱和罩壳支柱，检查底部螺钉头不突出软垫支撑面。随后从两侧装 C 板及下横梁；侧向紧固需要工具直线进入，不能被外壳遮住后才装。
3. **装法兰与桌夹。** 固定上法兰；按供应商方式组合 M12 调节螺杆和摆动压脚，再安装扩压板、下软垫及非承力保持罩。保持罩耳沿 Y 方向布置，M3 孔位为 X=±85、Y=32／78 mm，避让两侧 C 板。压脚应直接抵金属扩压板，保持罩仅防脱，不替代压脚承压。
4. **装桌下托架。** 固定两侧托架和托盘，安装后止挡，保留前止挡可拆；完成线束和束带路径后再放入控制盒。托架拆装不应要求先松开主桌夹。
5. **安装服务板。** 固定 PCB 螺柱和电路板，核查板底焊脚、螺钉及金属底板之间的距离。J1/J2 按合同向 -X 拔出，J3 向 +X 拔出；须同时留插头、手指／工具、线缆出线和应变释放空间。
6. **先试线束，再盖罩。** 完成机壳连接点、后部下行线束固定及与夹紧面的避让；确认后罩可以向上拆除。罩壳不应把插头或线束压紧来获得外形闭合。
7. **桌上空载试装。** 分别核对候选桌厚时螺杆的有效啮合、下压脚姿态、上软垫接触和工具操作空间。具体夹紧力与紧固扭矩需有计算及硬件依据，不能以“拧紧”为可重复的载荷验收条件。

## 加工与装配审查重点

| 项目 | 应核对的具体内容 |
|---|---|
| 公差 | 参数中的机加工、打印、孔位置和平面度是本原型声明；孔位置公差仍须对应明确基准和检验方法。不得自行套入未指定的通用公差标准 |
| 底板支柱连接 | M8 底部沉孔需按实际剩余腹板校核局部承压与拉穿；不能只用底板外形总厚度计算 |
| 螺钉长度 | 以板厚、垫圈、座面与螺钉公差计算有效啮合、端部间隙和突出量；钻孔深度不等于有效螺纹啮合 |
| 打印件紧固孔 | 通用打印偏差不能保证小间隙 M3 孔直接装配；按最终工艺说明实施后钻或其他已定义修整，并检查实际孔位 |
| 采购压脚 | 外包直径和高度只覆盖空间分配；颈部、卡接方式、摆角及装入路径须对照到货件或完整供应商图 |
| 盒体维护 | 占位模型尺寸必须严格对应参数；前止挡拆卸、束带释放与 +Y 抽出过程须完整检查，不以缩小占位消除碰撞 |
| PCB 与线束 | 使用本版 KiCad 板及配套元件包络；裸板不碰撞不足以证明插头可拔、焊脚净空或线缆弯曲空间成立 |

本文件不把名义几何不相交、计算通过、PCB ERC／DRC 通过或图册清晰等同于制造放行。未关闭项必须保留在交付说明中；后续修改应共同更新三维实体、特征表、质量、装配记录及对应电路板版本。

## 已完成的局部刚体复核

[独立 BREP 检查记录](../../engineering/base_b04/build/drawings/assembly-dfm-check.json)针对模型散列 `153bb04a9884f9586b6a2922c3e3215ae0b544a0c122ac2364cf1312bc035cc0`，在 15／30／60 mm 三种桌厚下检查了 90 对实体：下横梁 M8 头及垫圈与盒架耳板、保持罩及其 M3 螺钉与下横梁／C 板／盒架、压脚与下横梁。没有超过 0.001 mm³ 的交集；耳板的 D20 开边避让给 M8 头及垫圈留下 2 mm 名义距离，60 mm 桌厚时压脚和 M3 头到下横梁为 7 mm。

这份结果只描述指定源版本与所列刚体对的名义几何，未覆盖装入轨迹、公差、工具空间、实际压脚摆动、桌板接触压力或承载。模型后续更改须重新复核；它与上述较早 PDF 检查点是两份独立证据。

## 辅助图册复现

在具备 CadQuery、NumPy、ReportLab 和 pypdf 的项目 Python 环境运行：

```sh
python engineering/base_b04/drawings.py \
  --manifest engineering/base_b04/build/manifest.json \
  --font /path/to/Chinese-font.ttf
```

默认输出紧凑总装和成组特征表；需要逐件四视图时增加 `--individual-parts`。每次实体或清单更新后重新生成，并渲染 PDF 检查中文、表格和页边界。图册证据记录输入文件散列，避免把旧图配到新模型。
