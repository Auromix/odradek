# R5-WRIST-EROB01：eRob70I V5 可拆头转接候选

状态：**原创几何、装入空间与条件载荷筛查已成型；不是制造放行，也没有给整机赋予2kg额定载荷。** 旧RH总装、主参数与全臂接口均不修改。电机候选字段码 `eRob70H100I-BS-18EN` 仍需原厂受控订货确认；所用原厂图纸文件名带 `XX`，不证明该完整订单配置已存在现货。

新增两件：A01为关节端转接盘，H01为头侧接口样片。H01规定未来头框的接触面与孔位，不是已经接入新夹爪的承力头框。另有间隙扩大的 A01-G/H01-G 无载打印量规。机械接口为本项目原创约定，**不是ISO标准末端法兰**。

## 真实接口与坐标

来源为ZeroErr eRob70I V5 EtherCAT版原厂2D/STEP，以及中文安装手册V3.44。原厂CAD只在本地参与核对，不随项目发布。输入SHA、官方URL与页码在[来源表](sources/r5-wrist-erob01.json)，提取过程包含在[脚本](../../engineering/r5_wrist_erob01.py)。

统一坐标：原点A为输出安装接触面；+Z向头部，+X取原厂STEP的+Y，+Y取原厂−Z。转换是行列式+1的刚体转动：`[x,y,z]joint = [ynative, -znative, -9.774999898159106-xnative]`。不存在背视镜像。原厂CAD含一个融合solid，内部固定/旋转零件没有可靠分组；本研究只核对外部接口与装入，不认证原厂内部运动。

## 原创特征契约

全部名义尺寸为mm。完整真实截面、孔位与候选公差见4页[尺寸图目录](../../engineering/generated/r5-wrist-erob01/)，对应 STEP/STL/DXF 分目录。DXF的Ø4圆柱是M4螺纹大径简化图形，**不能照其钻Ø4后攻M4**；工艺需用合适底孔并取得贯穿完整牙。没有统一ISO总公差或表面处理默认值。

| 零件 | 主要特征 |
|---|---|
| A01 | 主盘Ø76、Z0…8；后裙OD60、母止口Ø50，Z−6.5…0。后入口C0.3，内根R0.1；真实Ø50完整圆柱配合段名义搭接约1.8mm，满足原厂“深度≥6”的几何位置要求 |
| OEM8孔 | Ø3.4穿过主盘；前沉孔Ø6.2深3.4，底面Z4.6；孔底C0.2让开头下过渡。上述头包络仍须与实际M3×0.35配套螺钉核对 |
| A01头侧 | 4×M4×0.7通牙，PCD64、45/135/225/315°，Z0…8，两端C0.25 |
| 销接口 | 两销位(0,+32)/(0,−32)。A01建议孔Ø3.000…3.003贯穿主盘Z0…8；销候选MISUMI MS3-8，Ø3 +0.005/+0.010，长8。名义Z4…12，即压入4/露出4；完整销端形状、长度公差与保持力尚未闭合 |
| H01 | Ø76、厚4，Z8…12；4×Ø4.5、前孔口C0.25；中心Ø18。上销孔Ø3.020…3.035；下销孔为沿Y的径向槽，宽同圆孔、总长5。一圆一槽避免双圆孔重复约束销距 |

销位在定稿前由R28改为R32，消除通孔贯穿Ø60后裙后仅余0.5mm边壁的问题；现在销孔仅穿8mm主盘，距Ø76外缘有4.5mm名义净边。

材料为6061-T6候选，密度2700kg/m³仅质量计算假设，A01/H01的最终质量见`study.json`及PDF第4页（约147.5g合计）；不含螺钉、销、真实头框。真实材料状态/证书、镀层或阳极氧化后的配合、加工圆角与公差链仍需确认。建议试制主厚8±0.05、后伸6.5±0.05、OD76±0.1、孔位位置度Ø0.10；这是后续工艺讨论目标，未覆盖原厂孔位容差或已保证互换性。

头侧四颗可购候选为[NBK SNS-M4-12](https://static.nbk1560.com/en-US/products/specialscrew/nedzicom/highintensity/SNS-J/SNS-M4/)，M4×0.7、SCM435/12.9黑氧化、长度12、3mm内六角、名义质量2g/颗。NBK官方尺寸表给最坏带滚花头径7.22、头高4、长度11.65…12.35；因此模型用该较大头包络，而不是仅名义Ø7。不加垫片；预紧和防松未指定。名义H01板厚下末端Z−0.35…+0.35；叠加两件板厚公差还会变化，不能把该范围当完整公差验证。

头侧几何有效牙重叠筛查：`11.65 − 4.05 − 1.4 − 0.25 = 5.95mm`，依次扣除样片最大厚度、按2P计的端部不完整牙、母牙入口倒角。条件是自制通牙已真正加工出相应完整牙；这不是铝牙剥离强度或螺钉预紧承载结论。OEM端完整有效牙仍完全独立TBD。

## 实体、装入和工具证据

`study.json`记录真实vendor输入hash、原创STEP重读、STL封闭性、逐项Boolean结果和解析包含体范围。

- A01与原厂融合solid相交体积0；H01与A01/OEM也为0。接触用微小轴向重叠积分核对：A面约468.056mm²，A01/H01面约3956.542mm²；这不保证现实接触压力均匀。
- A01后裙完整直向装入用**连续包含体**检查：Ø50…Ø60、Z−6.5…63.5的环体，加内根R0.1对应的Ø49.8…Ø60、Z≥−0.1小环体。二者并集覆盖沿+Z位移0…50mm内的所有后裙/内根位置；位移超过50mm后，后裙最低Z≥43.5，已与OEM最大Z0由平面分离，对原厂实体体积相交0；主盘始终Z≥0。没有用几个离散姿态冒充连续证明。
- OEM8孔使用Ø5.8、从Z4.6向+Z的工具空间探针；须先卸H01。头侧4孔使用Ø7.8、从Z12向+Z探针。12条通道对其当步障碍均为0穿透。这些是空间探针，**不是已选定扳手或套筒**；头框未来仍要保留这些通道。
- SNS-M4-12对三个长度11.65/12/12.35分别做头径7.22、杆径4的外包络实体检查；并用杆/头沿+Z的连续扫掠包含体证明名义板厚下直向插入。M4螺纹用大径孔表示，螺旋牙型接触没有当成实体碰撞错误。
- 销与A01预期有2…10μm名义过盈，不按零穿透要求消除它；H01圆孔/槽宽相对销的最小名义直径间隙10μm。热、孔距、压入保持和实际销端需试件验证。只验证同轴直插，不包括倾斜装入、线束牵拉、真实头框或整臂运动。

装配顺序：在独立台架承托A01压销，避免压装力经过关节轴承；关节断电卸载后确认其受控牙深/配套螺钉，沿−Z套入A01并分次交叉锁OEM8颗；确认中心线束有余量和可解绑点，再装H01、锁4颗M4。拆头先卸载断电、解绑线束，松4颗M4后沿+Z退出；随后才能操作OEM螺钉。**不能在打印件上施加OEM的2Nm锁紧扭矩。**

## 5.394Nm场景的条件筛查

`g=9.80665m/s²`，2kg工件位于输出面前200mm，1.5kg预算头COM前100mm，轴线水平、重力横向时：`F=34.323275N`，`M=(2×0.2+1.5×0.1)g=5.3936575Nm`。1.5kg是设计预算，不是已实现的新头称重。如果偏移改从H01前面量起，新增12mm会令弯矩变为5.8055368Nm。此处未加入冲击、夹爪内力、异常停机或惯性负载。

对于中心化孔坐标矩阵P，取 `m=[−My,Mx]` 后，等刚度轴向螺钉增量为 `f=P(PᵀP)⁻¹ m`，任意弯矩方位的第i颗幅值界为 `M ||[P(PᵀP)⁻¹]i||`。OEM8孔虽不均布，却有 `PᵀP=diag(1936,1936)mm²`，单颗弯矩增量最大61.2916N；头侧4孔为`diag(2048,2048)`，最大84.2759N。横向直接剪力平均值分别4.2904/8.5808N，仅为另一个理想均分模型。

上述不是总拉力：需要预紧、压缩接触持续存在、无显著撬力并近似等刚度。螺钉滑移摩擦容量、铝牙剪切、最小有效牙、预紧损失和轴承倾覆能力均没有因此被验证。

脚本还对原创STEP的6个真实净截面求面积与惯性张量，并记录轴向截面应力指标；选一条8mm宽、4.4mm厚的局部条带，长度取头侧螺钉到最近OEM孔的中心距离，计算小挠度悬臂示例。**两者都不是整体保守强度上界**：圆盘径向弯曲、孔口应力集中、止口接触与撬力需后续实体FEA/试验。因此没有用材料屈服值算一个“安全倍数”来宣布2kg达标。

## 打印件、文件与复算

A01-G把止口扩大至Ø50.4、中心Ø18.4、OEM孔Ø3.8、头侧孔Ø4.5、销孔Ø3.2；H01-G中心Ø18.4、销孔/槽宽3.3。这些间隙变化明确写入独立STL，金属名义CAD不整体缩放。量规只能检查宏观轮廓/孔位/接近顺序，不能验收金属止口精度、压入配合或承载。

PLA/PETG仅无电无载：A01-G前面Z8朝下，负Z方向建高；H01-G后面Z8朝下。先用同批材料/层高打印孔径试片，再按实测修正局部孔补偿；首层膨胀不要让Ø50边缘强压关节。导出容差0.01mm、角度0.05rad；STL重读全部watertight且绕向一致，体积相对偏差小于0.011%。切勿拿打印版带真实2kg负载或带动力运动。另提供`*-print-oriented.stl`，已按上述方向旋转/平移到打印Z=0；没有镜像。
