# Odradek 设计与验证路线｜R4

当前外形主线已选定：上两片大、下两片小、左右镜像。继续采用 7 DOF 本体、4 DOF 四片可拆末端，优先验证完整刚性灯板的收拢与抓取。阶段顺序表达工作依赖。

R4 已建立有来源的元件候选、静力与接触数学、同参数 STEP/Blender、独立指角域闭合证明、接口片与单指手动台架。当前进入承力连接、轴支承、灯光 IO 和台架集成，详见[工程入口](engineering/README.md)与[按项证据清单](engineering/release-checklist.md)。以下路线表达从研究到实物验证的依赖，不将生成文件等同于完成样机验证。

| 阶段 | 工作内容 | 进入下一步的依据 |
| --- | --- | --- |
| **R0／R1／R2：历史探索** | 保留本体形态、灯片抓取、片数和显示研究 | 明确 R2 展开正面已选定，紧凑保护茧不是已确认可达姿态 |
| **R3：几何反例与候选** | 同一完整灯板模型比较限位、轴向错层、根部偏置；分别检查空手与持物 | 区分 AI 视觉、任意 D 参数模型和真实机构；公开反例及模型范围，不把四矩形板连续域通过当作整头通过 |
| **任务与尺度定义** | 选桌面任务和工件，记录尺寸、接触条件、负载、范围及预算 | 为接触和机构共同确定实际设计输入，不把任意 D 换算成默认规格 |
| **同版整头包络** | 加入真实灯板轮廓、厚度、骨架、关节、软垫、屏幕、双鱼眼、掌体和线束 | 六对指片及各实体在允许独立角域内无交叉；收拢限位、实际间隙、禁止配置与光学遮挡均明确 |
| **接触样件与抓取验证** | 同侧凸起可换软垫／承力边框配凹入灯窗；比较定角垫及独立止靠面 | 接触法向、摩擦和夹持力有依据；不把物体推向屏幕或镜头承力；实测持物和释放，不能以空手合拢代替 |
| **相机与照明布局** | 上下鱼眼分别外倾、左右对称；选择倾角；四片照明与圆屏显示 | 按工作距离测视场重叠、指片遮挡、反射、可读性和温升；收拢状态能否观察由实测决定 |
| **模块与七轴协同** | 末端在 J7 输出法兰后拆卸；布置端侧执行器与控制、电源数据和锁紧；建立本体轴与限位 | 模块质量和载荷路径明确；同版 CAD 覆盖 J7 有限 roll、工作及停放，线束和桌面包络可行 |
| **行为与整机原型** | 用真实任务状态驱动注意力和显示；空手且任务允许才机械呼吸／表情性 roll | 抓取、保持、释放不受表达扰动；感知失效、停止及掉电行为有测试记录 |
| **工程深化与发布** | 完成力矩、刚度、惯量、材料、传动及 BOM；整理装配与控制资料 | 关键选型、样机记录和已知限制可追溯，外部贡献者可复现对应版本 |

当前数字研究见[收拢研究](r3-closure-study.md)和[几何检查图](concepts/11-r3-geometry-check.png)。它们不能确认图中头部已可制造或已有有效抓取；下一步的关键是将所有实体和工件纳入同一模型及样件。

2 kg 末端负载与先打印后金属加工已确认；工程计算暂用净工件口径，指根、限位和本体已有未冻结的参数布局。任务物体、相机实际倾角、传动支承、保持与反馈仍待验证。连续多圈旋转、自动换装和热插拔不属于当前已确认能力。
