# Odradek 设计与验证路线｜R1

阶段顺序表达工作依赖，不代表已承诺时间、成本或性能。图像是概念表达，下一步应先补足真实任务输入。

| 阶段 | 工作内容 | 进入下一步的依据 |
| --- | --- | --- |
| **R0：历史形态发散** | 保留六组轮廓、A／B／C、04 行为图和对应记录 | 明确原图的工具关系已由 R1 取代，仍可使用其本体审美参考 |
| **R1：一体化末端探索** | 比较 D2 两指对夹、D3 三指包络、D4 四指两组对向；优先绘制 D4 深化；探索中央圆形 LED 的特定显示 | 图文一致；区分用户需求、D4 建议与未定构型；不以图像宣称机构成立 |
| **任务与方向收敛** | 选择实际桌面任务，记录工件、接触条件、负载、操作范围和预算；用相同任务比较三案 | 明确主方向、目标工件与性能验证口径；记录仍未解决的问题 |
| **末端布局与样件** | 布置指骨架、内侧软垫、发光窗、驱动、中央模组与线束；检验开合、接近和抓取姿态 | 明确夹持力路径；检查指间／工件干涉、接触不一致、偏载和腕部质量；记录遮挡与维护问题 |
| **七轴协同布局** | 建立轴坐标、方向、限位与候选驱动；将末端体积和质量纳入本体设计 | 同版 CAD 覆盖工作和停放关键姿态；检查工件、护盖、手指、线束及桌面共同运动包络 |
| **照明、显示与行为原型** | 研究点阵与分区白光等构型的光学、散热和控制；验证方向／进度／完成／等待／故障图案；实现有约束的表达状态 | 测量任务照明、图案可读性、成像干扰及遮挡；确认空手才机械呼吸，抓取／保持／释放不被表情扰动，不为露屏松爪 |
| **工程深化** | 校核力矩、刚度、惯量、接触和温升；确定材料、传动、紧固、线束及 BOM | 关键选型有依据，装配维护可行，采购与制造条件明确 |
| **样机与任务验证** | 逐级测试关节、末端、整臂与目标任务；验证滑移、干涉、线束全行程、停止及掉电行为 | 保存测试记录，区分预编程演示与实际感知；问题关闭或明确限制，不凭外观或灯光宣称协作安全 |
| **可复现发布** | 整理设计源文件、装配说明、BOM、控制资料和已知限制 | 外部贡献者可按记录复现对应版本，概念、分析与实物证据可追溯 |

当前未确定：工件、负载、尺寸、臂展、驱动数量、传动、夹持力、显示分辨率、照明功率、感知与力反馈。它们应随任务和原型结果收敛，不能从概念画面补成已验证指标。
