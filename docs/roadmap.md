# Odradek 路线图｜从概念到可复现硬件

初始仓库收录本轮概念资产；下列工程工作均为计划，尚未完成，日期与责任人待确定。

| 阶段 | 可执行工作 | 进入下一阶段的依据 |
| --- | --- | --- |
| **本轮：概念发散** | 简报、六组轮廓探索、三案概念图、行为分镜、比较与资料边界；建立仓库 | 图文一致，七轴本体、夹爪与灯瓣机构自由度分开；不把草图表达为已实现能力 |
| **近期：任务与方向收敛** | 选一个真实操作任务；记录工件、附件、范围与预算；比较灯瓣展开／收拢和工具方式 | 形成负载口径、工具换装／共存选择及方向记录 |
| **布局验证** | 建立七轴坐标、轴向与限位；选择候选驱动；布置工具、光学头、灯瓣与线束 | CAD 体块覆盖关键姿态；记录灯瓣／工具碰撞、重心与装配问题 |
| **工程深化** | 完成承力件、护盖与紧固设计；校核力矩、刚度、惯量、光热；形成 BOM 和线束图 | 关键选型有依据，采购与制造条件确认，工程问题得到处理 |
| **注意力与灯光原型** | 分开定义关注朝向、任务照明、视觉跟踪和表达状态；验证慢张合与亮度呼吸，设置任务暂停行为 | 演示和测试记录清楚区分预编程动作与实际感知跟踪；不以视觉效果替代功能证据 |
| **数字样机** | 从同版 CAD 生成视觉及碰撞模型；建立 URDF、惯量与关节配置，检查关节编号和零位 | 模型与工程版本对应；仿真结果明确其适用边界 |
| **样机与任务验证** | 分级测试关节、灯瓣、整臂与目标任务；验证急停、掉电、线束全行程、光照与夹点 | 测试有记录；问题关闭或明确限制；不凭外壳或灯光宣称协作安全 |
| **可复现发布** | 整理可编辑 CAD、STEP、制造文件、BOM、装配／接线说明与测试记录；核对授权范围 | 第三方能按版本资料复现，且了解已验证能力与未验证边界 |

近期优先顺序：**任务输入 → 概念选向 → 执行器与包络 → 结构和护盖共同深化**。URDF、BOM 或 CAD 文件的存在本身不代表样机通过验证。
