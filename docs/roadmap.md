# Odradek 设计与验证路线｜R2

阶段顺序表达工作依赖，不代表承诺时间、成本或性能。当前已确认 7 DOF 本体、4 DOF 四片末端及可拆模块方向。

| 阶段 | 工作内容 | 进入下一步的依据 |
| --- | --- | --- |
| **R0／R1：历史探索** | 保留整体形态、灯片夹爪及中央灯光探索 | 历史图与当前方向区分清楚，提示词和决策可追溯 |
| **R2：当前概念收敛** | 比较 3／4／5 片艺术效果；深化左右各一组近邻双瓣、左右镜像而非中心对称的四片；画 J7 roll、可拆接口、圆屏、双鱼眼及空手全闭 | 同一方案的开闭状态、相机位置、指片数量和模块分界一致；确认 nickname 后再决定是否采用 |
| **任务与尺度定义** | 选择桌面任务，记录工件、接触条件、负载、操作范围、臂展、尺寸和预算 | 明确末端与本体共同使用的任务和性能验证口径 |
| **末端机构与接口样件** | 四指各 1 DOF；建立指骨架、软垫、指内分节联动、发光窗、圆屏、双鱼眼；将执行器与端侧控制布置在模块内 | 检查全开、抓取、空手全闭的净空和夹持力路径；明确模块质量、定位锁紧、载荷、电源与数据接口 |
| **七轴协同布局** | 建立 J1–J7 轴坐标、限位和驱动；J7 沿末端法线，模块位于输出法兰后 | 同版 CAD 覆盖工作、roll 与停放姿态；检查本体、末端、工件、桌面及线束的共同包络 |
| **照明、视觉与行为原型** | 四片提供照明；单圆屏画关注、进度和圆周图案；双鱼眼随整头转动；实现受任务约束的呼吸与注意力 | 验证照度、温升、显示可读性与视觉遮挡；全闭作为保护态，展开后再恢复观察；抓持不受表情动作扰动 |
| **工程深化** | 校核力矩、刚度、惯量、接触与温升；确定材料、传动、紧固、线束和 BOM | 关键选型与接口有依据，装配和维护可执行 |
| **样机与任务验证** | 逐级测试关节、可拆末端、整臂和目标任务；检查滑移、干涉、roll 线束、停止及掉电行为 | 保存测试记录，区分预编程演示与实际感知；问题关闭或限制明确 |
| **可复现发布** | 整理设计源文件、装配说明、BOM、控制资料和已知限制 | 外部贡献者可按记录复现对应版本，概念、分析和实物证据可追溯 |

近期优先验证四个问题：**四指如何以各 1 DOF 完成开闭和接触；全闭能否避开相机与圆屏实体；模块质量及接口是否适合腕部；J7 有限角度 roll 的线束路径是否可行。** 全闭允许遮挡光学视线，但不能发生零件碰撞。

具体工件、负载、尺寸、其余本体轴布局、传动、夹持力、显示分辨率、照明功率、感知和力反馈仍需随任务与样件收敛。连续多圈旋转、自动换装和热插拔不属于本轮已确认能力。
