# Odradek 设计简报｜R1 概念阶段

版本：2026-09-27。阶段：外观与本体共同探索；尚未完成工程设计。

## 已确认需求

- 项目名 **Odradek**，仓库 `Auromix/odradek`；首版采用桌面或固定底座，执行实际操作任务。
- 本体设计目标为七轴；末端抓取与表达所需的驱动自由度另计，不预设灯片与夹爪是两套机构。
- 通过关注朝向、任务照明、末端发光片的张合与光强变化，表达主动注意力和呼吸感。
- **灯片本身兼作夹爪手指**，抓取、承力、发光与外观共同设计。
- 探索中央圆形 LED 承担照明和特定显示；用户尚未指定具体模组构型。
- 借鉴游戏装置的机械层次与展开／收拢剪影，形成原创设计。概念图和仓库不代表已有可运行硬件。

## R1 工作假设

- 对比 D2 两指对夹、D3 三指包络、D4 四指两组对向。**建议优先深化 D4，尚未由用户选定最终方案。**
- 每指以承力骨架传递抓取力，内侧设置可换软垫，外侧或侧面设置发光窗。发光表面不默认承担工件接触。
- R1 图示暂用中央点阵与外圈分区任务白光，分别考虑光学、散热与控制；显示、照明、相机的具体位置和构型尚未定型。
- 显示图案可探索关注方向、进度、完成、等待、故障；它们表达任务状态，不证明感知、识别或跟踪已经实现。
- 机械呼吸仅在空手且任务允许时进行；抓取、保持、释放阶段不为表情改变夹持。灯光呼吸受任务照明和成像约束。圆盘被工件遮挡可以接受，不得为露出显示而松爪。
- 本体暂以“肩部 3 + 肘部 1 + 腕部 3”组织七个转动自由度；轴向、偏置、限位和驱动待确定。肩部较稳固、末端体量递减，关节、承力件与可拆护盖保持清晰层次。

R0 的 A FIELD、B FRAME、C SHELL 和 04 行为图保留为历史发散。其骨架、护盖与整体比例仍可提供审美参考；观察头换装或独立灯片搭配普通夹爪的工具关系已由 R1 取代。R1 见 [机构候选图](concepts/05-petal-gripper-options.png)与[深化研究图](concepts/06-petal-gripper-study.png)。

## 未知输入与验证边界

目标工件、操作流程、负载口径、臂展、精度、速度、持续工作时间、尺寸、预算、制造资源和断电行为均未确定。指形、抓取行程、驱动数量与传动、力反馈、照明参数、显示分辨率、光学视场与感知方案也未确定，暂不承诺性能、成本或协作安全。

每轮共同检查驱动与承力、全行程运动、装配维修，以及夹持力路径、指间／工件干涉、光学与显示遮挡、线束和散热。概念图不能证明机构成立或真实任务成功。

## 工业设计流程与本轮位置

1. **发现与定义**：梳理实际任务、环境和参考，补足对象与性能输入。
2. **发散与深化**：R0 探索整体形态；R1 将发光片与抓取合并设计，对比 D2／D3／D4，并以 D4 绘制深化研究。
3. **收敛**：按同一组目标工件、工作／停放姿态与维护条件比较，选定方向及待验证细节。
4. **协同深化**：机械、电气与工业设计共同建立真实执行器、接触面、光学模组、线束和运动包络。
5. **原型验证与发布**：以末端样件、七轴体块、工程样机和任务测试逐步验证，再整理可复现资产。
