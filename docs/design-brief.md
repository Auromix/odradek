# Odradek 设计简报｜概念阶段

版本：2026-09-27。阶段：外观与本体共同探索；尚未完成工程设计。

## 已确认

- 项目名 **Odradek**，仓库 `Auromix/odradek`；首版采用桌面或固定底座，执行实际操作任务。
- 本体设计目标为七轴；夹爪开合与额外灯瓣机构的自由度单列，不计入七轴。
- 显式设计需求：主动注意力的朝向表达、探照灯、末端数片灯瓣、慢速张合与亮度呼吸感。
- 借鉴游戏装置的机械层次与展开／收拢剪影，形成原创设计；表达动作在操作任务中应可暂停。
- 本轮交付若干候选概念图及项目仓库；仓库内容不代表已有可运行硬件。

## 草图共用假设

- 暂以“肩部 3 + 肘部 1 + 腕部 3”组织七个转动自由度，仅作概念比较；轴向、偏置及限位均待确定。
- 用同类固定底座与操作臂比较三种光学灯瓣头；夹爪共存或换装方式随方案探索，尚未定型。
- 肩部较稳固，末端体量递减；关节、承力件、可拆护盖有清晰层次。图中比例不作为加工尺寸。
- 优先探索标准驱动、机加工承力件和打印护盖的组合，工艺与材料仍需验证。

## 未知输入

目标工件、操作流程、负载口径（是否含夹爪／相机／灯瓣）、臂展、精度、速度、持续工作时间、预算、制造资源和断电行为均未确定。探照灯功率、光学视场、灯瓣驱动及自动跟踪感知方案也未确定。暂不承诺性能、成本或协作安全。

关注朝向与灯瓣动作是设计需求；自动感知、识别、跟踪能力尚未实现或验证。任务照明／视觉跟踪与表达动作分别定义：任务需要优先，呼吸亮度与张合不应干扰成像、抓取或人员观察。

## 典型工业设计流程与本轮位置

1. **发现与定义**：梳理任务、使用环境与参考，建立上述简报；当前输入尚不完整。
2. **发散与概念深化**：先绘制六组轮廓／灯瓣变体，再深化为 A／B／C 三案，比较轮廓、分件、维护与运动表达。本轮交付到此，并补充行为分镜，供下一步评审。
3. **收敛**：用相同工作、停放和维护姿态评审，选定主方向与待验证细节。
4. **协同深化**：机械、电气与工业设计共同建立真实执行器、线束、装配及运动包络。
5. **原型验证与发布**：体块样件、工程样机和任务测试逐步验证；通过后整理可复现设计资产。

每轮共同检查承力与驱动、全行程运动、装配维修三个空间，另检查灯瓣展开与工具净空。概念图不能证明机构、传动、散热、光学或线束方案成立。
