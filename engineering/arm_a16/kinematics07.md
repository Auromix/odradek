# A16 臂身运动学与载荷计算约定

全部CAD长度为mm；力矩计算转为m、rad、kg、N。`kinematics07-joint-table.csv`列出的轴向、偏移和零位与当前Blender关节层级共用`common.py`。零位是设计几何约定，尚不是到货编码器校准值。

根坐标到桌面世界坐标为绕Z转90°，再平移[0,75,0]mm。七轴按序为Z/Y/X/Y/Y/Z/X；J2的几何转角为q₂−90°，因此q₂=0时上臂竖直向上。340/185mm是J3→J4、J4→J5偏移中的X分量，J5同时偏Y62mm；不能将二者相加当成全部实际TCP臂展。

设H(d)为局部平移矩阵，R(a,θ)为绕单位轴a的旋转矩阵。第j轴：

`F_j_fixed = F_(j-1)_rotor · H(d_j)`

`F_j_rotor = F_j_fixed · R(a_j, q_j + zero_j)`

第一轴的父矩阵为根世界变换。裸臂TCP为`F_7_rotor · H([110,0,0])`，工具法兰法向为其+X。J7轴与TCP偏移同轴，纯J7滚转不会改变法兰中心位置；头部另设的TCP必须在工具矩阵中单独定义。

在世界坐标中，第j轴方向wⱼ为`R_j_fixed·a_j`，轴心oⱼ为固定矩阵的平移。TCP速度雅可比列为：

`J_v,j = w_j × (p_TCP − o_j)`，`J_ω,j = w_j`。

线速度雅可比使用m/rad，角速度雅可比使用rad/rad。`kinematics07.py`以独立位置与姿态有限差分检查五组关节角和七个轴，并检查J7滚转保持TCP位置。这只核对数学约定，不证明实物限位或整个工作空间可达。

重力保持力矩采用势能`U = Σ m_i·g·z_i + m_payload·g·z_TCP`的梯度；`τ_hold = ∂U/∂q`，重力广义力方向与它相反。`gravity.py`按轴上游关系直接累加重力矩，并用独立势能差分复核。原厂电机内部质量分布未测量，使用目录总质量和明确的几何中点代理；塑料/管材和名义采购件使用当前CAD体积，未建线束与补偿件另列余量。

3kg工况是裸法兰中心外部总负载。工具重心偏离法兰中心时，须加入真实工具矩阵/质心重新计算，不能沿用当前3kg数字。当前计算只有静态重力，未含惯性、摩擦、碰撞、挠度、封罩温升和掉电保持；肩部未通过持续保持参考，详见`release-gates07.md`。
