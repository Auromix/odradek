# A16 常规结构路线

全灵足链候选：J1 RS03；J2/J3/J4 RS04；J5/J6 RS10P；J7 RS00。RS10P 原生减速比25，不叠加传动级。长版轴距340 /185 mm保持，法兰中心净外载目标3 kg。当前仍是制造数据逐模块构建和**有支撑、断电、空载的试装验证**，没有整臂生产发布。

结构优先使用法兰、板式支架、标准金属管、普通螺钉、分体外罩。肩部候选补偿为一根商用气弹簧加两个销轴；不会增加凸轮、差动、同步齿轮或多电机并联。原厂关节内置减速器及驱动器保留。打印验证阶段不装带力气弹簧。

## 底座同源和优先级

当前构建读取兄弟工作区 `../odradek/engineering/base_b06/arm-handoff.json` 及其**同一份 B06-COMPACT-07-DFM**实体，不修改、缩放或另行设计底座。每次构建检查接口、原生Blender、外观清单、承力清单与法兰STEP五个哈希；变化时停止生成，避免静默沿用过期接口。记录在 [base-context.json](build/base-context.json)。A11/B05、A12/A14旧B06上下文仅作历史来源。

底座安装面z58，轴心(0,75)，PCD120的8×M6通孔，Ø56出口和Ø136罩颈保持。臂侧新适配盘Ø134可从上方装入。J1轴心升至桌上165 mm，为真实电机、连接件、线束和肩部补偿预留空间；该变化尚需全姿态与整机重心复核。

底座RJ45仍是**EtherCAT专用的被动直通**。原生灵足CAN电机不能据此当成EtherCAT设备。臂侧CAN/桥接方案、速率、延迟与独立使能链尚待完成；不重定义底座RJ45针脚。双GMSL同轴、电源和灯控也保留底座边界。

## R01 根部试配

[root01/manifest.json](build/root01/manifest.json)、[STEP](build/root01/step/)、[STL](build/root01/stl/)、[紧固件表](build/root01/hardware.csv)。STL坐标单位为mm；它不含单位元数据。所有STEP都在各自装配坐标中，打印时按清单转到平面，不能据此改变装配基准。

- R101：Ø134×8环形适配盘，中央Ø56，8×Ø6.6 /PCD120相位22.5°；四个M5螺母槽从上面装入，螺母和螺钉不进入底座实体。
- R102：Ø134、内孔Ø72.4、厚6的J1正面环形支架，原厂PCD98八孔及四个立柱孔。
- R103：同轴短支座，Ø70×20下柱、Ø120×10上盘。六个M4输出螺钉从深9.5 mm工具孔进入，接触面处握持厚20。该件可常规车削加铣钻；打印用于尺寸试配。
- R104：四根**购买金属隔套**Ø12 /内孔Ø5.5 /长96.5 +0/−0.1。早期打印验证也不将承力立柱改成塑料。

装配顺序：先对R101孔径/螺母槽打样；装四个M5螺母；固定R101至底座；将R102固定到断电RS03；放四根隔套、穿四根M5×110并逐步均匀紧固；装R103和六根M4×25；最后安装肩部与外罩。M6×20向底座THRU孔的10.4 mm名义旋入长度需要核查底座下面是否与相邻件接触，不能仅凭螺纹为通孔宣告通过。

RS03已重新核对：相同PCD98有前后两组螺孔。正面接触面为原厂Z35，正面孔圆柱区间Z26..34.5；旧元数据的Z−1.5..7对应背面另一组孔。正面几何基准保留，孔深依据2D的8 mm，不能从背面圆柱推导正面可用螺纹。

各件BREP有效、单实体、导出网格闭合只说明几何文件可用。打印尺寸、收缩、螺母落座、支架压溃、工具实际操作和所有运动/线束仍须按模块验证。PETG/PA12制造参数是打样起点，不能将打印件作为3 kg承载产品。以后金属骨架需重新验证疲劳、轴承反力、温升、停机保持和冲击。
