# A16 常规结构路线

**当前收敛试配资料：** [整臂打印试装包](../../manufacturing/selected/arm-body-a16-fit/A16-complete-body-supported-fit.zip)、[41页打印件工作图](../../manufacturing/selected/arm-body-a16-fit/drawings/41-print-part-fit-drawings.pdf)、[逐段装配](assembly07.md)、[制造放行缺口](release-gates07.md)、[走线边界](harness-boundary07.md)。C03根部、C04肩肘、C05腕部、C06长罩已合并，当前41件打印件、6件金属管材/隔套、494个名义紧固/采购小件。全部外罩现有普通固定结构；三个代表静态姿态和模块预留工具空间检查通过。**只允许外部支撑、断电、空载试装；完整运动、线束和3 kg承载仍未放行。**

完整实际电机Blender保存在本地`work/arm-a16/actual-motors-modules.blend`；公开[自有件Blender](../../manufacturing/selected/arm-body-a16-fit/A16-body-own-parts.blend)不含原厂电机再分发实体。底座读取同一B06源，不改几何、尺寸和协议。

[整合检查](build/assembly07-audit.json)核对41件贴床文件、41+3页当前工作图、541件自有/采购包络、36条罩固定轴线及归档哈希。[运动采样](build/motion07.json)记录修正J6固定点与J7罩裙后26个有限配置通过；不代表全连续运动或任意滑条组合合格。

下面R01/C02说明及其16件骨架包属于历史模块来源；当前装配以整臂试装包的`replacement_chain`为准，不重复安装已替换旧件。

全灵足链候选：J1 RS03；J2/J3/J4 RS04；J5/J6 RS10P；J7 RS00。RS10P 原生减速比25，不叠加传动级。长版轴距340 /185 mm保持，法兰中心净外载目标3 kg。当前仍是制造数据逐模块构建和**有支撑、断电、空载的试装验证**，没有整臂生产发布。

结构优先使用法兰、板式支架、标准金属管、普通螺钉、分体外罩。肩部候选补偿为一根商用气弹簧加两个销轴；不会增加凸轮、差动、同步齿轮或多电机并联。原厂关节内置减速器及驱动器保留。打印验证阶段不装带力气弹簧。

## 底座同源和优先级

当前构建读取兄弟工作区 `../odradek/engineering/base_b06/arm-handoff.json` 及其**同一份 B06-COMPACT-07-DFM**实体，不修改、缩放或另行设计底座。每次构建检查接口、原生Blender、外观清单、承力清单与法兰STEP五个哈希；变化时停止生成，避免静默沿用过期接口。记录在 [base-context.json](build/base-context.json)。A11/B05、A12/A14旧B06上下文仅作历史来源。

底座安装面z58，轴心(0,75)，PCD120的8×M6通孔，Ø56出口和Ø136罩颈保持。臂侧新适配盘Ø134可从上方装入。J1轴心桌上165 mm，J2相对J1升高114 mm；修正低位肩支架相碰。仍需全姿态与整机重心复核。

底座RJ45仍是**EtherCAT专用的被动直通**。原生灵足CAN电机不能据此当成EtherCAT设备。臂侧CAN/桥接方案、速率、延迟与独立使能链尚待完成；不重定义底座RJ45针脚。双GMSL同轴、电源和灯控也保留底座边界。

## R01 根部试配

[root01/manifest.json](build/root01/manifest.json)、[STEP](build/root01/step/)、[STL](build/root01/stl/)、[紧固件表](build/root01/hardware.csv)。STL坐标单位为mm；它不含单位元数据。所有STEP都在各自装配坐标中，打印时按清单转到平面，不能据此改变装配基准。

- R101：Ø134×8环形适配盘，中央Ø56，8×Ø6.6 /PCD120相位22.5°；四个M5螺母槽从上面装入，螺母和螺钉不进入底座实体。
- R102：Ø134、内孔Ø72.4、厚6的J1正面环形支架，原厂PCD98八孔及四个立柱孔。
- R103：同轴短支座，Ø70×20下柱、Ø120×10上盘。六个M4输出螺钉从深9.5 mm工具孔进入，接触面处握持厚20。该件可常规车削加铣钻；打印用于尺寸试配。
- R104：四根**购买金属隔套**，常规Ø12×壁厚3圆管（内孔Ø6），长96.5 +0/−0.1。早期打印验证也不将承力立柱改成塑料。R103打印时以宽上盘贴床、输出接触面朝上，避免25 mm的周边悬空；打印变换单独记录，不改变装配坐标。

装配顺序：先对R101孔径/螺母槽打样；装四个M5螺母；固定R101至底座；将R102固定到断电RS03；放四根隔套、穿四根M5×110并逐步均匀紧固；装R103和六根M4×25；最后安装肩部与外罩。M6×20向底座THRU孔的10.4 mm名义旋入长度需要核查底座下面是否与相邻件接触，不能仅凭螺纹为通孔宣告通过。

RS03已重新核对：相同PCD98有前后两组螺孔。正面接触面为原厂Z35，正面孔圆柱区间Z26..34.5；旧元数据的Z−1.5..7对应背面另一组孔。正面几何基准保留，孔深依据2D的8 mm，不能从背面圆柱推导正面可用螺纹。

各件BREP有效、单实体、导出网格闭合只说明几何文件可用。打印尺寸、收缩、螺母落座、支架压溃、工具实际操作和所有运动/线束仍须按模块验证。PETG/PA12制造参数是打样起点，不能将打印件作为3 kg承载产品。以后金属骨架需重新验证疲劳、轴承反力、温升、停机保持和冲击。

## 常规整段骨架与平腕

[skeleton01/manifest.json](build/skeleton01/manifest.json)提供18个承力/接口试配实体，含两根购买的20×40×2矩形铝管；长版上臂、前臂轴距仍为340/185 mm。上臂管长220 mm；前臂管长55 mm，常规U形后侧固定板完成剩余跨度，避让腕部回折范围。所有新连件都是法兰、直角支架、插接套和普通钻孔，未引入新传动机构。

平腕把J6电机中心放在本轴平面，J5→J6轴向距离55 mm，J6→J7为75 mm；电机轴、原厂减速比与接口没有缩放。J5输出面沿本轴Y40，J6输出面沿本轴Z−30.3。J7保留原有轴承盒及J7局部X110法兰。IF304/305是工具侧验证假件，已从裸臂模型和自重账本排除，不将其计成裸臂固定自重。

[骨架检查](build/skeleton01/review.json)只检查报告列出的三个静态配置和实体。不得把它扩展为滑条全部组合、运动路径、紧固件装配、外罩或内部线束的通过结论。[质量与重力复算](build/gravity.json)使用实际均匀塑料CAD和明确未建件余量；它不等于后续金属骨架。当前肩部3 kg持续负载没有合格结论，目录峰值120 N·m也不能代替持续零速约束。

[18件当前外罩候选](build/covers02/manifest.json)以CAD薄壁实体表达已选A连续甲壳方向；固定、移动罩相互独立，长向曲线搭配截面折线。当前已采用常规后盖与连接窗口，并将上臂/肘部同一刚性段合并后分为可打印接缝。其安装螺钉、固定耳、连续运动和线束尚未完成验证，**不进入最终制造选项目录或根部已检查的试配包**。
