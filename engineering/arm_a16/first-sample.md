# A16 首件尺寸与装配记录

当前目标是验证常规骨架能否实际打印、加工管材并装上原厂关节。首件使用外部支撑、断电、空载；打印骨架不承担3 kg运行资格。记录件号、实测数值、照片、偏差和处理方式，不能仅填写“通过”。

## 打印及普通管材

先打印小样校准孔、螺母口袋、插套和轴承配合，再打印19个根部/本体试配件。切片检查悬空面和支撑是否损伤接触面；当前并未提供已验证的G-code。

| 项目 | 名义值 | 实际应记录 |
| --- | --- | --- |
| 铝管 | 20×40×2；L220/L55 | 四面尺寸、壁厚、切长、端面垂直度 |
| 插套 | 20.4×40.4 | 去毛刺后无强压插入、拔出及实际间隙 |
| 横向孔 | Ø4.5，穿20宽度 | 孔位与同轴性，不能沿40方向钻 |
| 八个防压溃套 | Ø8/ID4.5/L16名义 | 实际管内宽和套长，不用螺栓压扁管壁 |
| 四根根部立柱 | Ø12/ID6/L96.5 +0/−0.1 | 等长、端面、整圈落座 |
| J7轴承孔/轴颈 | ID47.2 / OD34.95名义 | 用实际6807及既有配合小样校准，记录轴向游隙 |
| 根部走线槽 | 6×14，端R3，R55，55°/235° | 去毛刺、护边、线束/插头真实通过能力 |

打印件夹紧力和螺钉扭矩尚未定标。当前所有旋入数据先按图纸核对；确认盲孔、垫圈、螺母及工具空间后再制定拧紧过程。

## 逐段装配与人工试动

按[装配说明](assembly01.md)从根部到腕部装，所有自重由支撑架承担。记录R103输出螺钉先装后被S101遮挡的拆装顺序，以及S104/S107工具槽能否让实际工具通过。每段完成后检查接触面落座、销是否顶底、螺钉是否压住转动件。

先逐轴小范围人工试动，再试模型中的idle、attention、reference。记录每次接触的件号和关节角；不以驱动力越过干涉。三个姿态的CAD结果不覆盖滑条所有角度组合，也不覆盖任意两姿态间的路径。

18个外罩仍是候选；它们的固定耳、真实线材、服务环和连续转动尚未完成。外罩不得混进当前骨架首件打印套装。根部两个4×10空包络和管内Ø12直段均不是完整线束设计。

## 下一阶段必须补齐的实测

1. 灵足各关节真实接口、原厂允许紧固扭矩、封罩散热与掉电行为。
2. 线材/同轴型号及弯曲半径、动态余长、夹线点；外置盒的独立CAN接口方案。底座现有RJ45仍按EtherCAT专用直通保留。
3. 单气弹簧实际力—行程、温度、摩擦和滞回；当前只研究两个普通销点，未设计或安装带力机构。
4. 金属骨架的材料、减重截面、轴承反力、强度、疲劳、变形和加工公差，再验证3 kg法兰总外载。

以上均未在数字模型中获得生产资格；[issue-audit.json](build/issue-audit.json)只证明资料来源及包内哈希一致。
