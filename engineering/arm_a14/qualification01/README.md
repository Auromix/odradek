## 计算边界与独立复核

采用哈希固定的 A11 轴线、关节坐标与电机质心；工具平面采用已集成的 J7 局部 X110，非旧 X65.7。骨架、甲壳、五金、线束质量全部置零。3 kg 工件为法兰中心点质量；没有假定实际工件的惯性和偏心。

旧电机预算使用 RS03 0.920 kg、RS04 1.440 kg、RS00 0.313 kg；目录名义质量为 0.900、1.420、0.310 kg，RS06 为 0.621 kg。**改用目录名义质量后，J2 为 31.557 Nm、J4 为 14.409 Nm，结论不变。**为避免把质量预算称为实物绝对下界，另算已给出的质量下限并将没有公差的整个 RS06 人为置零；该极端轻化诊断仍使 J4 为 13.266 Nm，但 J2 为 28.255 Nm，不能独立用它证明 J2 超限。

所谓“无骨架下界”只在给定电机质量、质心和同方向重力项的模型条件下成立；不是证明所有补偿机构或新布局都不可行。伸直姿态不是本轮认定的碰撞合格工作姿态，J6 诊断也只在关节角域内。若限制工作域，必须先给出经碰撞和任务验证的范围，不能靠隐藏超限姿态宣称整臂满足原目标。

递归力矩与逐物体直接求和一致；重力势能中心差分独立验证最大误差 2.12e-9 Nm。结果和逐物体贡献在 [`build/motor-only-review.json`](build/motor-only-review.json)。复现：使用仓库 CAD Python 运行 `review.py`；不会修改原 A11 布局。

## 扩大角域诊断

`domain.py` 使用目录名义电机质量，4096个 Halton 角域点加3个命名姿态，骨架等仍置零。最大采样需求 J2 31.557、J3 14.131、J4 14.409、J5 6.712、J6 4.049 Nm；J1/J7 在本点质量重力模型中为零。具体力矩、弯矩、轴力和对应角度在 [`build/motor-only-domain.json`](build/motor-only-domain.json)。每个最大值见证点另做势能差分校验。

J3 的诊断需求也超过13 Nm 表值，不能只换肩、肘后认定原关节链合格。这些点没有先经过碰撞筛选，不代表可执行工作空间；采样最大值不是全域上界。保留这个限制，不据它发布额定负载或删减用户要求的活动范围。

## 进入制造的实际门槛

必须有同版本关节几何/孔型/有效牙深、持续载荷与热边界，随后才冻结金属关节座。质量账本、动态周期、失电支撑/保持、全臂外罩、运动线束及桌夹力流应随新布局重算。STEP 与图纸完成仅意味着可试制；生产达标还需要样机负载、刚度、温升、线缆循环和装配重复性实测。
