# A14：从外观试配推进到工程样机

长版、裸法兰中心 3 kg、七轴、低位 Z 折叠、A 连续甲壳继续保留。底座仍使用另一会话的同一份 B06 源；四瓣头仅作为风格参照，不在此处另造一版。

**当前未达到生产标准。** 最新的[关节持续载荷复核](qualification01/README.md)揭示 J2/J4 的当前电机配置不能按零速持续扭矩放行，J6 也有工件单独力矩超表值的诊断姿态。新关节选择、动态线束和金属承力骨架仍是总装冻结前置项。

本轮深化采用三个独立版本层：

- 已确认外观语言：底座宽肩收腰，臂身一条连续脊线与渐细长连杆，腕部收束为硬折面，深灰蓝/黑色缝/少量琥珀。
- 可复用模块：长连杆分体甲壳、标准管、隐藏骨架安装点，制造文件独立于电机适配端。
- 关节适配模块：供应商同版本模型、负载/热证据、金属关节座、接口线束；通过后才发布新的完整总装。

原 A13 局部腕部打印包保持历史有效范围，不扩充为整臂带载制造包。A14 新件先用于受支撑、无载的外形与装配研究。后续制造放行按[制造约束](../arm_a13/manufacturing-brief.md)逐项记录，不能由一张渲染图或封闭 STL 代替。

[LINK-SHELL01](link-shell01/README.md)已将上臂/前臂变成四件同源CAD分壳，收紧两端，补全原固定点与检修孔；三种命名姿态及两段路径的32个中间点通过该模块范围的实体干涉检查。角域诊断还发现旧J6后罩在J5=-90°处相交，随后单独修正该后罩。

[WRIST-TAIL01](wrist-tail01/README.md)为当前集成版本：四件连杆分壳加缩短的J6后罩，65个离散配置的新件相交检查全部通过。[滑条预览](../../docs/viewers/arm-body-a14-wrist-tail01/index.html)、同版本Blender和五件增量试配包已更新；原尺寸电机、长版轴距、底座源没有变化。其他关节造型罩仍未全部实体化，未宣称完整身体外观已定稿。

扩大关节角域的电机名义质量诊断发现J3也超过当前零速表值。新的[候选比较](candidate01/README.md)核对了X10/X8/X6的具体版本、温升与中孔，并单独列出低减速比腕部方向；不能只替换J2后便冻结整链。
