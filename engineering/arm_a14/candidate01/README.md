## 推荐的研究顺序

1. 若接受近端约20:1：先验证 X10 肩部、X8 上臂滚转/肘部、较低减速比腕部的组合。X8约Ø96，值得用来减小旧大关节与外罩的视觉突出；其1.33 kg下游质量必须重新反推肩部需求。**这只是分配候选，没有通过整链计算。**
2. J6 从RS00升为RS02是较低减速比的候选；需要取得同版本安装模型及零速热条件。不能直接沿用旧RS00腕座，也不能把未确认中空画成贯通线道。
3. 若低减速比腕部不能满足完整腕部质量/线束力矩，再比较中空X6；其Ø80和0.780 kg会影响腕部修长比例与近端负载，不能只看扭矩变大。
4. 若仍坚持约9:1，则优先研究补偿机构或更大的近端关节；这会修改体积、失电状态和手动回驱体验，不能隐藏在“外观细化”里。

X10原厂STEP已经取得并检查为有效、30个实体。其原始轴向是Y、轴向长63.5 mm，径向中心在原文件坐标X≈-1.250668、Z124，外径124；原厂原点不是本体关节原点。只有完成轴线/安装面/定位孔/有效牙深的映射才可导入装配，不可直接按外包盒自动吸附。

## 下一版冻结所需证据

- **关节**：同一SKU的STEP、2D图、安装面/止口/孔圆/有效螺纹深度、编码器零位及线束端口实体；轴承径向/轴向/倾覆能力和力矩寿命限制。
- **持续与动态工况**：供应商明确安装导热与零速能力；本体完整质量账本，从J7向J1反推静载、动态和反力。运动周期、偏心/惯性、失电保持方法仍需定义；不能以点质量模型覆盖所有工具。
- **线束**：两路GMSL2成品线及连接器、供电与控制线规格；各活动关节的最小动态弯曲半径、锚点、储线和扭转限制。中孔净空间不等于线束连续路径。
- **结构与外观**：独立金属承力骨架、可拆非承力甲壳、所有电机适配端；按已选连续脊线/硬截面/窄分缝重建关节罩，不能用缩小电机换取纤细外观。
- **试制和验收**：完整2D基准/尺寸/公差/材料/表面处理、紧固BOM与工具通道；塑料受支撑试配后做金属样机的负载、刚度、温升、线束循环和重复装配试验。未产生实測数据前不发布生产达标。
