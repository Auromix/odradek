# B06 紧凑一体盾形底座

**当前底座唯一来源。** 本体与其他设计会话读取本目录，修改也统一回到本目录；只读缓存不作为另一套设计。见[底座同源规则](../../docs/engineering/base-authority.md)。

2026-10-08；用户已确认256×256×256 mm打印空间及紧凑一体方向。本文件夹只放本轮收敛候选，B05及其历史保持独立。

主外罩约 **239×224×71 mm**：前鼻、左右翼肩和颈台是一件，外表面不再布置M3固定孔。保留两侧较宽的后翼、较小的前肩、收腰、连续折肩线及琥珀灯窗，呼应四瓣末端。颈部开口ID136、顶部Z74；轴心为XY(0,75)，Z0为桌面，+Y朝桌内。打印床尺寸不用于缩放电机、PCB或安装孔。

## 本轮外观细化 · B06-COMPACT-02

沿用已确认的一体主罩与紧凑包络。颈台顶部保留Ø136圆口和Z74，外侧改为小倒角、短直壁和直线斜面，减轻原来圆鼓的环形感。肩面径向下降坡度由0.22改为0.8，折肩位置由外扩行程的69%内收至51%，让两侧斜裙展开，减少直立侧壁的厚重感。四个浅肩脊在颈台和外缘收敛，呼应末端四瓣；这些是连续实体曲面，不新增分件或装饰孔。

前灯窗中心由Y171移至Y165，避开新的折肩转角。灯窗、罩内M2柱和压条随实际曲面重建；M2柱顶按整个圆周的罩面做随形收口，压条支点按整个接触圆面最低的灯窗内表面留出0.4 mm，避免局部穿面；透光件仍需光学与实物配合验证。后盖出线槽、六颗底面M3和PCB支柱坐标保持；元件及根部安装孔没有缩放。

法兰周围的颈台根部仍为Z60：降低此处会与Ø160法兰的实体预留发生干涉，因此收薄集中在外肩和斜裙。五件架构、约239×224×71 mm外包络、256³打印目标与装配顺序不变。隐藏螺钉、后盖边界和琥珀灯窗形成主要功能细节，主视觉面保持完整。

## 内部接口

J1按RS03保守包络Ø106×57 mm预留；电机固定侧PCD98八M4保留在项目顶环网格中。底部PCD120八M6孔阵及Ø160×12 mm法兰空间保留，安装平面Z58。新增的Ø136颈口同时考虑根柱与八颗M6的竖向工具入口，不把旧104 mm开口继续沿用。

根座和腰罩来自[固定输入](inputs/root-snapshot.json)的A11项目网格，采用yaw90°、平移(0,75,34.6)。A11根部安装圆台已收紧至Ø140；下方法兰仍预留Ø160，孔阵不变。这不是把旧A10腰罩直接缩进新壳，旧A10腰罩需改版才可复用。原厂电机精细CAD没有重分发；RS03圆柱是尺寸检具，不包含插头、传感器或转子分界细节。

接口板保持116×56 mm、厚1.6 mm；四个板孔为X±52、Y−10/34，板底Z20。I/O按既有B05候选MCAD整体Y−36 mm摆放，PCB支柱从底架伸到板底；不缩放元件、焊盘或板框。板、RJ45、端子、两路同轴及插头规划包络见[输入与变换](inputs/io-snapshot.json)。该输入含项目自建接插件尺寸抽象，不能视为全部原厂实体。原生嘉立创工程及其钻孔、线路、封装与MCAD一致性仍需电控模块核对，本轮未改PCB。

可换通信模块继续区分RJ45物理接口与实际协议；A04/A11是RobStride CAN路线，既有EtherCAT面板不能据此称为已实现的EtherCAT系统。独立48V和GMSL同轴的最终接线、应力释放与散热在后续接口模块处理。

旧B04桌夹、220×256 mm底板及盒架没有塞进缩小外壳。模型中的法兰仅是已知安装空间检具，没有悬空法兰能承载的含义；承载底板、立柱、后沿桌夹和向内收盒架仍需围绕新包络设计。外罩底架不承受2 kg工作载荷。

## 装配与打印

一体颈口Ø136小于根部安装圆台Ø140及腰罩最大外径。因此主罩不能从上方套过已装好的整支机械臂：先把根座从罩底装入，再连接底部承载接口，之后安装电机、顶环、腰罩和上部机械臂；腰罩与上部组件应保持可拆。完整动作顺序与工具可达性还须实物执行，本轮工具射线只检查主罩本身的遮挡。若后续要求不拆本体即可移走主罩，应重新讨论独立或剖分颈环，不能强行穿过小开口。

1. 先试印M3螺母槽、M2导孔和板孔小样，核对实际PETG/ASA补偿及螺钉尺寸。
2. 从外罩内部侧面插入六颗DIN934 M3螺母；四颗属于主壳，另两颗属于后盖。随形柱顶停在外表面内，避免把安装柱做成外部凸包。
3. 从内侧放灯窗，再装压条，用两颗M2×6拧入罩内导孔。压条支点在三圈采样的灯窗最低内表面下预留名义至少0.4 mm光学软垫空间；柔性垫片、压紧量和灯板都要实配确认。
4. 安装接口板与接插件，检查引脚及底架间隙。板固定M3导孔需要按打印工艺试配，不把塑料导孔当作已验证的螺纹连接。
5. 底架与主罩由四颗ISO7380-1 M3×10从底面固定；后盖另两颗。名义板顶Z7、罩柱底Z7.8，螺母槽Z10..12.8，M3螺杆Z7..17，覆盖螺母高度。底面头部向下伸1.65 mm。主罩拆卸需卸下底座，并拆下腰罩等遮挡件；后盖底部工具空间须与新桌夹一起验证。

`print-parts/`平移到打印坐标，`stl/`保留总装坐标；两者不是同一用途。主罩打印取向、支撑、底部支柱桥接、颈口圆度和收缩须在切片器中检查，不承诺免支撑。256 mm床检查每侧留5 mm，额外brim及排除区另计。

## 数字验证范围

- [打印检查](build/exterior/print-checks.json)：独立检查闭合、连通、法向、退化/重复面、正体积及256³床包络，不修补STL。
- [实体干涉检查](build/exterior/solid-fit-checks.json)：使用manifold3d对打印件之间、打印件与冻结根部/接口元件做封闭实体交集，阈值0.01 mm³用于排除数值噪声。报告检查数量、无效实体和所有超阈值交集。
- [表面接触与工具射线](build/exterior/fit-checks.json)：Blender重新打开原生文件，检查表面接触，并对八个根孔各取16条Ø13工具包络边缘射线。表面接触不等于体积干涉，以独立实体报告区分。

这些检查只覆盖冻结参考姿态和所列几何。没有覆盖J1扫掠、完整机械臂姿态、真实线缆与锁扣、打印层强度、温升、桌夹反力、机械臂承载或实体试装，不能据此做带负载运行或制造放行。

## 重建

用Blender4.5 LTS运行`blender_compact.py -- --no-render`生成原生模型和STL；随后重新打开生成的.blend运行`render.py`与`check_fit.py`。使用含numpy、trimesh、manifold3d及rtree的Python运行`check_solids.py`，并调用B05的独立`print_checks.py`指定`--bed 256 256 256 --margin 5`。最后运行本目录`viewer.py --build-dir build/exterior`。

`refresh_rear.py`和`refresh_lens.py`用于原生母曲面的局部重建，不读取或修补失败STL。主罩生成时的网格清理精度为0.01 mm，其余件为0.001 mm；最后一次罩面封口三角化后还会删除仅由三条自由边组成的零体积孤立薄片，保留所有实体连通分量供独立检查；上述精度远小于名义试装间隙，但仍不是打印补偿或制造公差。

本轮结果：5/5打印件通过网格与床包络；108组静态封闭实体交集无超阈值干涉；128条根部工具边缘射线无阻挡。原生复开仍报告预计接触边缘，因此不以BVH接触数宣称无接触，最终判定使用实体交集体积。
