# B06-COMPACT-04 无动力样件装配顺序

单位mm。Z0是桌面，+Y朝桌内，机械臂根轴位于(0,75)。仅适用于当前模型，禁止把历史B04/B05件混装。先核对BOM、图纸、模型及PCB版本；灯板、线束和插头释放仍是未关闭的整套放行项。

## 1. 金属件与桌夹预装

1. 将B06-101/102/103按STEP位置组成B06-W01焊接件：上板下表面Z2、腹板顶Z2；腹板底Z−90、下夹板顶Z−90。按评审图规定连续双侧角焊缝，腿长6，名义喉厚4.24。制造方须给出焊接工艺、夹具顺序和检查记录；模型不含焊缝实体。
2. 焊后确认上板基准平面和上下夹板相对位置，复查M12/M6螺纹。不得让焊瘤进入桌面保护垫区域或螺孔。不要在已装PCB、塑料、硅胶附近焊接。
3. 各M12螺杆装采购DIN6311压脚与随件卡环；压脚Ø25平面朝上。分压板与硅胶垫放在压脚上方。压脚球面座和卡环必须用原厂实际件核对，现有模型只有保守尺寸包络。

## 2. 根座与外罩

1. 准备主罩，先从内部放入四个M3螺母。灯窗/压条的最终板件与螺钉仍待灯板接口冻结；不把旧B04灯板直接用于本模型。
2. 在B06-104法兰下方安装四根B06-105柱，使用顶部M8×16。柱端面坐实，四个螺钉尖端Z33.5；柱底Z17。此步骤必须在根座覆盖法兰孔位之前完成。
3. 主罩颈口Ø136，小于根座外径Ø140；从主罩的大底部开口放入裸根座，不能从颈口硬压入。将法兰/柱组件从下方定位到根座下方，上配合面Z58。
4. 从裸根座上方依次装八个M6×20和1.6厚垫圈，PCD120、初相位22.5°。名义根座厚8、法兰螺纹咬合10.4。必须先装并检查这八颗螺钉，再装电机、顶部环和腰部外罩；模型中已用Ø13工具实体核对裸根座阶段的直线进入空间。
5. 从底部装金属承力板到四柱底端，再装底部M8×20。头部坐在Z10.5沉孔面，名义柱内咬合13.5，与上螺钉尖端间隔3。粘保护垫、夹桌和装盒架之前完成这些底向螺钉。
6. 外罩与根座是两条不同的定位/受力路径；不要用塑料隐藏M3螺钉代替根座M6或柱M8。

## 3. 接口板与后盖

1. B06-307底架放入四个PCB M3螺母和两个后盖M3螺母；PCB螺母从两侧插入，后盖螺母从上方放入。确认螺母不转动，必要时先做螺母配合小样。
2. 在PCB尚未装入底座时，用两个M3×8、上下0.5厚垫圈、M3螺母将空B06-309同轴支架固定到原生H5/H6，中心(X±10,Y−8)。PCB底面Z24，顶面25.6。确认板下螺母不接触铜皮；保持原生安装孔禁布区。支架螺钉必须在同轴接头安装前拧紧；接头本体会挡住上方工具进入，不能颠倒顺序。
3. 再将两个RF连接器装入支架：后侧AF9.8六角凹位容纳名义AF9.5固定法兰，前侧采购螺母锁紧。不得让装配扭矩传到板焊点或后盖；真实同轴插头/螺母扳手空间需样件检查。若日后拆支架，需先退出同轴连接器。
4. 用四个M3×10将PCB固定到底架，中心(X±52,Y−20/24)。原生板框116×56×1.6，不能缩放PCB/封装来适应开孔。
5. 四个主罩隐藏M3×10从底面装入；后盖两颗M3×10从背面装入，轴高Z32。后盖从后方接近，两个螺钉头落在凹入平座。
6. 接口对应关系：背部RJ45窗口是专用EtherCAT布线通路；两个同轴窗口直通外置GMSL接收设备；独立48V插头供电。当前接口板不含EtherCAT主站/ESC、GMSL解码或电源保护控制器。上线前必须完成指定线束、保护和外置控制器契约。
7. 断电检修时先拔全部外部插头，再退出两颗后盖螺钉，后移40后抬起。现有报告只检查13个位置，贴墙安装须另留维护空间；不可据此保证贴墙原位拆盖。

## 4. 桌夹与盒架

1. 只用于已确认的平整桌面15–60厚预算。不得用于玻璃、空心纸蜂窝或强度未确认桌面并据此声称带载安全；首件验证桌面局部压力和防滑后再定使用边界。
2. 先把已预装底座放到后沿，再将两套分压板/保护垫居中放在(X±45,Y50)。从下方用AF6六角扳手交替转动M12螺杆，使两侧接触并均衡收紧。
3. 结构筛查中的每杆1500N预紧仅是计算假设；K=0.2换算约3.6Nm不是可直接发给用户的锁紧扭矩。实际预紧、桌面损伤和防滑须在受约束测试台标定。
4. 两侧盒架通过四个M6×20和垫圈连到腹板侧面(Y−55,Z−80/−67)。它们可独立拆除，不用松开夹桌螺杆。
5. 托盘用四颗M4×10，头沉入Ø8.4×3沉孔且低于盒体底面；这四颗不要加垫圈。前后限位条各两颗M4×20。
6. 盒体预算180×150×50、3kg。用20宽粘扣带穿托盘两侧4×24槽，固定盒体；机箱通风口不应被垫/带盖住。取出盒子先松带、拆朝桌内的前限位条，再向+Y抽出；无须松桌夹。实际盒体通风和接插件仍待最终盒型确认。

## 首件必须记录

- 逐件尺寸/孔距、打印壁厚和螺母袋配合；实际螺钉不得顶底、压PCB或刮线。
- 焊接变形、平面度、螺纹通止及金属毛刺；桌夹压脚卡环正常。
- 外罩/后盖装配、灯窗压紧、RJ45锁扣/电源拔插/同轴扳手操作和线缆弯曲。
- 盒架3kg独立承重、盒子抽取；桌夹防滑/桌面压力的单独约束测试。
- 后续再做限流通电、保护、温升、EtherCAT和双GMSL链路；上述无动力检查不能替代运行放行。
