## 重力复核

[可复现脚本](study.py)保留340 mm上臂、185 mm前臂、J7局部X110工具端面。对4099个配置计算空载及3 kg中心点负载；新电机质量使用目录名义值，电机中心和轴位置暂沿用旧布局，**不是新总装实际质心**。

结构/甲壳/紧固/线束及补偿活动端给出独立、显式的 **1.85 kg预算**。这不是CAD实测质量；也额外计算零结构质量和1.5倍预算的敏感性。1.5倍预算不等于安全系数。

上述补偿是用于判断设计空间的理想恒力模型：J2固定侧下方150 mm的锚点与J2输出侧沿上臂方向100 mm的锚点连接，拟合恒力约285.9 N，同时计算空载和3 kg；并未选定某支气弹簧。理想安装点不受J3 roll影响，但实体固定支架能否绕开实心电机、上臂和桌面，还没有验证。不能画穿过电机的杆件来“实现”它。

令J2角度为θ、a=.10 m、b=.15 m，锚点距离为 `l=sqrt(a²+b²+2ab cosθ)`，电机残余保持矩为 `τ_motor=τ_gravity + F ab sinθ/l`。全J2范围−60°到110°需要约149.13–250 mm的眼距变化，约100.87 mm行程；这个行程是几何需求，**不代表标准气弹簧可以塞入这些眼距**。实际力随行程/温度变化、摩擦、预载、安装偏置、失效状态、空载过补偿、寿命都必须补算。补偿失效时肩部仍然超参考，不能只依赖软件保护。

1.5倍结构预算（2.775 kg）的理想恒力约310.8 N，3 kg样本最大肩需求20.124 Nm，空载19.369 Nm。它说明理想补偿下存在静态设计空间，**不证明封闭甲壳的持续热能力或全空间可用性**。所有样本未进行碰撞筛选、并非可用路径；样本最大值也不是全角域数学上界。

计算以独立批量力矩求和与递归力矩对照，并以重力势能和弹簧势能导数验证符号。最大重力虚功误差约1.59e−9 Nm。详细姿态、账本、结果和限制见 [gravity-study.json](build/gravity-study.json)。没有动态惯量、线束力矩、偏心工具或整机温升的验证结论。

- 当前仅完成原始几何检查，未冻结安装面基准/孔位、公差、有效牙深、端口朝向和输出轴承载荷能力。两个候选的完整STEP未被粗略外包盒吸附进旧总装。
