# SHOULDER01：常规单气弹簧补偿研究

遵循用户“不要引入太复杂机械结构”的要求，主路线仅采用一支成品双眼气弹簧、两个销轴和板式支架。关节仍为灵足原生传动，不增加凸轮、差动、多级齿轮或并联电机。本目录是结构设计输入，尚未是装配发布。

选用[SUSPA Type16-1原厂系列](https://www.suspa.com/global/products/gas-struts/gas-struts-type-16-1/)中的 `01625011 / 16-1-131-110-A17-B17` 作为尺寸候选：眼距264±2 mm、行程100 mm、管径15、杆径6、眼孔6.10、眼片厚3、端部R6.5 mm。原厂目录PDF第10页和来源SHA记录在 [study.json](build/study.json)。尺寸系列确定不等于力值和寿命已验收；还没有购买或联系供应商。

J2相对J1的高度由90增至110 mm；J3横移−10 mm，为真实RS04交叉安装保留间距。上臂340 mm、前臂185 mm、J7局部X110端面及3 kg目标保持。新布局先作为候选，须经过原尺寸电机、底座和所有结构件的实体检查。

固定眼位于J1输出坐标 `[0,-80,-75]`，活动眼位于J2输出坐标 `[65,-80,0]`，两个销轴均平行J2轴。活动锚点固定在J2输出支架，不能接到随J3 roll转动的外罩上。气缸朝上、活塞杆朝下；原厂建议方向和摩擦/温度影响见[SUSPA FAQ](https://www.suspa.com/global/products/gas-struts/faq/)。

J2−60°至110°的解析眼距173.852–250 mm，实际使用行程76.148 mm。考虑长度±2及两端各3 mm行程余量，允许区间169–259 mm，整个J2单轴范围均在区间内。眼距成立不等于支架、电机和桌面碰撞已通过。

为了收紧腕部并减少不同安装接口，本研究把J5/J6均设为RS10P，保持双编码器；其25:1原生减速比必须明确保留，不能标成9:1。J6改用RS10P尚非最终采购决定，代价包括回驱表现改变及增加约80 g。J7仍为RS00。

计算包括显式1.95 kg结构预算、空载及3 kg负载、4099个未筛碰撞的配置。无补偿时J2样本最大约38.934 Nm。以恒定F1为采购变量，计算气体压缩增力比1.0/1.3/1.6、0/50°C、F1±10%、摩擦±30 N的**假设包络**，最小化后的F1约274.8 N，最差样本电机矩约27.204 Nm，接近RS04目录零速28.5 Nm。此处增力比/公差/摩擦都不是这支产品的原厂保证。它只能用于提出采购/台架要求，不能作为封闭甲壳负载放行。

下一步需要实际力—行程曲线来收紧包络，并按完整CAD质心重算。没有独立失电保持或气弹簧失效承载结论。塑料阶段只打印无弹力替身并使用外部支撑，不安装带储能气弹簧或进行3 kg试举。

[study.py](study.py)提供可复现计算；动能、线束、输出轴承、持续热、间隙及工具访问需要在后续实体模块中闭合。底座仍使用同源B06，不能为迎合此候选另改一份底座。
