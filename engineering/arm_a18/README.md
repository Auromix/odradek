# A18：承载可行性与触点接口的独立工程收敛

继续长版、灵足全套关节、B06魔鬼鱼底座和连续甲壳方向。A18先处理承载与可试装接口，不覆写A16发行包或A17外观候选。当前不是生产放行版本。

## 承载计算

`feasibility01.py`复用当前541件CAD／名义五金账本、7个原厂电机目录质量和0.49 kg未完成件余量。原始静态极值与A17逐项一致；法兰参数修订用独立势能微分核对。4099个关节配置未经过碰撞过滤，不能称为完整可达空间或动态承载结论。

腕部比较保留全部原部件质量，不把“缩短”的结构质量自动减掉；亦不删除两只6807支撑轴承，不假定RS00原厂轴承的载荷能力。局部法兰X110→75、J6–J7距离75→65，J5静态筛选从8.979降至7.565 Nm。它只是几何力矩比较：原同轴插头与服务仓需要深度，不能直接把现有STEP压缩或整体缩放。该紧凑布局尚未选定／验证装配。

肩部新增0.15 kg共同运动余量后，比较三种普通气弹簧直连销轴方案。固定销轴世界高度不低于85 mm，连续J2全范围解析验证气弹簧眼距，并考虑目录长度±2 mm及两端4 mm行程余量。计算得到：

| 方案 | 假设包络下J2最大残余力矩 | 与28.5 Nm目录零速参考比较 |
| --- | ---: | --- |
| 单01625011，Ø15／100 mm行程 | 29.552 Nm | 超出 |
| 单01625025，Ø18.5／80 mm行程 | 28.153 Nm | 仅略低，无20%设计余量 |
| 双01625011，同步直连 | 28.777 Nm | 超出且增加部件 |

保持简单机构，后续优先评估单支较大气弹簧，不将双支方案当作自动改善。F1、销轴位置是优化候选，不是采购冻结值。还未检查气弹簧完整外形、端部铰接、支座、侧载及连续碰撞。力递增1–1.6、温度0–50℃、F1±10%、每支摩擦±30 N为本项目的试验预算假设，**不是供应商保证**。改变这些假设需要原厂力曲线或实测证据，不能为通过计算而任意收窄。

原厂依据：[SUSPA16-1](https://www.suspa.com/global/products/gas-struts/gas-struts-type-16-1)、[SUSPA16-2](https://www.suspa.com/global/products/gas-struts/gas-struts-type-16-2/)。16-2目录给出的80–750 N是F1范围，不能当作整个行程恒定力。灵足目录中的带散热板转速额定值、峰值与零速参考不能相互替代：[官方资料库](https://github.com/RobStride/Product_Information/blob/main/README.md)。20%静态余量是工程筛选目标，也不是生产级热／动态／疲劳证明。

## 可制造性工作边界

接口继续采用可替换平面板、标准螺钉与螺母、手动双同轴插接；不增加自动盲插或复杂锁紧。打印件用于外部支撑、断电、无工件的尺寸试装。电路板几何与触点名义包络不等于已完成PCB布线或连接器资格。

生产版仍需要把当前承载不足落实到合适的电机散热／助力条件与工作空间，再完成金属骨架尺寸链、强度与疲劳、实际螺纹深度、动态线束、控制停机及断电保持、实物试装和载荷／温升试验。现有原厂轴承载荷、气弹簧力曲线、桌夹承载等未确认信息会逐项记录，不伪造实测结果。
