# 当前A18器件核对单13：灵足关节与肩部气弹簧

这是待取得证据的核对单，没有向任何厂商发送消息或代表厂商确认能力。对应当前FRONT10／IF09、556项自有CAD及0.49kg未完成件余量；弹簧支座另留0.15kg。表11为历史A17基线，当前采购核对只使用表13。现有3 kg长版模型保留，不能以目录峰值代替温升、轴承或结构验证。

## 肩部助力

`spring-required-force13.csv`将原始“目录F1”问题转化为**实际工作眼距下允许的助力值**。171个J2角度、4099组其他关节参数、0／3 kg两种法兰负载，用22.8 Nm临时电机残余筛选目标反推单支气弹簧的力窗口。

| J2角度 | 工作眼距 | 所需实际推力窗口 |
| --- | ---: | ---: |
| 30° | 217.598 mm | 684–1267 N |
| 60° | 208.075 mm | 808–1173 N |
| 90° | 194.801 mm | 795–1173 N |
| 110° | 185.388 mm | 784–1130 N |

上述推力不是额定F1：F1在近伸出端定义，实际压缩时会增大。现有01625025的目录F1上限750 N不自动否定或满足表中工作力；需要具体伸出／压缩两条曲线及温度、误差范围。禁止把工作力需求填写为已能订购的F1参数。

当前数字候选销轴距a=27.205 mm、b=194.000 mm、固定销X=9.555 mm；这些尺寸还未通过支座与根部运动装配，**不得按此采购或钻孔**。固定销属于J1转子，低位置意味着支架／气弹簧需经过J1电机及静止支撑区；仅眼距在范围内不能说明机构可装入。需要先完成根部实际动态包络和常规支架，再重新反推同一装配版本的力窗口。

给气弹簧供应商核对的内容：

1. 完整实物装配CAD或受控2D，端眼形状、孔／厚度公差、缸体有效长度、杆端接头和实际极限眼距；允许的安装方向、端部转角与侧载限制。
2. 对候选长度／行程，取得0／20／50℃下从伸出到压缩、从压缩到伸出的力-眼距曲线，明确F1测点、递增比、摩擦滞回、批次公差及寿命变化。
3. 将实测上下包络逐行放进所需力窗口，加入安装／轴距误差和真实部件质量；不以一条20℃标称曲线作为全部工况通过。
4. 允许工作速度、循环寿命、断杆／泄压状态和端部销轴载荷。普通助力气弹簧不等于断电防坠制动器。

计算以肩部重力随角度的正弦／余弦关系重建，三组直接重算误差约7.82e-14 Nm，仅验证公式与数值一致。其他关节配置为离散集合，未做完整连续组合、可达过滤、动态加速度或实际温升资格。

## 灵足电机与实装接口

当前J1为RS03，J2／J3／J4为RS04，J5／J6为RS10P，J7为RS00。使用源记录中完整具体版本；不能用RS02图纸替代RS10P或任意缩放电机。

- 对七个实物序列／固件／CAD版本，确认双编码器能力、支持协议、绝对位置／上电零位与输出方向，并核对每个安装基面、定位圈、孔位和允许紧固方式。
- RS04固定M4、输出M5，RS10P固定／输出M4，RS00固定／输出M3的实际可用盲孔深度、底孔、螺钉头空间和厂家紧固要求逐一测量。尤其RS00固定面深度目前未确认，不能依据外形圆柱推断螺纹或把未确认深度定成公差图。
- 确认每型输出端允许径向、轴向与倾覆力矩及组合载荷／寿命；两只6807辅助轴承保留，不能因RS00外形有轴承就删除支撑。
- 取得零速保持／低速周期工况的热模型或测试条件。现有半包围壳体和金属连接板不是目录指定铝制散热板，28.5 Nm等目录参考仍需实装温升与降额验证。
- 供电峰值／再生、过流保护、通信超时、停机方式及断电关节回落需要纳入外置盒与系统测试；先做独立电机台架，不将未验证整臂当作测试治具。
