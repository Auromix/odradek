# A13：整臂制造重构的前置审查

2026-10-09。用户强调：机身需要达到可制造级别，造型优雅，与同源魔鬼鱼底座及四瓣花统一。继续沿用已确认的A连续甲壳语言，长版约700 mm、七轴、J7末端滚转、裸法兰总外负载3 kg为既有目标；四瓣模块不计入本轮本体自重或负载认证。

**本目录当前只有审查和重构约束，尚无A13制造模型。** 最新实际模型仍在A12/wrist02，其24姿态腕罩试配结果不延伸为整机制造资格。制造方式正在向用户确认：推荐验证版即采用铝合金承力骨架、打印外壳；另一个选项是先打印结构无载验证，再加工金属承力件。此次审查不依赖这个选择。
