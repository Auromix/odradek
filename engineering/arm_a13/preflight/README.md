# A12 当前机身：制造重构前的审查

2026-10-09。本报告绑定现有A12/wrist02实际模型、A11承力结构、22个A12外罩及同源B06版本。没有修改模型或更换电机；它解释为什么当前版本不能作为整臂制造发布。来源指纹、完整逐关节结果和假设在[计算JSON](build/current-load-review.json)，汇总在[CSV](build/current-load-comparison.csv)。

## 质量与肩部需求

工况：裸法兰中心3 kg，参考水平伸展；其他命名姿态另见JSON。质量按既有结构/硬件账本、电机目录质量、外罩封闭网格实心体积与PETG密度1.27 g/cm³假设估算。线束继续保留0.24 kg预算。不是实物称重，也没有切片或去重叠后的制造质量。

| 计算对象 | 裸臂估算 kg | J2静态 N·m | 动态筛查附加上界 N·m | 筛查合计 N·m |
|---|---:|---:|---:|---:|
| A11既有版本 | 8.31 | 37.13 | 2.43 | 39.56 |
| A12当前造型与结构 | 9.11 | 38.95 | 2.51 | 41.46 |
| A12诊断：去掉所有外罩 | 7.69 | 35.90 | 2.39 | 38.29 |

七个电机的原账本质量合计约5.45 kg；22个A12外罩估算约1.42 kg。A11外罩约0.62 kg，现有A12外观包覆明显增加估算质量。去罩行只用于分解问题，不是可制造方案，也不是最终轻量化下界。

动态项是按25°/s、30°/s²与保守转子包络惯量得到的筛查上界，不是实测峰值、工作周期RMS或连续额定需求。**不能仅凭41.46大于40就断言瞬时动作失败；静态38.95已超过35工况、且封闭装配缺乏持续保持热证据，是当前不得冻结J2选型的原因。**

厂商README说明，RS04的40 N·m与35 N·m分别对应345×345 mm和220×200 mm铝散热板，引用的是2026-07-13规格；两者都不能直接移用于本机紧凑甲壳内的零速保持。[RobStride官方参数与热条件](https://github.com/RobStride/Product_Information#产品选型--product-selection)。官方仓库另有2026-09-17规格文件，未在本轮解析该PDF；重新采购/冻结型号时须核对最新交付版本、几何及热条件，不能混用版本。

A11参考值重算与旧报告一致。新账本的递归力矩与虚功差分验证最大误差约1.90×10⁻⁸ N·m。256个Halton姿态加命名姿态的静态筛查及负载质心偏置计算留在JSON；这些姿态未经碰撞过滤，不是有效工作空间或全域上界。

## 当前阻碍制造的具体事项

| 项目 | 当前证据 | 对后续设计的要求 |
|---|---|---|
| 整臂承力骨架 | A11有15个打印承力件，原本仅用于受支撑试配 | 重做金属截面、承力转接和定位；不把实心打印件直接改为铝密度 |
| J2选型与热 | 当前静态账本38.95 N·m；持续保持能力未验证 | 下游减重后重新核算；必要时重新选关节、改变包装布局或提出补偿方案 |
| 整体外罩 | 22件中14件仍是Blender造型网格；2件J2罩、6件腕罩有CAD | 所有预定制造件形成可追溯实体与安装、检修和尺寸定义 |
| 外罩固定 | J2/腕罩沿用名义夹罩站位，衬垫与摩擦固定未实测 | 推荐固定到独立结构耳座，明确定位与紧固，避免以抱紧电机壳作为默认结构 |
| 腕部粗大 | RS00是Ø57级电机，但当前J7轴承笼包络Ø84；三轴支架及外罩另占空间 | 同时优化轴承座、支架与电机相对位置；按实际模型核查，不能缩放电机 |
| 内走线 | 固定段D12空间和未连接关节过渡只是意向 | 选定线缆/插头，连接真实固定与活动端点，验证弯曲、扭转和插合空间 |
| 运动资格 | 腕罩24个回归姿态，其余外罩未完成整臂实体检查 | 全制造件、真实元件和底座一起定义可用姿态与动作路径；滑条角度不是合法域 |
| 制造图 | 当前SVG多数为投影/包络查看图 | 补齐加工特征、基准、孔型、螺纹深度、配合、关键公差及装配说明 |
| 臂根与桌夹 | 8×M6/PCD120仍为接口；B06外壳不承担臂载 | 本体导出完整六轴载荷给同源底座；不得把外罩/PCB架认作承力底盘 |

本体数据与底座唯一来源继续分开管理：本次使用的B06-COMPACT-03原生SHA为`86812642f0597b7e024515db6ee6df84cb1a91052140f90cd3f5074446a6ce4c`。不在本体仓库另建底座。

## 复现

在含numpy和trimesh的项目运行环境执行`review_current.py`。程序只读取现有来源并输出本目录报告，不修改CAD。它核对A12原厂版、A11账本及关联指纹；更换模型后需重新审查，不能继承本轮数据。
