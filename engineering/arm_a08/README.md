# A08 裸臂打印与装配验证版

本体目标为裸臂法兰**总外负载3 kg**，不含四瓣头。当前是可拆装的尺寸验证原型，不是3 kg承载发布版。模型包含真实安装孔、紧固件、分件和J7外置双轴承；不能用电机额定转矩或无干涉结果代替结构、热、线束和实物负载验证。

## 文件与复现

下列路径相对于仓库的`engineering/arm_a08/`。下载的独立打印包中，STL位于包内`stl/`；Blender和完整STEP另存于仓库。Blender内部使用米，直接打印请采用已导出的毫米STL。

- `build/odradek-bare-arm-a08.blend`：原生Blender，七轴层级和角度属性驱动。选择`J1.rotor`至`J7.rotor`，修改Custom Properties中的`angle_deg`。J2竖直为0°。
- `build/stl/`：仅打印结构、外壳、量规，单位mm；采购件没有打印STL。
- `build/step/`：原始设计BREP零件及采购件简化包络，均为mm。电机包络不含真实连接器或内部结构。
- `build/parts.csv`与`build/print-manifest.json`：零件、坐标归属、材料、质量假设和装配说明。
- `build/verification.json`：从导出的STEP/STL重新读取的验证报告。仅静态姿态实体相交检查，不是连续扫掠验证。
- `build.py`用CADQuery生成尺寸结构，`blender.py`将同一清单导入Blender；模型不得独立修改后仍声称与计算一致。
- `../arm_a07/loads.py`从同一模型质量台账向J1回算力与力矩。

复现顺序为：`python engineering/arm_a08/build.py` → `python engineering/arm_a08/verify.py` → `python engineering/arm_a07/loads.py` → `blender --background --python engineering/arm_a08/blender.py`。随后重新打开保存的blend运行`audit_blender.py`，最后运行`document.py`生成结果表与打印包。需要CADQuery、NumPy、trimesh与Blender4.5。生成器使用公开厂家尺寸资料建立原创接口，不复制或分发厂家STEP几何。Blender内底座仅为已有B04-P2的只读外观背景，不属于本体打印套件。

## 结构与外观

保留Z/Y/X/Y/Y/Z/X轴序：J5俯仰、J6横摆、J7直接roll。关节采用可拆固定载架与旋转载架；没有假定电机中空。深灰细长双轨骨架承载，灰色折线盾板与圆润多面关节罩可拆，黄铜色腕部法兰呼应底座与灯瓣。关节电机本身占据的体积不会通过渲染缩小。

B4前臂拆成两个交错搭接件，30 mm搭接区用两根M5×60、金属隔套连接，可分别放入256 mm级打印平台。J7为独立可拆腕筒：RS00、两个6807、轴承笼、压盖、内圈隔环及Ø60三孔工具法兰。法兰为本项目接口，不声称兼容某一标准机器人法兰。

相邻模块交界以真实安装面为基准；连杆先沿轴向离开固定载架，再向外转折，避免旋转件穿过固定载架。螺孔在连杆融合后重新加工，保留头部避让；RS04输出九孔使用非等分实际孔位，定位销采用三个局部避让孔。

## 打印顺序

1. 首先打印四种电机孔位量规和三个轴承配合量规，使用实际到货电机、螺钉、轴承核对孔距、突出量和配合。RS00图纸与STEP输出突出量不一致，须测量并调整垫片或参数。
2. 再打印J7轴承笼、压盖、内圈隔环和B7法兰，确认手转无卡滞、端面间隙以及螺钉长度。打印轴颈是配合研究件；加载版本应考虑金属轴颈或嵌件。
3. 打印B6/B5，逐件验证电机安装面和螺钉可达；随后B4两件、B3/B2/B1/B0。
4. 最后打印两块盾板与七组半壳；外观件独立拆装，不用外壳给关节提供主承载能力。

承力打印候选为PA12/PA12-CF，结构质量采用实心PA12密度1.15 g/cm³计算；外壳PETG采用1.27 g/cm³。这些是设计假设，不是材料实测。PLA/PETG结构仅作尺寸验证。先在切片器中确认单位、支撑、平面与孔轴方向，避免让主弯曲路径依赖层间拉伸；当前STL保留装配坐标，切片时需逐件移动至平台并确定朝向。不能由256 mm包络检查直接推断所有朝向都适合打印。

## 从J7向根部装配

1. 在RS00输出端安装B7轴颈/法兰。六根M3×40从前方凹孔装入，孔内用Ø7 mm、厚1 mm垫圈；按实测螺孔深度核对名义3.5 mm啮合，不能顶底。工具三孔M4螺母置入法兰背面六角槽，工具端螺钉长度按实际工具另定。
2. 将RS00固定端接到B6载架。六根低头ISO7380-1 M3×12配0.5 mm垫圈；不能换成同长高头圆柱螺钉，否则可能侵入后轴承区。
3. 装后6807、轴承笼、前6807、内圈隔环与压盖；六根M3×40连接笼/压盖至B6，背面M3螺母加垫圈。外圈和内圈的轴向公差链需实测调垫，禁止用拧紧塑料件的方法强压出轴承预紧。
4. 依次连接J6/RS06、B5、J5/RS06、B4、J4/RS03、B3、J3/RS03、B2、J2/RS04、B1、J1/RS03、B0。每个电机固定侧属于上游刚体，输出侧属于下游刚体；不可把两侧外壳同时固定在一个零件上。
5. B4两件交错合拢，放入两根OD8/ID5.2/长20 mm金属隔套，再装M5×60及上下钢垫圈、M5螺母。隔套长度以打印后内侧面实测为准；载荷版本不能依靠塑料隔套承受拧紧力。
6. B0按B04-P2的PCD120八个M8孔连接，旋转与高度变换见清单。底座具体螺孔深度、桌夹承载仍需由底座分支复核；当前M8×20的名义底座啮合为10.4 mm。
7. 装两块盾板：B3用M3×30，B4用M3×35，配前后垫圈与螺母。每组关节半壳用两根M3×25、垫圈和螺母；根据实际电机外形补配可更换软衬垫。

电机连接螺钉均先核对到货螺纹深度与垫圈厚度。RS04输出端孔距较密，使用M5小外径垫圈（外径9 mm、厚1 mm），避免相邻垫圈相交。拧紧转矩不能照搬钢-钢连接到打印件，须结合材料压溃、蠕变和实测夹紧力确定。

## 走线与选型边界

主连杆双轨内侧约21 mm，B6腕部局部约13 mm，用于预留电源/CAN线束；12 mm线束在腕部余量很小，需用实际线径与固定夹复核；半壳后口开放、盾板可拆。电机均未确认贯通孔，因此线缆从固定侧绕至下一段，不能贯穿假想轴心。当前不装四瓣头，GMSL相机线不采购，仅保留后续通路；实际CAN与电源连接器尺寸、弯曲半径、每轴活动余量和固定夹仍须按实物建立线束模型。打印装配验证阶段不能直接套用查看器角限作为带线束运行角限。

选型为RS00/RS06/RS03/RS04的条件候选，双编码器、低比行星、CAN通信已由资料支持。三个发布阻碍必须闭环：电机在当前封装中的持续保持热能力；J1–J6输出支承允许载荷与寿命；打印承力件及连接的强度、疲劳、蠕变和配合。3 kg仅定义总质量，重心偏离法兰后力矩增大，允许重心包络尚未冻结。
