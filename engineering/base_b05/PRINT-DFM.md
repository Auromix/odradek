# B05 打印与装配检查边界

本文件是给 B05 建模使用的分件建议及网格检查说明。实际零件名称、尺寸和紧固件以 B05 最终模型及 BOM 为准；它不声明 B05 已通过实物装配或承载试验。

## B04 暴露出的具体问题

当前 B04 manifest 中前罩约 270.15×210.66×51 mm、后罩约 259.99×94.61×51 mm。它们不是一般 220 mm 方形打印床上可以直接平放打印的零件。STL 封闭并不等于打印机能够容纳，也不证明打印孔位和接头可以实配。

B04 接口面向下。最新参考要求后部内凹接口面板，外面另有后盖，接线后通过下方出口向桌下引线。这需要一起重排接口插头、锁扣/扳手操作、线缆转弯和后盖空间，不能只改变外壳外形。

## 给外观与结构建模的分件建议

- 环台独立。中央环台围绕金属承力接口，外观件与承力法兰留装配间隙，不用外罩传递机械臂载荷。
- 宽肩按左/右、前/后分区。B04 全壳跨越约 270 mm 宽、310 mm 深；仅左右分半仍可能超出打印床。以四个肩甲分区为起点，每件在选定打印姿态下控制到约 210×210×250 mm 内，再把分缝沿装甲转折安排。前方灯模块可作为单独短饰件连接左右前肩，避免将灯窗切成两半。
- 外罩从上方分件拆装，使用短直定位止口，不做互相锁死的长燕尾。初轮止口每个配合面预留约 0.3 mm 作为试片起点；这不是经过设备验证的打印公差。公母试片验证后再冻结。
- 采用可见或可到达的螺钉、独立垫圈/垫肩及可更换嵌件。螺钉拉紧在局部实心支柱，不挤压薄肩面。嵌件安装方向、烙铁空间、螺钉长度和底部余量必须在三维中看得到。
- 光学件单独打印/制作。灯板、灯罩、遮光隔板和接插件能随前灯模块取出；在拔插灯线前，前罩应有可托住的开盖位置。透光件与外罩可用不同材料，但不因使用透明料而声称亮度或均匀性达标。
- 后部采用“内部承托架＋可更换接口面板＋后盖”。板和面板从支架上独立更换；面板约束插接方向，插拔力由支架承担。PCB 焊脚不作为承力定位，外观肩甲不承担电缆拉力。
- 后盖向后或向上直接取下。出线口应是开边槽加分体护线块，使接头不必穿过狭小孔洞才能拆盖。接线后外盖能闭合，且不会压住 RJ45 锁扣、同轴螺母、动力插头锁扣或线缆应力释放段。

后部面板必须依据实际选定连接器建立至少五个包络：板上本体、外露口、已插接插头、解锁工具/手指、线缆允许弯曲区。不同接口不能共用一个“圆孔占位”；同轴接口额外保留装配扳手空间。线缆最小弯曲半径按具体线缆数据和实配确定，不用通用弧线替代。

## 首件文件如何交付

Blender 文件用于外观编辑、装配观察和渲染。切片输入使用**逐个零件的 STL 或 3MF**，单位为 mm；不要用总装 GLB，也不要让购买件、螺钉、PCB 或线缆检具混入打印件文件夹。

建议目录分开：

```text
build/print-parts/       # 外罩、灯罩、面板、后盖等真正试打印件
build/assembly-mockups/  # 如需打印的金属结构占位检具，醒目标注“无动力装配”
build/reports/           # 绑定本次输出散列的检查结果
```

每个零件同时给出装配姿态和打印姿态，明确打印材料、层高、壁数、支撑面、孔后加工、嵌件安装及采购紧固件。打印姿态下的放置只是第一步，仍需在实际切片器中逐层查看薄壁、悬空、支撑接触面和孔是否闭合。未知打印机时，220×220×250 mm 仅作为本项目暂用兼容检查床，不代表用户设备。

承力金属底板、桌夹、法兰和托架可以打印占位件检查拆装顺序，但应放在 `assembly-mockups/`。这些占位件不得用于给机械臂施加载荷、夹紧力或证明 2 kg 工件能力。

## 使用网格检查器

依赖 Python 3、`numpy`、`trimesh`。在仓库根目录运行：

```sh
python engineering/base_b05/print_checks.py \
  engineering/base_b05/build/print-parts \
  --bed 220 220 250 --margin 5 \
  --output engineering/base_b05/build/reports/print-checks.json

python engineering/base_b05/print_checks.py --self-test
```

默认给打印床 X/Y 每边留 5 mm，因此当前打印姿态可用范围为 210×210×250 mm。包络检查允许把整体平移到打印床，但不会静默旋转零件。STL 本身没有单位，默认明确按 mm 解读；米制 STL 必须传 `--stl-unit m`。

`--allow-orthogonal-rotation` 仅用于筛查“换一个坐标轴朝上是否装得下”。默认不开启，避免把侧立才能放下的罩壳标成已完成打印准备。即使开启，报告仍保留导出姿态是否适配，且不把所有可容纳的姿态当作合理打印姿态。

检查器会记录输入及脚本 SHA-256、库版本、封闭性、面绕向、按共享边连接的壳数量、退化/重复三角面、带符号体积、尺寸和包络；仅合并重合顶点来读取 STL 拓扑，不自动补孔或修复错误。默认要求每个打印对象只有一个封闭连通壳。双壁完全密闭的中空模型可能因具有独立内外壳而被拒绝，需要人工确认并更改模型/验收要求，不能删除内壁使检查通过。

Core 3MF 保留内嵌单位、组件实例和变换；必需扩展、跨文件组件等本检查器不支持的内容会报错。多对象 3MF 按每个实例检查，并另外报告整组包络；**不检查不同对象之间是否重叠**，必须重新切片排板。多个 STL 也按单件检查，不意味着可以同一盘全部打印。

返回值 0 只表示所检查的网格及单件打印包络通过。非零表示至少一项不通过或文件不可读。网格自交、最小壁厚、支撑、层间强度、装配干涉、电气性能和承载均不在该脚本的通过结论内。

## 首件装配核对

1. 空底座先装金属骨架与后部支架；检查各螺钉和工具路径，再装 PCB。
2. 装好真实接口及线缆，确认面板位置与接头吻合、接线方向正确，能够解锁拔出。
3. 预装后盖，验证四路外线可自然向下离开，盖体不把压力施加在接头与线缆转弯处。
4. 分别装中央环台、肩甲和前灯模块；验证不用弯曲罩壳强行对孔，所有螺钉都能放入和取出。
5. 做完整无动力拆装一次，记录打印收缩、孔补偿、止口间隙和嵌件异常后修正文件。

仅在这些实配问题关闭后，才把外罩与接口模块标为“首件装配通过”；这与桌夹、承力结构、PCB 供电和通信的独立试验是不同结论。
