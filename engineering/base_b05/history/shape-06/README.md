# B05 底座：SHAPE-06 外观与紧固试装候选

本轮以 [B 收腰盾形参考](../../docs/concepts/selected/base-shield-current-reference.png)和魔鬼鱼轮廓为方向。上冠采用连续的径向坡度，取消翼肩局部鼓包；两翼外展后收回前鼻，以统一的裙边转折线保留硬朗机甲感。后方横缝移到翼根之后，前鼻、环台、琥珀灯窗和深色紧固件组成清楚的视觉层次。此三维候选仍需用户审阅，并不表示造型已经定稿。

## 螺钉与造型协同

外罩采用15个M3浅螺钉座，内侧四组支架的接触面跟随对应外罩的实际内表面。浅座深0.5 mm，避免在约3 mm薄壳上开深沉孔；圆头螺钉有意露出，形成一致的小尺度机甲细节。主肩甲各三点固定，前鼻三点固定，左右后肩甲各两点固定，后盖独立两点固定。

中央装甲环由四根独立立柱承托，立柱穿过外罩的隐藏Ø9.4 mm孔，柱径Ø9 mm。环台的夹紧力不通过薄外罩传递。四颗环台螺钉独立拆装，装甲环仍不是承载机械臂的关节法兰。

四组支架通过8颗下方螺钉固定到左右定位底环，配Ø2.8 / Ø3.1 mm定位销孔。标准件统一为 **27颗 ISO7380-1 M3×10 圆头内六角螺钉 + 27颗 DIN934 M3 螺母**。螺母槽名义对边5.8 mm、高2.8 mm，向+Y开口插入。标准件模型省略螺纹，不能打印代替真实标准件。

标准件尺寸依据[Accu 圆头螺钉数据](https://www.accu.co.uk/socket-button-screws/8288-SSB-M3-35-A4)和[DIN934 M3螺母数据](https://www.accu.co.uk/api/product-datasheet?id=268686)。真实采购须核对型号、材料和尺寸。

## 无动力试装顺序

1. 分别切片14个自制件；先用小样验证Ø3.4孔、螺母槽和定位销孔的打印补偿。
2. 从侧面装入四组支架的螺母，核对防转与回位；螺母不应靠外罩压住才能留在槽内。
3. 对准定位销，把支架装在两半定位底环上，从下方拧入8颗M3×10。底环两半尚未和未来承载骨架建立正式固定接口，试装时需要夹具保持相对位置。
4. 安装左右肩甲、前鼻和后肩甲，再安装独立后盖；检查紧固时外罩不变形。后盖两颗螺钉独立拆卸，提起后向后抽出的路径尚待完整碰撞与实物检查。
5. 安装中心装甲环，检查隐藏孔与四根立柱不干涉。

以上是数字模型的试装顺序，工具入口、侧插螺母行程、销孔补偿、支架接触面和后盖拆出路径仍需实物确认。底环和外罩支架均不承担机械臂负载。

## 打印与集成边界

STL明确使用mm，`print-parts/` 已平移到正坐标；`stl/`保留总装坐标。检查使用220×220×250 mm床和5 mm XY余量；最大平面件约199×74 mm前鼻、170×170 mm环台。摆放方向、支撑、收缩补偿、最小壁厚与自交仍需进一步检查，网格闭合不等于能装配或能承载。

模型保留后盖下方出线口、灯窗和116×56 mm PCB的候选空间。RJ45、两路GMSL同轴、独立48V电源的真实组件、可替换接口板固定、线缆弯曲半径和应力释放尚未集成；灯板和透光件的固定亦未完成。原生[嘉立创接口PCB](../electronics/base-io-b05/README.md)本轮未修改，不作为已完成布线或可下单制造的证据。

构造入口为`blender_exterior.py`和`exterior_fasteners.py`。原生构造按1微米网格清理，处理重合相反面、孤立单三角薄片及最短高不足1微米的四面体布尔碎片；其他多面组件仍由独立检查拒绝，检查器不修补模型。`assembly_checks.py`只检查名义间隙和螺母高度的螺杆覆盖，明确不检查完整碰撞、实物装配、预紧力或负载。
