# B05 内部布局独立检查

结论：水平 I/O 板可以作为布局候选继续建模；内部 RJ45 J2 需要移到中线、接地端子 J6 需要避让。服务板采用 90° 旋转后，还需把原提案沿 +X 再移 2 mm，并删除旧外罩柱 `(-98,95)`。这些修正后的名义几何没有发现与本次保留金属框架的正体积交集，但外罩、实际线缆和新 PCB 原生再导出尚未关闭。

结果保存在 [layout-audit.json](layout-audit.json)，包括 STEP/接口源文件 SHA-256、近距零件对、交集体积、变换及抽样拔插结果。没有修改 B04 金属几何或 B05 主模型。

## 本次采用的几何

金属件直接读取 B04 导出的独立 STEP，覆盖底板、两侧 C 夹板、夹紧横梁、法兰、四个承力柱、压板、盒架与托板。PCB 直接读取原生机械包的 STEP；其中板体和钻孔为原生几何，连接器部分包含有明确说明的厂家尺寸抽象和插头规划包络，并非全部是真实接插件 BREP。

I/O 主变换为：

```text
从板局部 (u,v,w)：X=58-u，Y=76-v，Z=20+w
从 B04 世界坐标：X=-Xold，Y=85+Zold，Z=47+Yold
```

在该变换上，对 J2 全部子实体再移 `X−38 mm`，使内部 RJ45 中心从 X38 到 X0；对 J6 全部子实体移 `X+4、Y−8 mm`，对应局部端子中心从 `(u46,v12)` 到 `(u42,v20)`。这是候选布局验证，**原 PCB 钻孔和铜线仍需在嘉立创 EDA 中同步修改后重新导出**。检查时没有把移动后的引脚与尚未修改的旧板孔相交作为已关闭项目。

服务板先检查提案 `X=-60-v，Y=87+u，Z=23+w`；发现零间隙后，进一步检查修正候选：

```text
X=-58-v，Y=87+u，Z=23+w
四个板孔：(−63,92,23)、(−103,92,23)、(−103,162,23)、(−63,162,23)
```

两种变换都保留在 JSON 中。顶层 `service_transform_local` 是发现零间隙的原提案；`recommended_service_candidate` 才是修正后的候选，避免把原提案误读为已通过。

## 找到的问题与修正结果

| 项目 | 具体发现 | 修正候选的结果 |
|---|---|---|
| 内部 RJ45 原位 | 旧插头规划 X26..50、Y76..116 与右前承力柱相交约 6469.88 mm³ | J2 移到 X0 后，规划插头走两根柱之间；本次未发现与金属正体积交集 |
| J2 与接地端子 | 仅移动 J2 会接近旧 J6 的线鼻子区域 | J6 同步移至 `(16,56)` 后，J2 外壳与 J6 线鼻子规划的最小净距为 3.5 mm |
| 服务板左侧 | 原提案裸板左缘 X−110，恰好接触 C 夹板内面；0 mm 净距不能作为可装配间隙 | 改为 `X=-58-v`，裸板 X−108..−58，与左 C 夹板及左前承力柱均留 2.0 mm 名义净距 |
| 旧外罩柱 | 原 `(-98,95)` 柱进入新服务板，单 PCB 交集约 27.12 mm³，另有小量引脚包络交集 | 必须删除或迁移该罩柱；不能随 B04 框架一并沿用 |
| 服务板支撑 | 不能沿用旧 PCB 的四柱位置 | 新增四根高 9 mm 支柱，从底板 Z14 到板底 Z23；修正后中心 X−63/−103、Y92/162 |

新服务板左两柱距底板直边 7 mm。若沿用 Ø6.4 的柱外包络，距边余 3.8 mm；Ø2.5 攻丝预孔到该直边剩 5.75 mm。孔深、螺钉有效啮合、底板已有孔之间的距离，以及新孔的制造图，仍需在主结构中正式建立；这里没有把支柱图形摆上去等同于完成紧固设计。

## 名义净距与外罩必须保留的空间

| 项目 | STEP / 包络计算结果 |
|---|---|
| I/O 固定总包络 | X−58..58，Y12.5..76，Z16.6..40 mm |
| I/O 最低引脚至金属底板 | 2.6 mm；这是几何净距，不是电气绝缘认证 |
| I/O 板边至前部两根承力柱 | 最小 3.0 mm |
| 内部 RJ45 插头/释放规划至法兰下表面 | 最小 2.1 mm：规划最高 Z43.9，法兰底 Z46 |
| 修正后服务板及已插接包络 | X−108..−58，Y77.5..174.3，Z20.5..35.7 mm |
| 修正后服务板包络至 I/O 固定件 | 最小约 9.98 mm |
| 修正后服务板包络至保留金属 | 最小 2.0 mm |

外罩不能用 PCB 裸板的矩形决定内腔。特别需要罩住左肩 J1/J2 已插接高度 Z35.7，以及后部 I/O 支架最高 Z40。内部 RJ45 的规划高度已很接近法兰底，不能在此处再增加盖板、隔板或走线压条而不复核。

若先分配 2 mm 名义内腔余量，左肩接头上方内壁至少应高于 Z37.7，I/O 高件上方至少应高于 Z42；这是建模分配，不是现有 B05 壳体已经达到的尺寸。侧壁同样应在上述真实包络外留空间。外壳壁厚、打印收缩及紧固件凸起另计；不能拿外表面高度代替内表面净高。

PCB 下方引脚与金属底板间隙、端子裸露金属及保护接地，仍需要电子设计分别确认。既有 2.6 mm 几何距离不能代替绝缘、耐压或污染等级判断。

## 支撑和拆装核对范围

为服务板建立了四根独立 Ø6.4×9 mm 柱包络，以及 M3 头 Ø5.5×3 mm、垫圈 Ø7×0.5 mm 的名义包络；I/O 按四个安装孔建立 Ø6.4×6 mm 柱和相同 M3 头/垫圈。本次未发现这些新支撑/螺钉头与相应组件或金属的正体积交集。支柱与 PCB 底面/底板顶面的预期接触不作为冲突。

服务板 J1/J2 插头按 −Y 抽出，在 0、5、10、15、20、30 mm 位置检查；J3 按 +Y 抽出，在 0、5、10、15、20 mm 检查。修正候选下，各抽样位置没有与所保留金属、I/O 固定件及规划插头相交。该检查使用插头延伸区的规划包络，**没有验证完整手指、锁扣动作、线缆弯曲和连续拔插过程**，且默认先拆外罩。

内部 RJ45 的规划包络为 X±12、Y76..116、Z19..43.9；另以 X±15 表示释放区域。它是保守布置盒，实际插头长度、与插座的插入深度、尾套与弯曲段必须用真实样件或可靠厂家 CAD 再核对。不能据此承诺背部后盖一定能盖上。

## 后续交接

1. 主结构采用修正后的服务板位置和四个新柱位置，删除或迁移 `(-98,95)` 的旧外罩柱；不要保留旧 PCB 支柱造成多余实体。
2. 嘉立创 EDA 原生工程同步 J2/J6 布局、钻孔、封装与线路，然后重新导出组件几何复查。
3. Blender 新外罩形成实体后，用其内壁和真实面板/后盖检查上述高件、接头释放区及全路径拆装；本审查没有替代该步骤。
4. 实配确认插头、线缆和嵌件后，再冻结打印件。金属框架在本次仅作为几何基准，承载、刚度和加工放行仍是独立事项。
