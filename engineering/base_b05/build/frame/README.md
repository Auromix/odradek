# B05 内部结构参考包

本包为 Blender 外罩建模及后续装配核验提供内部占位。真实 STEP 实体与逐件 STL 均以 mm 为单位；**金属框架和 PCB 的状态仍是参考/候选，不能以本包直接制造承载样机或投板**。

- `B05-FRAME-REFERENCE.step`：内部框架与电子模块参考总装，不含桌板、墙面、外置盒空间检具及内六角工具。
- `manifest.json`：所有逐件名称、分类、材料、颜色、变换来源、特征、状态及文件路径。Blender 应按这份清单导入 `parts/`，不要用目录通配把别的历史文件混进去。
- `parts/`：逐实体 STEP/STL，包含环境和采购件占位。多数 STL 是显示/装配参考，**不是打印件**。
- `print-parts/`：只有四个继承的非承力压脚保持罩试打印件，已平移到 Z0，单位 mm。切片支撑和嵌件/实配另行检查。
- `geometry-checks.json`：单实体有效性、封闭 STL、逐件 STEP 回读及体积误差。
- `interface-collisions.json`：新电子模块及新螺钉头/垫圈对金属的名义交集；不检查外罩与柔性线缆，不包含螺纹啮合或元件自相交。
- `print-checks.json`：四个非承力保持罩的网格/打印床检查；其通过结论不适用于金属框架。

## 稳定引用名称

| 模块 | ID / manifest 字段 | 状态 |
|---|---|---|
| 原承力骨架、夹紧和桌下盒架 | 大部分保留 `B04-*` / `HW-*`，`module=inherited_*` | 继承结构参考，未重新承载放行 |
| 增加新安装底孔的底板 | `B05-101-DECK` | 新增 8 个 M3 预孔的金属参考；历史孔仍保留 |
| 服务板 | `B05-SERVICE-*`；PCB 为 `B05-SERVICE-PCB` | B04 原生机械包刚体旋转移位，含规划插头包络 |
| 服务板新柱/螺钉 | `B05-SERVICE-POST-1..4`、`B05-SERVICE-M3-1..4` | 采购 M3 支柱/螺钉候选，不是打印承力结构 |
| I/O 候选模块 | `B05-IO-CANDIDATE-*`；板体为 `B05-IO-CANDIDATE-BRI01_PCB` | J2/J6 已做候选位置变换，旧钻孔和铜线未同步更新 |
| I/O 新柱/螺钉 | `B05-IO-POST-1..4`、`B05-IO-M3-1..4` | 采购件候选 |

`source_reference.name` 保留原组件名称，供后续通过已确认的嘉立创 EDA 新机械导出逐项或整模块替换。每一行都包含 `prototype_status`，不要在界面中把 `candidate_reference_not_updated_native_board` 隐去后显示为最终 PCB。

## 本包具体改变

删除旧前/后罩、旧服务板及其柱、全部旧罩柱、旧竖向 I/O 载板及护罩和这些模块的固定螺钉。旧罩柱 `(-98,95)` 不再穿过新服务板。未知的 B05 外罩安装位置未添加占位螺柱。

服务板刚体变换 `X=-58-v，Y=87+u，Z=23+w`，四孔来自原生机械合同，位于 X−63/−103、Y92/162。新 M3 支柱主体高 9 mm，Z14..23，底部公牙长 6 mm；板厚 1.6、垫圈 0.5、上螺钉 M3×8，有效进入柱内 5.9 mm，柱内牙分配深 6 mm。

I/O 使用 `X=58-u，Y=76-v，Z=20+w`；J2 另移 X−38 到中线，J6 另移 X+4、Y−8。四个 PCB 支撑孔依据接口合同的 `PCB chassis standoff` 角色读取，为 `(±52,26)`、`(±52,70)`，均有现有 deck 实体支撑，未落入后侧 U 缺口。故本轮不额外添加跨缺口桥架。新柱主体高 6 mm，Z14..20，公牙长 6 mm；板上 M3×6 有效进入柱内 3.9 mm，内牙分配深 4 mm。

所有新柱均由顶面 Z14 向下增加 Ø2.5、深 8 mm 的攻丝预孔，特征注明 M3×0.5、完整牙深 6 mm。STEP 使用预孔/柱包络表示螺纹，正常螺纹啮合区不应拿实体相交作干涉失败。采购件实际牙深、螺钉长度和装配公差仍需核实。

## 仍缺的接口

1. 嘉立创 EDA 中的新 I/O 板钻孔、封装和走线必须完成、校验并重新导出。本包旧板孔与移动后的 J2/J6 引脚不匹配，已明确作为候选参考；不能从这里导出制板文件。
2. 同轴支架孔是另外两孔 `(±10,38)`，不混同为四个 PCB 支撑孔。支架通过面板/独立金属支撑承受插拔与拧紧反力的接口还需设计，当前不能宣称 FR4 已完全避开机械反力。
3. 后部可换面板、后盖、四路线缆、应力释放、完整插拔/扳手通道需与新 Blender 外罩联合检查。
4. 新外罩安装点及前灯模块不在本参考包中，由外观/结构主模型完成；未知位置没有先行猜测。
5. 金属件公差、材料与加工图、夹紧力、桌面压痕、承载及电气安全仍未放行。塑料打印不能替代其中任何承载验证。

## 重建

在仓库根目录、已安装 CadQuery 与 trimesh 的 Python 环境中运行：

```sh
python engineering/base_b05/frame.py
python engineering/base_b05/print_checks.py \
  engineering/base_b05/build/frame/print-parts \
  --output engineering/base_b05/build/frame/print-checks.json
```

生成器通过 `base_b04/model.py` 的 `make(covers=False)` 读取继承框架，再明确过滤已失效的模块。它不修改 B04 源文件。
