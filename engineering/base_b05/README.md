## 简化与装配

自制件由14降至8，标准件由27螺钉/27螺母降至18螺钉/18螺母。外罩固定6颗（每侧3颗）、前鼻4颗、后盖2颗、装甲环4颗、骨架搭接2颗，统一ISO7380-1 M3×10和DIN934 M3螺母。原支架与底环之间的8颗螺钉已取消。

翼肩与前鼻保持0.8 mm名义接缝；各外罩采用0.5 mm浅圆头螺钉座，孔Ø3.4 mm、头座Ø6.6 mm。圆头螺钉有意露出形成装甲细节，螺母槽对边5.8 mm、高2.8 mm，向+Y插入。真实标准件尺寸仍需采购核对，简化螺纹参考不得打印代替标准件。

两半骨架在Y=-8和159 mm处以两处搭接连接。左件带一体定位舌，右件带接收槽；水平与高度名义间隙各0.3 mm，两颗螺钉从上方夹紧到左件内的螺母。搭接定位代替了上一版需要夹具保持底环两半相对位置的做法，实际刚度和装配补偿仍待验证。

1. 先打印孔槽与搭接小样，确定打印补偿；再分别切片8件。
2. 从侧面插入两半骨架的螺母，将定位舌放入接收槽，拧入两颗骨架连接螺钉。
3. 对准骨架上的随形支柱，装左右翼肩与前鼻；检查外罩没有被螺钉强行拉弯。
4. 安装独立后盖，检查插线、拆盖和工具入口。
5. 装中央环台。四根独立支柱穿过薄壳隐藏孔，环台夹紧力不通过薄外罩传递。

这是数字试装候选的装配顺序，尚未经实物执行。透光件固定、灯板安装和完整线缆仍需下一模块设计。

## 打印与集成边界

STL单位为mm；`print-parts/`已平移到正坐标，`stl/`保留总装坐标。8件均闭合、单连通体、正体积、无重复/退化面并满足床包络。最长骨架208 mm，占210 mm可用床长的大部分；切片时须核对支撑、裙边/边沿占用和实际打印机可用面积。

网格检查不检查最小壁厚、自交、支撑、层间强度、收缩或配合公差。骨架虽合为两件，其支柱上的螺母插槽仍可能需要支撑，不能据此声称免支撑打印。建议PETG/ASA无动力试装，灯窗使用透光材料。

本轮骨架仅固定外罩，尚未连接正式承载骨架、桌夹与机械臂法兰；不可装机械臂做带负载动作。旧B04/B05骨架和法兰不能直接套用本轮包络。后部116×56 mm PCB空间、下出线口与灯窗仍为候选空间，RJ45、两路GMSL同轴、独立48V真实接口组件、PCB固定、线缆弯曲半径与应力释放尚未完成集成；[嘉立创接口PCB](../electronics/base-io-b05/README.md)本轮未修改。

原生构造按1微米网格清理，处理重合相反面、无实体体积的单三角薄片及最短高不足1微米的四面体布尔碎片；独立检查器不修补模型。`assembly_checks.py`只检查名义间隙和螺杆覆盖整个螺母高度，不证明预紧力、实物装配或载荷资格。
