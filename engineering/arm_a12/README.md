# A12：连续甲壳的逐模块深化

用户已确认[风格A](../../docs/concepts/selected/arm-body-a12-manta-carapace/README.md)，保留七轴长版、全尺寸原厂执行器和已有机械接口。外罩与金属/结构承力件分离；背脊走线、活动线弯、检修开盖及散热从本轮起与造型共同设计。

当前可查看[腕部第二模块](wrist02/README.md)及[七轴交互预览](../../docs/viewers/arm-body-a12-wrist02/index.html)：J5–J7的三个固定侧造型罩已替换为六件分体 CAD 外罩，14个其余整臂设计曲面保持独立。内部承力结构仍采用A11基线，外罩及整臂尚未进入制造发布。上一轮[整臂造型初稿](whole_style01/README.md)和[第一模块J2肩罩初稿](shoulder01/README.md)的检查单独保留，不能推断整臂已通过适配。

先收敛整臂外观，优先解决腕部圆筒叠置与端座过渡，再逐模块深化肩桥、上臂、肘、前臂，最后验证完整线束、装配与打印试配。每个模块保留独立源文件和报告；由用户查看真实Blender结果后收敛，再推进下一段。未选中的B/C继续留在概念探索目录。

B06底座是相邻权威项目中的同源上下文，仅作只读引用；本体项目不另建可编辑底座。A11基线不被A12覆盖；任何新增外罩都重新做自身数字检查，不能继承旧版制造或承载结论。3kg仍是裸法兰目标，封闭电机后的散热和实际持续扭矩必须重新验证。
