# A12 / A：腕部外罩无动力试配资料

本包只有 J5、J6、J7 的六件非承力分体外罩，版本 A12-A-WRIST02。对应 RS06 / RS00 / RS00 的实际尺寸模型；不是整臂制造包或带电动作发布。

- `build/fit-print/`：分缝面朝下的毫米 STL，单件包络均小于180 mm。摆放仅为候选，打印前在切片软件核对单位、支撑及薄壁，未验证任何机型或材料批次。
- `build/step/`：六件原 CAD 坐标实体。
- `build/drawings/`：STEP 三向投影查看图，安装站位和分缝定义；不是完整公差制造图。
- `build/fit-print-manifest.json`：来源 SHA、摆放变换、尺寸与实心体积估算。
- `build/fit-audit.json`：24个设计/回归姿态下，六件新腕罩对既有电机、结构、名义硬件与J2罩，未发现超过0.05 mm³阈值的相交体积。连续路径、其他造型罩、底座及线束不在范围。
- `build/base-context.json`：同源底座版本记录，本包不含底座零件。

J5 / J6 沿 X=±0.20 分两半；J7沿 Y=±0.20 分两半。固定在各自 `J5.fixed`、`J6.fixed`、`J7.fixed` 坐标系，不跨接不同关节刚体。名义皮厚2.6 mm、分缝0.4 mm、螺钉通孔Ø3.5。复用既有六颗 M3×20、六个M3六角螺母与十二片名义0.5 mm垫圈；未添加供应商电机安装孔。

建议按 J5 → J6 → J7 单模块受支撑、无动力地试配。先放入两半并核对电机、支架、螺钉和工具空间，再确定衬垫尺寸及夹紧方式，检查罩固定侧与输出转动侧的关系。电机避让体名义径向间隙1.2 mm，不代表整体均有相同间隙；软衬垫和保持力尚未实测。未经夹紧保持、温升、线束和实物装配验证，不做带电运行或负载测试。

三处开口只是检修/布线出口。真实线缆、插头、应力消除、弯曲半径、扭转寿命及连续动作尚未验证；不假设电机有通孔。六件按PETG密度1.27 g/cm³估算实心质量约234 g，不含其他外罩和紧固件，实际打印质量另测。

整臂模型、供应商来源和模块报告见 Auromix/odradek 仓库 `design/arm-body` 分支的 `engineering/arm_a12/wrist02/`。裸法兰3 kg仍是目标，此包不证明承载资格。
