# A11 长版：已确认的翼脊外观与可拆护罩

用户确认的方向是底座微调、臂身重构、四瓣保留。这里保留长版七轴构型和真实电机接口，以A10承力骨架为输入，新增/重做可拆外观件；不是另一个AI概念图。

- 连杆：20×40×2金属直管保持不变；上臂护罩具有连续收腰和纵向折脊，前臂端部较收敛，避免切断外壳。
- 关节：原尺寸RobStride RS03/RS04/RS06/RS00；十面护罩、端部倒角、开放散热窗，原固定/输出螺钉位置保留。
- 肩部：原桥架增两处D3.5穿孔，用两组M3×30穿栓固定独立护板；不把护板作为承力结构。
- 臂根：安装盘外径140mm，8×M6/PCD120孔位保留；16面弧形收腰护罩从臂根Z43mm起，避免侵入底座环台。
- 底座：读取同源仓库`../odradek/engineering/base_b05`的SHAPE08；原魔鬼鱼外轮廓、8件分件保持，环台内径132mm、外径170mm，裙体折线更明确。底座外观骨架不承担臂载。
- 四瓣：原R5-PETAL-FORM02轮廓不改。整机风格渲染中的四瓣与中央脸部仅作比例/材质参考，默认隐藏，未并入本体装配、质量或负载认证。

本机原厂电机实体模型放在`work/arm-a11/odradek-a11-long-actual-motors.blend`，不随项目许可证重发布供应商CAD。公开`.blend`含自主电机包络，保留七轴可编辑控制；原厂导入脚本和源指纹可复现。

依次运行`style.py`、`manufacture.py`、`review.py`、`collision.py supplier`与`blender.py`。CADQuery环境用于结构、STEP/STL生成，Blender4.5用于实际几何装配和呈现。`style.py`最后调用`shoulder.py`。供应商源STEP及本地14组网格依照A10固定源版本准备。
