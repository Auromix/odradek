# A17 魔鬼鱼甲壳：整臂外观重新收敛

用户指出A16臂身与B06底座不像同一物种。本轮继续已选的连续甲壳方向，重建实际CAD外壳，不改变供应商电机尺寸，不增加传动机构，不修改底座源模型，也不把相机／花瓣头纳入裸臂载荷计算。

形态修订采用真实圆弧截面：保留宽面、内收侧缘和浅背脊，将原来的硬多边形转折圆顺化。上臂使用连续纵向曲面，肩、肘和腕部保留受限的轴向分段，避免未经验证的曲面鼓包侵入折叠空间。结构件与紧固件采用较安静的深灰材质，外壳用与底座协调的石墨蓝灰。材质调整不是电机隐藏或结构装配证据。

机械安装仍使用A16 C03–C06的普通螺钉、平垫、热熔螺母与鞍座。新增曲面必须保留安装轴、接触台阶与检修孔；J7和连杆的直柱安装特征从现有安装表直接重建，避免布尔差值产生薄碎面。装配尺寸与固定点仍需真实样件确认。

## 源与验证边界

- `style01.py`生成18件新CAD壳体；`build/rounded-raw`为内部形态构建阶段，不能与最终零件混装。
- `blender01.py`将新壳装到当前原厂模型和B06原生场景中，检查221个底座网格的世界几何指纹保持不变；14个电机外形分件保留原尺寸。
- `review01.py`在相同26个关节样本上重算所有涉及新零件的精确CAD交集；只对源SHA不变的旧零件之间继承A16检查。不等于连续扫掠或完整关节范围验证。
- 当前 `build/style01/review.json`：18件新罩＋523件未变自有零件＋14件真实电机外形分件＋B06承载法兰，共556个几何项；26个指定姿态零干涉，桌面平面检查通过。不同关节的任意组合、连续扫掠、完整底座外壳、实际工具与动态线束不在此结论内。
- A16已发行的 `manufacturing/selected/arm-body-a16-fit` 不被这轮外观候选覆写。新件在候选独立目录中存放；不能将两个版本的同一壳体同时装上。

外壳名义截面壁厚2.6 mm，不是全局最小壁厚证明。塑料打印仅用于有外部支撑、断电、无载荷的试配，金属骨架不是简单把塑料密度换成金属密度。

## 生产放行仍未达成

第一轮高阶放样发现上臂与20×40骨架管相交（约2173 mm³）。改用同一闭合半环截面、三次曲线和弦长参数后消除这处交集，根部上沿也收窄，关节后盖改为轻量的空心浅弧面。随后26样本发现10对剩余干涉，历史210条记录见review-before-clearance。扩大200 mm鞍座内侧空间、采用D12直柱及沉入式螺钉座、恢复J7紧凑平后盖后，原有干涉消除，但曲面连带变化又造成4件罩与J4固定板相交；历史104条记录见review-before-socket-clearance。

最终按同一J3坐标系内的真实J4固定板，对两件上臂罩和两件肘罩切出避让空间，并增加六个±0.25 mm轴向平移切削；这是轴向空间预留，不是全局法向间隙或公差合格证明。`style01.py --trim-existing`支持修复现有CAD批次，正常完整生成也包含该避让。manifest的change_stats是原始曲面生成阶段记录，socket_clearance_repair记录后续切削；parts是当前最终零件数值。最新26样本重新计算为零干涉，旧失败记录不能用于当前几何放行。

独立候选包位于 [arm-body-a17-manta](../../manufacturing/candidates/arm-body-a17-manta/README.md)，包含18件替换罩的STEP、毫米贴床STL、18页名义试配投影、安装坐标表及数字检查。其余23件打印结构件、6件库存件、494件名义采购件和7个灵足电机沿用A16试配包。外观仍为工程候选，没有把新曲面或渲染结果宣称为用户认可的最终设计。

本轮检查18件贴床STL闭合、绕向一致、正体积、单连通；坐标变换为正交刚体变换并可还原，最大尺寸小于250 mm。18页A3投影已逐页渲染检查版面，图纸注明所属关节局部坐标系。ZIP通过CRC和逐文件SHA256校验。尚未切片或实物试装，绘图是名义试配视图，不能替代生产尺寸链、公差与GD&T。

长版、3 kg裸臂法兰总负载、灵足整套选型不变。当前CAD、名义采购件、目录电机质量和未完成件余量估算裸臂10.768 kg；4099个未过滤关节配置的静态筛选，肩部最大约44.052 Nm，超过RS04的28.5 Nm零速参考，J5约8.979 Nm相对于9.5 Nm参考也缺乏充足余量。这些配置不是已经通过碰撞筛选的可达工作空间，电机重心不是实测值。虚功数值核对最大误差约6.72e-9 Nm只验证计算一致性，不验证真实载荷能力。详见physics.json。

旧A16气弹簧不确定性预算未通过，当前候选也没有新气弹簧／支座模型或验证结果。还缺真实电机版本／螺纹深度、热与动态负载、金属骨架强度／疲劳、线束运动／同轴误码、实际装配和载荷试验。外观改进及有限样本无干涉不构成生产资格；不允许据本包开展无支撑通电或3kg载荷试验。
