# A19 连续工程迭代

保留340/185 mm轴间距、3 kg裸法兰总负载目标、灵足关节及B06同源底座；本目录为候选工程工作，不覆盖A18当前试配包。

## 肩部偏置销位筛选15

`shoulder15.py`允许移动销离开上臂轴线，仍只有一支普通气弹簧和两端销轴。使用A18当前556项CAD质量、目录电机质量、0.49 kg既有余量及额外0.30 kg运动件余量。J2为0.5°网格，其他关节采用4099个姿态；气弹簧极限长度采用解析极值并与FK核对。

在本脚本明确列出的力值、温度、摩擦和行程假设下，五种候选的最优有限采样残余峰值为28.27–29.30 Nm，均超过22.8 Nm筛选值。这是数值搜索结果，不是全局不可行证明；这些销位未做装配验证，也不发行加工图或采购选型。不能缩小未知力值范围来制造通过结论。

原厂长度和F1范围来源：[SUSPA 16-2](https://www.suspa.com/global/products/gas-struts/gas-struts-type-16-2/)、[SUSPA 16-4](https://www.suspa.com/global/products/gas-struts/gas-struts-type-16-4/)。实际全行程双向力曲线、温度曲线、安装朝向及支座仍需验证。22.8 Nm不是封闭壳内持续保持额定值。

后续模块分别保存实际电机装配、结构件、外壳和验证结果；模块失败也保留结果，失败件不进入当前制造包。

## J5实际电机空间筛选16

`wrist16.py`以原厂RS03 STEP的已核验刚性变换替换J5，保持输出面、实际孔位和1:1尺寸。不再使用RS10P的孔或缩放壳体。原55 mm J5—J6间距在J6=60°时，两片J7后罩与RS03固定壳体分别相交约113 mm³。改为75 mm后，100个有限姿态的231个不同精确候选相交检查未发现大于0.08 mm³的相交。

这是新电机与其余旧件的初筛；明确移除的旧J5支架、外罩和紧固件须重做。不能将这个结果描述为完整腕部、整臂全工作空间或线束通过。原厂电机STEP及分件仍只存于忽略的`work/`目录；仓库保存来源、变换与报告。
