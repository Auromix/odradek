# B04-SERVICE01

Native routed low-power base service PCB. This is **not the complete robot-base connector panel**: EtherCAT, GMSL, and main actuator power are out of scope and require the separate interface assembly.

Read `../../../docs/engineering/base-b04-pcb.md`. Start with `mechanical/base-b04-assembly.step` for assembly coordinates, `kicad/base-b04.kicad_pro` for native ECAD, and `verification.json` for exact current evidence.
