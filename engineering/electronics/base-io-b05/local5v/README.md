# 底座就地前灯电源 · 板级打样候选

48V从原有端子分出支路，经F1输入保险、D1反接二极管、U1非隔离DC/DC产生5V，J7通过底座内部短线连接前灯板。不增加桌下5V供电线。原有EtherCAT直通和48V主路径保持不变。

正式编辑源是同一工程的[原生立创工程](../base-io-b05/base-io-b05.eprj3)。[当前制造文件](../manufacturing/b06-io-local5v/)包括原生Gerber、钻孔、电测网表、BOM、坐标文件和STEP；历史b06-io-prototype目录不代表当前版本。

J7引脚1=5V，2=PWM预留，3=48V RETURN；4/5为固定焊脚，同接RETURN。灯板插头顺序同样为5V/PWM/GND。PWM预留仍未接控制器，不能将当前供电支路描述为已完成程序灯效。当前原理图保留单端PWM警告及相同RETURN标签警告，PCB严格DRC必须为0，不放宽规则。

选型如下，所有标称能力仍需整板测试：

| 位号 | 型号 | 作用 |
|---|---|---|
| U1 | RECOM R-78HB5.0-0.5 | 就地5V转换 |
| F1 | Littelfuse 0451.500MRL | 0.5A输入支路保险 |
| D1 | Diodes S1B-13-F | 输入反接隔离 |
| C1 | TDK C5750X7S2A106K230KB | 10µF/100V输入电容 |
| C2 | Yageo CC0805KKX7R9BB105 | 1µF/50V输出电容 |
| R1 | Yageo RC0805FR-07470RL | 470Ω/1%常开最小负载 |
| J7 | JST BM03B-GHS-TBT(LF)(SN) | 内部灯线 |

[RECOM原厂规格](https://recom-power.com/pdf/Innoline/R-78HB-0.5.pdf)要求输入超过50V时使用3.3µF/100V电容，并建议至少10mA负载。[TDK实际型号](https://product.tdk.com/en/search/capacitor/ceramic/mlcc/info?part_no=C5750X7S2A106K230KB)的标称10µF不能替代52.8V偏压、负容差、温度和老化后的有效电容证明。R1在4.75V及+1%阻值下约10.01mA，在5.25V及−1%阻值下约59.2mW；低负载输出精度、启动与纹波必须实测。

[Littelfuse原厂规格](https://www.littelfuse.com/assetdocs/fuse-451-and-453-datasheet?assetguid=533cd5cc-956c-4243-867f-6ab5a62f6ba1)列出该保险的冷阻及熔断积分。不能据此保证输入电容热插拔和重复启动可靠，也不能保证输出短路一定使输入保险熔断。外置48V源仍须限流和保护。首轮5V支路测试预算100mA；500mA模块额定值不是整板放行值。

U1原始库的三孔为1.00mm；本工程局部封装改为1.10mm孔、1.60mm焊盘、2.54mm间距。客户端附属焊盘DTO的孔径单位与封装DTO存在差异，因此审计以真正导出钻孔工具及坐标为准，并要求保存重开后仍保持。不要以临时PCB焊盘修改代替工程封装修订。

`package-envelopes.json`提供装配最大包络，Blender引用同一文件。初始布局与同轴支架干涉，当前布局已避让；包络检查仍不证明插头卡扣、线弯曲和打印收缩。完整插头线束和端子螺母堆叠仍是装配放行条件。

独立检查入口：`../check_routed.py`验证当前哈希、原生DRC、旧走线未变、实际制造文件及U1孔径；`check_fit.py`验证独立底座中的元件体和六处螺钉工具包络。检查需要CAD Python环境。原生编辑脚本记录增量步骤，不能无条件重复执行；已保存原生工程是交付源。任何修改后均须重开、重导出和重验，不能更新旧哈希来冒充验证。

**尚未生产放行。** 电容有效值、启动/浪涌、故障保护、温升、EMI、程序控制、线束和实物装配均未完成资格测试。测试可用独立限流48V源、5V电子负载和示波器完成，不需要机械臂。
