# B06 IO 板级打样候选

原生来源：`../../base-io-b05/base-io-b05.eprj3`。输出日期2026-10-09，嘉立创EDA专业版4.1.60。数字验证见`../../reports/b06-routed-audit.json`。

PCB116×56 mm，标称1.6 mm，4层FR4；外铜35 µm，内铜15.2 µm。目标叠层JLC04161H-7628，两侧介质0.2104 mm。阻焊、丝印按Gerber；不增加PoE、PHY或电气隔离。PTH及NPTH钻孔单独输出；使用电测文件检查网络，不根据丝印猜测极性。

`B06-IO-PROTOTYPE-Gerber.zip`是实际原生导出，`gerber/`是CRC验证后的相同内容。`B06-IO-PROTOTYPE-IPC356.ipc`是独立导出的电测网表。供电J3→J4/J5、屏蔽J6、数据J1→J2；GMSL馈通另在金属支架上安装，不由本板传输。

打样目的：验证封装焊接、孔位、数据直通和供电温升。尚无整机电流额定值或以太网类别认证；长度匹配不能证明阻抗。不要将48V接入RJ45，不进行带电插拔。完整底座的金属受力路径、连接器插合与线束检查另须通过。

元件BOM见本目录`B06-IO-Native-BOM.csv`：当前原生板与原理图复开核对的六个连接器，安装孔不计入采购。板级制造不代表整套底座已可装配。

J4/J5/J6为Würth74651173 THR接线柱：厂家明确波峰焊不适用，推荐回流；整板混合装配工艺需制造方确认，不能按“全板波峰焊”下单。其M3螺纹高3±0.2mm，接线环、螺母和锁紧方式尚需完成真实叠层核对。0.5Nm是接线柱数据表条件，不能作为整板或其他紧固件的通用扭矩。见底座`manufacturing.md`。
