# A10 打印配合验证包

**单位mm；不按额定3 kg产品使用。** 先打印16个配合样块，核对实际电机、管材、轴承和嵌件，再决定整套打印。打印结构及罩壳33件；金属直管、抗压套、紧固件、轴承及电机必须另行采购。

`print-ready/`已经旋转并平移至正坐标，平台250×250×250 mm包络检查只是几何可放入，不是切片完成或免支撑证明。`print-audit.json`记录正反变换，装配坐标STL在原CAD目录，不应重复打印。

结构件优先采用PA12服务打印进行受支撑的装配验证。FDM的PLA/PETG版本仅先用于孔位、装配、碰撞和外形检查；不能将固体CAD质量或PA12假设直接用于该打印件的负载结论。孔位不能被切片自动“修复”改变。所有横孔、螺母槽和罩壳悬垂需在切片器中审查支撑、清理路径及方向。

配合样块包括：6807轴承座46.9/47.1/47.3 mm；轴颈34.8/34.95/35.1 mm；M4热熔嵌件底孔5.3/5.5/5.7 mm；20×40管的总间隙0.2/0.4/0.6 mm；四种电机输出接口。实物测量结果回填参数后重建，不能用锤击或紧固螺钉强迫不匹配的电机、轴承和管材入位。

安装用通孔只去毛刺；轴承位/嵌件孔按样块结果加工。保持端面平面度，用合适垫片校准J7轴承堆叠；塑料不得承担精密预紧。螺钉规格见BOM，扭矩需按实际打印工艺、材料和供应商螺纹数据确定，本包没有经试验的统一锁紧扭矩。
